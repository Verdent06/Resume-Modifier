# Front-End Developer Intern — Guidewire

## Quick Facts
- **Type:** Internship
- **Location:** Toronto, ON, Canada — Hybrid
- **Compensation:** CA$24.04–CA$29.81/hr + Bonus + Long Term Incentive Awards
- **Template Used:** full-stack

## Role Summary
Interns join Professional Services and work on real customer implementation projects using Guidewire Digital products and the Jutro design system. Day-to-day work includes designing, implementing, and testing front-end features in React, HTML, CSS/SASS, and JavaScript; building responsive, accessible UIs; collaborating with UX Designers and BAs to turn requirements into reusable UI components; and integrating with RESTful APIs and backend services. You use Git and modern workflows, participate in code reviews, and apply AI-assisted tools (e.g., GitHub Copilot, Claude) to boost productivity and quality. Success at 3 months means shipped features on customer projects, effective pairing with senior consultants, and contributions to documentation or implementation patterns.

## What They're Really Looking For
- **React-first front-end** — Components, props, state (hooks/context), and some performance awareness; Jutro is React-based, so React is non-negotiable.
- **Web fundamentals** — HTML, CSS, SASS, JavaScript with enough depth to implement responsive, accessible UIs without constant hand-holding.
- **Integration comfort** — RESTful APIs, JSON, and wiring front-end to backend services; you'll debug data flows and refine integrations.
- **Design-system mindset** — Reusable components, consistency, and alignment with accessibility best practices; Jutro and “implementation patterns” imply they care about repeatable, scalable UI.
- **AI-augmented workflow** — Willingness to use Copilot/Claude for productivity and quality; this is called out in requirements and desired qualifications.
- **Collaboration and communication** — Hybrid, cross-functional work with UX, BAs, and implementation teams; consulting/customer-facing context means clear communication and learning from feedback.

## Required Skills
- Demonstrated ability to embrace AI and apply it to your current role as well as data-driven insights to drive innovation, productivity, and continuous improvement
- Current enrollment in the 3rd or 4th year of a Bachelor's degree, or a graduate program, in Computer Science, Software Engineering, or a related technical field
- Foundational knowledge of web development, including experience with HTML, CSS, SASS, and JavaScript through coursework or projects
- Familiarity with React and modern front-end concepts such as components, props, and basic state
- Strong understanding of Object-Oriented Programming principles and core software design fundamentals
- Awareness of responsive design techniques and web accessibility considerations
- Clear, proactive communication skills and the ability to collaborate effectively in a hybrid, cross-functional team environment
- Curiosity, a problem-solving mindset, and willingness to learn from feedback in a consulting and customer-facing context

## Preferred Skills
- Prior hands-on React development experience through academic projects, personal work, or internships
- Understanding of React state management (e.g., hooks, context) and basic performance considerations
- Experience with Git or other version control systems and standard branching workflows
- Familiarity with RESTful APIs, JSON, and integrating front-end apps with backend services
- Exposure to AI-assisted development tools (e.g., GitHub Copilot, ChatGPT, Claude) and interest in using them to accelerate delivery
- Basic knowledge of build tools and package managers such as Webpack, npm, or similar
