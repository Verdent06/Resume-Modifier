## Role Summary

Ten-week Chicago **Technology Intern – Software Engineering** (Workday **R160832**, hybrid). Interns are fully integrated into application and platform development teams contributing to real financial solutions: design, development, deployment, maintenance, and modernization of applications, databases, data pipelines, APIs, microservices, and cloud-based platforms. Agile delivery; collaboration with business and technology stakeholders; modern engineering practices (CI/CD, TDD). Recruiter places the intern given interests, skill set, and relevant experience. JD surface stack examples: **Java, Python, SQL, Azure DevOps, Github**. Every technology internship "likely involves" some automation via coding and some generative-AI capability — practice flavor, not an ML-research seat. Company identity (`company.md` / `companies.md`) is **wealth + asset servicing + asset management** — custody/wealth platforms, not IB coverage, not a trading desk, not a consumer-app startup. Sister tracks (InfoSec R160869, Infra R160872, DS/Analytics R160865) are different packets; this lens is SWE only. Sample path: Technology Analyst in the Software Engineering track of ADP.

## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has that the JD names (**Python**, **SQL**). Keyword-through-use in bullets, not Skills-only (`resume.md` §2). **Do not invent Java or Azure DevOps.** Git/GitHub through use matches the named tools list.
- Shipped full-stack or backend software: REST/APIs or services, databases, data pipelines, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Agile/stakeholder delivery and tests or CI through use match "what you'll do."
- CS fundamentals visible: DS&A coursework plus engineered work defensible if a coding screen is later invited (platform unpublished).
- Modern practices through use: Git/version control, CI/CD or automated tests, cloud-based platforms — not a homelab-as-SRE story.
- Custody-wealth / fintech-backend flavor on that spine: production APIs, financial or regulated-data workflows, reliability/controls-minded delivery — memorable here without replacing the SWE spine.
- Curiosity about financial markets as *evidence on the page* (finance-adjacent shipping), not a cover-letter slogan.
- Class-year and GPA on the page: `Expected May 2028` and GPA 3.66 satisfy the Summer 2028 window + 3.0 floor.

**Anti-patterns:**

- Skills-line Java / Azure DevOps / Spring / Node / C# / Azure with zero bullet evidence (fabrication smell at a shop that named those as examples).
- Invented Snowflake, Databricks, Copilot, Fusion, Tableau, or Sentry — banned; not in inventory. Do not turn "generative AI capabilities" into a Copilot claim.
- Invented custody-platform, core-banking, or Java-microservice claims because the company is a bank.
- Agentic-AI / LoRA / notebook-ML lead as if this were the Data Science and Analytics intern seat (R160865).
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/API/cloud/enterprise SWE.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + finance-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
