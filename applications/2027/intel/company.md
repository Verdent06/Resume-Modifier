# Intel

Intel designs CPUs, GPUs, accelerators, and the foundry/process stack behind them — Core/Xeon on the client and data-center side, Arc and Gaudi on graphics and AI, plus the software that enables products and platforms (drivers, tools, firmware-adjacent system software, validation). Intern SWE seats sit across a catch-all early-career pipeline (applications, cloud, firmware, GPU software, middleware, research, system software, validation), not a single RTL or oneAPI desk. `reference/companies.md` B-TIER Notes flag a large intern program and that **20% manufacturing layoffs in 2025 significantly hurt signal**; this 2027 Bachelor’s SWE posting (req **JR0286834**) is a generic polyglot SWE catch-all, not a chip-design or graduate 🎓 sibling.

## Quick Facts

- **Tier:** B-TIER — Good / Solid Resume Addition (`reference/companies.md`)
- **HQ / offices:** Santa Clara, CA (HQ). This req primary: US, Oregon, Hillsboro (JSON-LD locality: USA - OR - Aloha). Additional: Phoenix AZ, Folsom CA, Santa Clara CA, Austin TX. **Not available in Colorado.**
- **Valuation / signal:** Public (NASDAQ: INTC); large intern program; 2025 manufacturing layoff cut (~20% in Notes) hurt prestige vs AMD/NVIDIA SWE. Extern analog: 25,000-position 2025–2026 restructuring with early-career pipeline still live **[directional]**.
- **Product focus:** Silicon + the software that enables Intel products and platforms (CPUs, accelerators, tools, firmware-adjacent system software) — not a consumer web product
- **Intern comp (2027 Software Engineering Intern, Bachelor’s, JR0286834):** Annual Salary Range $95,698.00–$95,702.00 USD (Hourly Role) on the JD; intern rates depend on degree, location, and role. Relocation may be available based on eligibility. Extern analog $30–$77/hr + housing stipend **[directional]**
- **Work model:** Paid Student / Intern; on-site; Shift 1 US. Starts Spring and Summer 2027; year-long intern/co-op also considered. This posting is an existing vacancy (posted 2026-09-02).
- **Clearance / eligibility:** Currently pursuing a Bachelor’s in CE, CS, Data Science, EE, Mathematics, or related STEM; 3+ months technical experience (coursework, projects, research, internships, co-ops, orgs). GPA 3.0+ preferred. **Not eligible for employment-based visa/immigration sponsorship.** On-site at listed US sites only (Colorado excluded).

## Stack & Hiring Signal

- **Languages:** JD names none as exclusive. Preferred interest: programming, scripting, data analysis, automation, modeling, simulation, validation, debugging. Do not invent SYCL, oneAPI, OpenVINO, CUDA, Verilog, RTL, or firmware internships.
- **Domains:** Software that enables Intel products and platforms; code review, high-level design, scripting, automation, validation; open/secure software platforms and tools; programming + data + systems thinking; collaboration with hardware, systems, product, and software teams. Placement families (not the screen): AI Frameworks, Cloud SWE, Firmware, GPU SWE, Middleware, Application SWE, Software Research, System Software, System Software Validation.
- **What wins:** A full-stack intern spine (`resume.md` Part III §12 / `recruiting.md` Part III §11) with programming/scripting shown in bullets (Python, C++, SQL/JS-family where real), plus visible systems / performance / real-time / hardware-adjacent depth so the page is memorable at a chip company. Do not invent firmware, RTL, oneAPI, or Linux-as-undefended-skill. Workday knockouts (Bachelor’s enrollment, no sponsorship, on-site, not Colorado) are absolute (`recruiting.md` §8). Bottleneck is the resume (`companies.md`).
