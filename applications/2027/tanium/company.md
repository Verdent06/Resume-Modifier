# Tanium

Tanium is a private Autonomous IT company: real-time endpoint intelligence plus unified IT and security control on one platform (linear-chain query architecture). The product is Autonomous Endpoint Management (AEM) — operators ask questions and take action across the estate without waiting on a scan window. This intern req is Engineering - Core Plus product work: frontend *or* backend assignment on next-release B2B security / endpoint-platform features delivered to customers, not a security-research or malware internship.
