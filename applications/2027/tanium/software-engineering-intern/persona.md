# Software Engineering Intern – Summer 2027 at Tanium

## Role Summary

Paid hybrid Software Engineering Intern (3 days/week) in Durham, NC ($55/hr) or Emeryville, CA ($60/hr), plus 401k match and a monthly comms stipend. The intern is assigned to a **frontend or backend** team by ranked preference and available projects, ships features for the next release of Tanium's B2B security / endpoint platform that are delivered to customers, works 1-1 with a senior mentor and a peer intern buddy, produces a unique deliverable, and demos to engineering leadership in a 70+ intern cohort. JD surface is finished FE/BE software on a product team. Company identity is Autonomous IT / real-time endpoint intelligence — not a security-research seat and not an ML-training internship, even though marketing copy says "Driven by AI."

**Eligibility contradiction (flag, do not resolve):** JD body requires graduating Spring 2027 or Fall 2026 and lists term dates June 8–August 14, **2026** (stale vs Summer 2027 title; published 2026-09-10). Greenhouse form also offers Spring 2028 / Summer 2028. Screen from **JD text**: class-year miss. GPA 3.5+ is a hard form/JD gate.

## Screen Criteria

- Finished frontend and/or backend software in bullets — a complete delivery path (API, UI, or both), not a skills list and not a half-built tutorial (`resume.md` §12). Breadth across the stack plus depth in at least one layer.
- Python and TypeScript demonstrated inside an architectural decision. React / Angular / REST / Docker / AWS / Git / CI through use when present. Do not invent Node.js, Snowflake, Databricks, Copilot, Fusion, or Tableau.
- Production or stakeholder-facing delivery so "features delivered to Tanium's customers" can be analogized — a real consumer of the work, not only solo architecture.
- Quantified impact (latency, failure rate, throughput, hours saved, scale) so "finished" can be sized.
- Differentiator is flavor, not a second spine: security/endpoint excitement is an interest filter, not a prior-AppSec or malware-research requirement. Do not lead with an off-axis ML-training or C++ DSP identity.
- Anti-patterns: tutorial-grade projects; Skills-only Python/TypeScript/React; notebook ML without delivery; CI/CD as the only story; club-ops without engineering; framing a campus consulting club as prior professional employment; thin filler.
