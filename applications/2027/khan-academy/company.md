# Khan Academy

Khan Academy is a 501(c)(3) nonprofit (founded 2008, Salman Khan) that ships a free Pre-K–12 and early-college learning platform — math and science first — plus Khanmigo, an AI tutor. The JD cites **155 million** registered learners; Form 990 / press directional **~185 million** by mid-2025 **[directional]**. FY2025 revenue **$117.5M** / ~**337** staff (Form 990). Engineering identity is learner-and-teacher product at nonprofit scale: classroom tools, content widgets, and Khanmigo features used by millions — not an ML-research lab and not a language-knockout shop. Company stack *used in production* (explicitly not required of interns): Go, JavaScript (React / React Native, Redux, Flow), Google Cloud Run, GraphQL.

## Stack & Hiring Signal

- **Languages:** JD: any language/tool welcome — **do not require Go, React Native, Redux, Flow, or GraphQL-as-used**. Company ships Go + JavaScript (React / React Native, Redux, Flow) + Google Cloud Run + GraphQL. Screen for honest product-SWE proof (JavaScript/TypeScript/React/Python through use). Do **not** invent Go, React Native, Flow, GraphQL-as-used, Khanmigo, PhET, Snowflake, Databricks, Copilot, Fusion, Tableau, or a Khan internship.
- **Domains:** Learner-and-teacher product engineering at nonprofit scale — UI widgets, classroom tools, Khanmigo-adjacent features, content integrations. Mentorship + onboarding onto the company stack. AI-assisted development with ownership of generated code.
- **What wins:** A full-stack intern spine (`resume.md` Part III §12 / `recruiting.md` Part III §11) with shipped product (frontend + API + persistence or deploy/test path) in languages the candidate actually has, plus a project that can be demoed. Resume + essays are the binding intern skill gate (`recruiting.md` §1, mid-size Greenhouse). Apply in this first-wave window (`recruiting.md` Part II §8; close Oct 16). Mission fit is a filter, not a substitute for shipped software. Prior software internship is a hard JD gate — titled SWE/co-op evidence on the page.
