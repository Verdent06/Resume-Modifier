# Software Engineering Intern (Summer 2027) at Scale AI

## Role Summary

Paid Summer 2027 SWE intern (May/June start) on-site in San Francisco. Interns ship on the same roadmaps as full-time engineers: RL/post-training data pipelines, evaluation infrastructure for enterprise and public-sector customers, agentic applications and the tooling that makes them observable/testable/safe, contributor-growth and fraud/quality systems, matching algorithms, contributor UI/UX, and AI-infra products to visualize/query/explore Scale data. JD surface is product engineering: full-stack web apps, APIs, talking to customers, iterating on what to build, a prior CS/SWE internship, shipping products, systems that process large volumes of data, and Python / TypeScript / React / MongoDB (and/or). Company identity is AI data infrastructure for frontier models — not a consumer CRUD shop and not an ML-research internship.

## Track Decision

- **screen_track:** full-stack
- **differentiator:** AI data platform / applied pipelines / eval-and-quality infra
- **track_divergence:** true

The literal requirements test general SWE / product-engineering fundamentals (`reference/resume.md` Part III §12, `reference/recruiting.md` Part III §11): a shippable full-stack product, APIs, a prior internship, volume data systems, Python and TypeScript/React through use. MongoDB is an *or*, not a fabrication invitation. Scale's memorable identity is applied data/eval/agentic infrastructure at contributor-and-model scale (`reference/companies.md` A-tier Notes; `company.md`). Spine is full-stack shipping. Differentiator stays prominent and deep: production data pipelines, eval/quality gates, agentic systems with metrics — without turning the page into LoRA-paper / ML-research framing (`recruiting.md` Part III §13 applied vs research split).

## Team & Bar

A-tier, <3%; intern funnel in `companies.md` is **3–4 rounds, Med–Hard, HackerRank, sys design Yes, bottleneck = tech rounds**. Greenhouse university recruiting (`UR-2027-INT`); a human reads the PDF, then HackerRank is the high-volume intern filter. Recruiter voice: an intern who already shipped product (not a tutorial clone), has a real CS/SWE internship on the page, can talk to customers and iterate, and looks like they belong next to data-platform engineers — not someone listing Scale products they have never used, not a notebook-ML researcher. Coding is LeetCode medium-hard; tech rounds are the doctrine bottleneck after the OA. Behavioral is a filter (`recruiting.md` Part I §6) mapped to Scale credos (ownership, quality, customer impact), not the differentiator. Eligibility is computed: Expected May 2028 = Spring 2028; Summer 2027 intern returning to school.

## Screen Criteria

- JD languages demonstrated in bullets, not Skills alone — Python and TypeScript/React through use. MongoDB is an example in an and/or list, not a requirement to invent.
- Prior Computer Science / Software Engineering internship visible as a titled experience — the JD names it.
- Product engineering: full-stack web (frontend framework + backend/API + datastore + deploy/CI) with trade-offs the candidate can narrate (`resume.md` §12).
- Systems that process large volumes of data — ETL, pipelines, scoring/eval at countable scale — with impact metrics a recruiter can size in 30 seconds.
- Applied LLM / eval / agentic signal in the top half when present (nice-to-have on the JD): eval harnesses, quality gates, agent pipelines with faithfulness/qualification numbers — not paper-abstract research.
- Shipped product used by someone other than the author (customers, operators, paying clients).
- Class-year on page: `Expected May 2028` satisfies Spring 2028.

## Anti-Patterns

- Inventing MongoDB, Snowflake, Databricks, Copilot, Tableau, Fusion, or Sentry.
- Leading with LoRA / research-paper / `model.fit()` framing as if this were an ML-research intern seat.
- Skills-list TypeScript or React with no bullet evidence.
- Club-ops, GTM/quant sourcing, or deal-flow work with no engineering the role tests.
- Notebook ML with no pipeline, API, eval, or deploy story.
- Thin single-bullet filler that dilutes a production + pipeline spine.
- Claims the candidate cannot defend for 45 minutes in a project deep-dive or a HackerRank follow-up.
