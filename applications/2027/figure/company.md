# Figure

Figure is an AI robotics company building autonomous general-purpose humanoid robots for home and commercial work, with the stated goal of shipping humanoids at human-level intelligence. Flagship hardware is Figure 02 → Figure 03; Helix 02 is the proprietary pixels-to-actions vision-language-action stack that coordinates loco-manipulation. BMW Plant Spartanburg is the public commercial deployment: Figure 02 contributed to ~30,000 X3s in 2025; Figure 03 returned in June 2026 for logistics sequencing in Hall 52. This intern is Platform Software middleware — robot IPC at ~320M messages/hour, data capture/storage, and developer visualization — not firmware bring-up and not Helix/VLA research.

- **Tier:** A-TIER — Excellent / Strong Signal (`reference/companies.md`)
- **HQ / offices:** San Jose, CA (3960 North First Street). This intern is onsite 5 days/week; no remote/hybrid.

- **Intern comp (2027 Middleware Intern):** $40.00–$45.00/hour (JD)

## Stack & Hiring Signal

- **Languages:** C++ and Python required; TypeScript bonus. Linux, computer architecture, and networking protocols are floor knowledge. Bonus: Bazel, timing-sensitive environments, shared memory, lock-free systems.
- **Domains:** Embedded Linux middleware, high-rate robot IPC, data capture/storage, developer tooling/visualization, test infrastructure
- **What wins:** Hardware/software projects outside coursework; C++ and Python shown in bullets (not Skills stuffing); lock-free / timing-sensitive / shared-memory evidence; Python used to investigate and stabilize failures. ROS/perception/controls are not this req. Club-ops and notebook ML fail the screen.
