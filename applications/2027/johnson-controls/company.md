# Johnson Controls

Johnson Controls International plc (NYSE: **JCI**) is a global buildings-technology company — HVAC, industrial refrigeration, fire, security, and energy-management — with **OpenBlue** as the digital layer on that installed base. Legal HQ is **One Albert Quay, Cork, Ireland**; U.S. operating signal is Milwaukee. FY2025 net sales **$23.6B**; ~**87,000** employees worldwide as of 2025-09-30 (~31,000 U.S.) per the FY2025 10-K. This packet is **not** Clarios (the 2019 Power Solutions / automotive-battery spin) and **not** a generic OpenBlue campus SWE intern. The Burlington, MA co-op sits on the **Stack Forging Thermal Solutions** team from the **Alloy Enterprises** acquisition (announced 2026-02-18, closed 2026-05-13): proprietary slicer / machine-control / production software for leak-tight single-piece thermal components used in data-center and industrial cooling. Hiring org on Workday CXS: **1017 York International Corp.**

## Stack & Hiring Signal

- **Languages:** Required **Python**, **C/C++**, **Git**, **UNIX/Linux**. Preferred **JavaScript** and **React**. Tests named for Python and C++ applications. Do **not invent** Jira-as-used, Bash-as-homelab, ROS, PLC, firmware internships, OpenBlue product usage, Java, MATLAB, Snowflake, Databricks, or MatchStream.
- **Domains:** Production software for advanced manufacturing; machine control; slicing; test/validation; React UI on a production app; hardware / embedded interfaces; unit + integration tests; workflow automation.
- **What wins:** A one-page PDF that shows the **full-stack SWE floor** (Python + C++ through use, Git, tests, React if honest) **and** hardware-adjacent / real-time / machine-interface evidence in the lead window — without claiming firmware, PLC, or Stack Forging product ownership.
