# Hermeus

Hermeus is a venture-backed defense aviation company building high-Mach unmanned aircraft through rapid hardware iteration. Flagship program is Quarterhorse (Mk 2.1 has flown; path toward Mach 5 / hypersonic), with the longer-term Darkhorse / hypersonic unmanned product for U.S. and allied customers. Software on this intern req is Atlanta Hardware-in-the-Loop (HIL): real-time simulation that ties hardware components to software models so flight software and vehicle/avionics/flight-deck systems can be tested on the bench. `reference/companies.md` has no Hermeus row.

## Quick Facts

- **Tier:** Unrated (`reference/companies.md` has no Hermeus row). Nearest published peers for intern brand: SpaceX (B-tier, C++/Python mission-critical aerospace), Anduril (A-tier, C++ embedded/autonomy), Shield AI (B-tier, defense AI). Comp sits closer to industrial/C-tier intern pay than those names.
- **HQ / offices:** Atlanta, GA (this HIL intern, onsite). Other intern sites: Washington, D.C.; Jacksonville; Los Angeles. This packet is Atlanta HIL only — not the Los Angeles Modeling & Simulation intern.
- **Valuation / signal:** Series C Apr 2026 — $350M ($200M equity led by Khosla Ventures + $150M debt) at $1B post-money; >$500M total raised. Backers include Canaan, Founders Fund, RTX Ventures, In-Q-Tel. Customer: Department of War / U.S. defense. ~300 employees (TechCrunch, Apr 2026). Quarterhorse Mk 2.1 first supersonic flight May 2026 (Mach 1.21, Spaceport America / White Sands).
- **Product focus:** High-Mach unmanned aircraft (Quarterhorse demonstrators → hypersonic path); this intern is HIL test benches for flight software, not airframe CAD and not LA modeling-and-simulation.
- **Intern comp (2027 Software Engineering Intern (HIL)):** $25–$33/hour by degree level (JD guideline). Overtime eligible. Monthly living stipend. No housing. Relocation: one flight or eligible gas reimbursement. 5 days sick leave; weekly paid lunches; stocked breakrooms.
- **Work model:** Paid, onsite Atlanta. Spring ~16 weeks (January–April) or Summer ~12 weeks (May–August). Company internships page also lists a Fall term (Sept–Dec) — this req is Spring/Summer 2027 only.
- **Clearance / eligibility:** U.S. person required (22 C.F.R. § 120.62 / export control). GPA 3.0+. Pursuing CE, CS, EE, or related. Most Hermeus internships require U.S. person (company internships page).

## Stack & Hiring Signal

- **Languages:** JD: Julia, *or* strong scientific computing in Python, MATLAB, or C++. This intern ships test scripts and HIL infrastructure, not a named web framework list.
- **Domains:** Hardware-in-the-Loop test benches; real-time simulation connecting hardware to software models; automated / regression tests for flight software and vehicle systems; test-stand upkeep (config, calibration, docs); debug across signal / hardware / software / comms; avionics and flight-deck validation.
- **What wins:** Because Lever means a human reads the PDF (`recruiting.md` intern funnel; Unrated startup), a one-page resume that proves Python and C++ *in bullets*, automated-test or tooling discipline, and hardware–software-boundary / real-time / integrated-systems debug — without claiming Julia, MATLAB, Raspberry Pi, Arduino, STM32, or ROS that are not in inventory. Club-ops filler, Skills-only languages, and a generic full-stack/LLM product page with no test-or-systems signal fail this HIL screen. Do not blend Modeling & Simulation / LA framing into this Atlanta HIL packet.
