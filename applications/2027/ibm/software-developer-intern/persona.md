# Software Developer Intern 2027 at IBM

## Role Summary

A Summer 2027 Software Developer Intern (jobId 128497) on IBM Software engineering teams. The intern designs, builds, tests, and debugs software in front-end, back-end, or full-stack environments for cloud, AI, and hybrid-platform products — React UIs or back-end services/APIs, Git, Docker/Kubernetes/REST, Agile ceremonies and code reviews, with optional exploration of AI/ML, automation, and cloud-native development. This is a **general SWE intern**, not ML research, not Extreme Blue, and not a CAD/mechanical req. Official work arrangement is **hybrid** with location flexibility across Lowell MA, Durham NC, Bellevue WA, San Jose CA, and Austin TX.

JD surface vs company identity: requirements are polyglot software-development coursework/projects, DS&A/debugging, front-end or back-end exposure (React, Node.js, Python, Java, SQL), Git, and interest in cloud/containers. IBM's identity is hybrid-cloud + enterprise AI software (IBM Cloud / Red Hat). That identity flavors the same full-stack spine; it does not convert the role into an applied-ML or SRE hiring profile.

## Track Decision

- **screen_track:** full-stack (JD requirements literally test front-end and/or back-end software development, APIs, Git, and cloud/container *interest* — default general SWE)
- **differentiator:** hybrid-cloud / enterprise AI software (IBM Software + Red Hat) — cloud-native delivery and AI-infused products as company identity, not a research-ML bar
- **track_divergence:** false

The screen spine and company identity agree on `reference/resume.md` Part III §12 (General SWE / Full-Stack): a genuinely engineered, shippable product with frontend framework, backend/API, a database, cloud deploy, and a CI step, narrated decision-by-decision. The differentiator sharpens emphasis *within* full-stack toward REST APIs, Docker/cloud, Git/CI, and any production AI-tooling used as engineering (not notebook ML). `reference/recruiting.md` Part III §11 is the hiring flavor: DS&A-gated at scale (HackerRank here), resume-first bottleneck at IBM specifically (`companies.md`).

## Team & Bar

IBM is B-tier: large intern program, bureaucratic, Red Hat as the cloud-relevance signal. Funnel is Avature resume screen (the bottleneck, ~10–15%) → easy HackerRank OA → 2–3 easy technical/behavioral rounds; no intern systems-design round. Recruiter voice: a student who has already written, tested, and shipped software with Git — any of the named languages — and can talk about APIs, a UI *or* a service, and some cloud/container curiosity. Preferred pluses (cloud vendor, REST + databases, CI/CD, personal/OSS projects, Agile) are differentiators on a high-volume intern pile, not knockouts. High school diploma is the posted education floor; bachelor's preferred. US work authorization is assumed for this req; candidate needs no sponsorship. `recruiting.md` §8 lists IBM among early-identity intern programs — the resume still has to survive Avature + a human skim.

## Screen Criteria

- Software-development evidence in bullets: design/build/test/debug of a real front-end, back-end, or full-stack artifact — not coursework listed without a project.
- JD languages demonstrated *inside* architectural decisions (Python, TypeScript/JavaScript, C++ as applicable), not Skills-only. Java/Go/Rust/Swift/Kotlin are JD examples, not a floor — do not fake them.
- Front-end *or* back-end exposure with named tools in context: React (or a comparable UI framework), and/or services/APIs; SQL or another datastore through use.
- Git and collaboration signal (version control, code review, team or stakeholder delivery).
- Cloud / containers / modern deploy as *interest backed by use*: Docker, a cloud vendor (AWS counts; IBM Cloud is preferred not required), REST APIs. Kubernetes is a plus if present; absence is not a reject.
- CI/CD or automation and personal/open-source projects as preferred screen-upside.
- Emerging AI/ML as exploration on a SWE spine — agentic/LLM work that shipped is a plus; a research-only or notebook-ML lead is off-axis for this req.
- Class-year on page shows current enrollment (`Expected May 2028` is in window for a 2027 intern who returns to school).

## Anti-Patterns

- ML-research or notebook-training resume aimed at Watson/research labs — this posting is Software Developer Intern, not a research scientist intern.
- Skills-list stuffing for Java, Kubernetes, IBM Cloud, or Node.js with zero bullet evidence.
- Pure CAD / mechanical / aero lead, or C++-only DSP as the *spine* when the JD tests web/API/cloud software (systems depth can support, not lead).
- Tutorial clones with no Git, no API, no deploy, and no users.
- Thin single-bullet filler that dilutes a shipped full-stack story.
- Claiming IBM Cloud or Kubernetes that was never used.
