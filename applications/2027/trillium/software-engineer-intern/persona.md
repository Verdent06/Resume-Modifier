# Software Engineer Intern at Trillium

## Role Summary

SE Intern in Trillium Labs building high-performance solutions for complex financial trading and data-analysis applications, reporting to the Lead Software Architect and collaborating with the software engineering team (and, through them, traders) in New York (in-person). JD surface is generalist fintech SWE: design, code, and debug applications using software-development best practices; support integration and testing across multiple systems; research relevant technologies; participate in code reviews; and document work. Proficiency named as "Python, C++, and C#," plus software-development methodologies/tools/version control and a solid algorithms/data-structures foundation. Company identity is proprietary trading / market-making: in-house trading technology where performance, correctness, and desk collaboration matter on the firm's own capital.

## Track Decision

- **screen_track:** full-stack (general SWE)
- **differentiator:** proprietary-trading / high-performance systems (C++ and low-latency/performance depth) + financial data-analysis applications
- **track_divergence:** false

The screen spine is general SWE per `recruiting.md` Part III §11 and `resume.md` Part III §12 — ship working software end to end, DS&A foundation, C++ and Python proven in bullets, testing and version-control discipline. The differentiator is flavor on that spine (performance-sensitive trading systems, financial/quantitative data work, integration across systems), not a second track. Do not pivot the resume to an ai-ml or robotics framing; the JD tests a fintech generalist who can build and debug high-performance applications and reason about data structures and algorithms.

## Team & Bar

Trillium is unrated in `companies.md` but sits in the proprietary-trading / market-making peer set (funnel family near DV Trading, CTC, IMC — OA-gated, C++/Python heavy, low-single-digit acceptance, brutal-early cycle per `recruiting.md` Part I §1 and Part II §8). Recruiter voice (Lead Software Architect + eng team): interns who already show CS fundamentals, ship real software, communicate with engineering and desk stakeholders, and demonstrate performance-sensitive or data-analysis engineering depth. Comp is $25/hr, in-person NYC, 12–13 weeks — selective but below top-tier quant headline rates; the bar still expects language depth and systems/analytical signal. Eligibility is soft (prefers a completed CS/CIS/Math degree, will consider candidates pursuing one) — a rising-senior CS student is in-band, so class-year is not a hard page gate here.

## Screen Criteria

- C++ and Python proven in bullets, not Skills-only — both load-bearing at a firm where language depth is a floor signal. Do not claim a language absent from real work; deep Python + C++ beats an invented C#.
- Low-latency, real-time, or performance-engineering depth that reads as trading-tech adjacent: concurrency, hot loops, zero-allocation constraints, sub-millisecond or throughput wins.
- Production / shipped-software signal: deployed services, REST APIs, release-ready binaries, measurable reliability, latency, or cost outcomes; testing and version-control discipline visible.
- Financial / quantitative or data-analysis framing where numbers size impact — this firm builds trading and data-analysis applications and reads performance-sensitive, data-driven problem solving.
- DS&A / OOP foundation visible via coursework and engineered projects defensible in a coding interview.
- Integration/testing/code-review discipline (works across multiple systems, reviews code) is a plus layered on the SWE bar — absence is not an auto-reject.

## Anti-Patterns

- Pivoting to an AI/ML-research or robotics resume when the JD tests a fintech generalist SWE.
- C++ or Python named in Skills with zero bullet evidence at a firm where language is a floor signal.
- Claiming C# (or any language) with no backing work just because the JD lists it.
- Finance-jargon padding without engineering substance; soft, metric-free shipping claims where production/performance impact is the firm's selling point.
- Club-ops or community-growth framing with no engineering depth; thin single-bullet filler diluting a strong systems + production spine.
