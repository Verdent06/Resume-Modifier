- Azure / C# / .NET / Ionic / GraphQL as plus (company-stack flavor), never as the lead story for a generic SWE intern req, and never invented.
- Class-year and GPA on the page: `Expected May 2028` and GPA 3.66 satisfy the Dec 2027–May 2028 window and 3.5 floor.

**Anti-patterns:**

- Skills-line C# / .NET / Azure / Node.js / Java / GraphQL / Ionic with zero bullet evidence (fabrication smell at an Angular/.NET/Azure shop).
- Invented Snowflake, Databricks, Tableau, Copilot, Fusion, or Sentry — banned; not in this intern JD and not in inventory.
- Invented auto-lending, dealership-OMS, or Azure-microservice claims because the company paragraph named used-car finance.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/app development, Angular, and Agile delivery.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + finance-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
