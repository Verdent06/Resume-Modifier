# Intern, Agent Development (Summer 2027) at Sierra

## Role Summary

Summer 2027 on-site intern (San Francisco or New York) working directly on **production AI agents** for Sierra's enterprise customers: contributing to agent design and development, shipping features, and learning from real-world use at scale. JD title is Intern, Agent Development; body names the role Software Engineer, Agent Intern. JD *requirements* are generic SWE intern (CS degree, problem-solving in ambiguity, builder/high-agency, communication). Company identity is enterprise customer-experience agents — evals, RAG, agent tooling, prompt engineering, React/TypeScript/Go as the preferred product stack — not an ML-training rotation and not a research lab.

## Screen Criteria

- Full-stack spine: shipped product features with a backend/API layer, a data store or pipeline, and a frontend or client — breadth plus depth in one layer (`resume.md` §12). Lead with shipping, not with a research-ML identity.
- Production AI/LLM systems visible in the top half: agents, evals, RAG, or agent tooling demonstrated in bullets (architectural decision + metric), not a Skills-only AI list. Preferred stack is a plus that should be *used*, not stuffed.
- TypeScript through use in at least one bullet (JD preferred language the candidate has). React through use is a plus; do not imply a React production internship if the titled frontend is a different framework. Do not invent Go.
- Builder / high-agency evidence: owned delivery, diagnosed defects, shipped under ambiguity — matching "find creative ways to overcome obstacles and ship."
- Quantified impact (latency, cost, accuracy, eval lift, throughput, reliability, paying users) so "production" and "at scale" can be sized in ~7 seconds (`resume.md` §4).
- Communication / stakeholder signal somewhere on the page (client delivery, mixed-audience product, or owned scoping) — the JD names excellent communication as a requirement.
- Keywords through use, not isolation (`resume.md` §2): eval frameworks, RAG, prompt engineering, agent tooling, LLM, production, shipping features.
- Class-year on page: `Expected May 2028` satisfies the intern graduation window.

Anti-patterns:

- Notebook ML, LoRA-as-the-whole-story, or research-track framing that hides the SWE intern spine.
- Club-ops, GTM/quant sourcing, or deal-flow with no engineering the Agent Intern role tests.
- TypeScript / React / RAG / evals named only in Skills.
- Implied React production internship or invented Go / Snowflake / Databricks / Copilot / Fusion / Tableau.
- Thin single-bullet filler that dilutes a production-agent + full-stack page.
- Prompt-playground work with no eval, no deploy, and no metric.
