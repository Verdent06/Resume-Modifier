# Rippling

Rippling is a compound workforce platform that unifies HR, IT, and Finance on a single employee graph so companies can hire someone anywhere and stand up payroll, benefits, a corporate card, a laptop, and third-party apps (Slack, Microsoft 365) in one flow. The technical identity is backend systems on that shared graph — product teams (user-facing and internal) plus platform engineering that layers abstractions on the compound platform — not a single-product HRIS and not generic CRUD. Interns join a specific product or platform team for 13 weeks, own a project scoped to the term, and ship production features; the intern class is large (~150+) for a private compound-platform company, and the resume-to-OA path is fast.

## Quick Facts

- **Tier:** A-tier (`reference/companies.md`)
- **HQ / offices:** San Francisco (HQ); NYC, Seattle, Bangalore. This apply is San Francisco.
- **Valuation / signal:** $16.8B Series G (May 2025); ~$1.85B raised (Kleiner Perkins, Founders Fund, Sequoia, Greenoaks, Bedrock, plus later GIC / Goldman Sachs Alternatives / Baillie Gifford / YC participation). Forbes “best startup employers” signal.
- **Product focus:** Compound HR / IT / Finance workforce platform on one employee graph (20+ products)
- **Intern comp (2027 SWE intern, Winter backend):** unlisted on the JD. Directional (not JD-sourced): SWE intern ~$75/hr SF (Summer 2026, Extern) + housing ~$2k–$2.5k/mo + relocation
- **Work model:** Paid; Winter 2027 mid-January through April, 13 weeks; hybrid 3 in-office / 2 remote (office-based within commute radius; not remote). NYC twin posting exists — ignore for this SF apply.
- **Clearance / eligibility:** Currently enrolled in a Bachelor's or Master's in CS or related field; must graduate after the internship. Backend intern req lists prior SWE internship/co-op using Python as a screen criterion (posting still encourages applying if not all requirements are met). No citizenship/clearance gate on the JD.

## Interview Process

| Stage | Format | Notes |
| ----- | ------ | ----- |
| Resume screen | Human + Rippling ATS (rolling) | Review starts on submit; OA often follows within days |
| OA | HackerRank — 4 MCQ + 2–3 coding, Med–Hard DSA | Binding filter; bottleneck. Graph/DP/string patterns common **[directional]** |
| Live technical | 1–2 × 60 min HackerRank | Coding; full-stack reqs add web fundamentals — **this req is backend-focused, so JS/HTML/CSS is not a screen floor** |
| Behavioral | Light (interns) | Filter round (`recruiting.md` §6), not the differentiator |

**Estimated funnel:** Resume → OA → 1–2 live tech · Med–Hard · HackerRank · Light sys design (interns) · Bottleneck: OA · ~2–5% **[directional]**

## Stack & Hiring Signal

- **Languages:** JD names **Python** only (prior intern/co-op using Python). Backend-focused; do not treat JavaScript/HTML/CSS as required for this posting. Shipping stack on the compound platform is Python-heavy server-side.
- **Domains:** Backend services and APIs on a shared employee graph; product engineering (HR/IT/Finance surfaces) and platform abstractions; production ownership on a scoped intern project
- **What wins:** Python backend in bullets (prior titled intern/co-op using Python), shipped services/APIs with production ownership, DS&A fluency for the OA. Do not invent Rippling-product experience (HRIS, payroll, App Studio, Travel, Help Center). Club-ops and notebook ML fail a backend screen. OA is the elimination stage — resume still has to look like someone who already ships Python backend.
