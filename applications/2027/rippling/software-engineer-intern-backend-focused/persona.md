# Software Engineer Intern - Backend Focused - Summer 2027 at Rippling

## Role Summary

Summer 2027 Software Engineer Intern, backend-focused, 13 weeks (May/June–August/September), office-based (≥3 days/week within commute radius) in San Francisco, Seattle, or New York. Interns join a product team (user-facing or internal HR/IT/Finance surfaces) or platform engineering (“startup of startups” abstractions) and ship production backend on Rippling’s compound workforce platform — payroll, expenses, benefits, devices, and third-party apps on one employee lifecycle / employee graph. JD surface is generic backend SWE intern: prior SWE intern/co-op using Python, enrolled BS/MS CS graduating after the term, backend programming, cross-functional communication, adaptability. Company identity (`companies.md` A-tier; `company.md`) is compound HR/IT/Finance backend on a shared employee graph, not a single-product HRIS and not a JS/HTML/CSS web-fundamentals floor (that round exists on full-stack Rippling intern reqs; this posting is backend-focused). JD copy still says $1.4B+ raised; `companies.md` is authority at $16.8B Series G / ~$1.85B raised — do not treat the posting’s raise figure as current.

## Screen Criteria

- Python demonstrated **in bullets**, not Skills alone — the JD’s only named language and a prior-intern/co-op-utilizing-Python floor signal.
- Prior titled internship or co-op in software engineering (or equivalently scoped production delivery) visible on the page; Python used in that work is the strongest read of the JD requirement.
- Backend spine: server-side services, REST/APIs, data stores, deploy path — not frontend-only, not notebook ML (`resume.md` §12, backend-weighted).
- Production ownership a recruiter can size in 30 seconds (shipped API, sole-engineer delivery, before/after reliability or throughput) — maps to “full-time engineer responsibilities” and a scoped intern project with business/client impact.
- Compound-platform flavor without fabrication: multi-entity data, production APIs, or platform-shaped backend visible in the top half — never invented Rippling products (HRIS, payroll, App Studio, Travel, Help Center, corporate card).
- Cross-functional or stakeholder delivery in at least one entry — the JD names communication across departments.
- CS fundamentals on the page (DS&A coursework; software-design decisions in bullets) — the OA is Med–Hard DSA and is the funnel bottleneck.
- Class-year on page: `Expected May 2028` satisfies graduating after Summer 2027; internship term is rising-junior summer with return to school.
- Languages and backend keywords appear through use. Do not treat JavaScript/HTML/CSS as a screen floor for this backend-focused req.
- Anti-patterns: Python only on the Skills line; no titled intern/co-op (or production-equivalent) when the JD lists prior SWE intern/co-op using Python; leading with LoRA / LangGraph / agentic-AI as if this were an ML internship; GTM/quant deal-sourcing or club-ops with no engineering the role tests; frontend-only or DSP/plugin-only C++ as the lead story; invented Rippling-product experience; thin single-bullet filler that dilutes a Python-backend + production spine; JS/HTML/CSS stuffed to mimic the full-stack intern loop.
