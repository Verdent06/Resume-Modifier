Paid full-time **onsite** Software Engineering Winter Internship at Rubrik HQ, Palo Alto, CA (3495 Deer Creek Rd), **January 11, 2027 – May 7, 2027**. Comp unlisted on the JD; Levels.fyi Winter 2026 Palo Alto **$60/hr + $11K housing** **[directional]**. The intern is a full member of an engineering team, ships code, and works on one of several possible product-area projects (ML models for core functionality, eng-team tooling, new security features, or exploratory research on emerging tech) — assignment options, not exclusive. ## Screen Criteria

- Shipped frontend and/or backend software in bullets — a complete delivery path (API, UI, pipeline, or systems artifact), not a skills list and not a half-built tutorial (`resume.md` §12). Breadth across the stack plus depth in at least one layer.
- Python, C++, and JavaScript/TypeScript demonstrated inside an architectural decision, not Skills alone. Do not invent Java, Go, Objective-C, Kubernetes, Snowflake, Databricks, Copilot, or Fusion.
- Production or stakeholder-facing delivery so "write code that will ship" can be analogized — a real consumer of the work, not only solo architecture.
- Quantified impact (latency, failure rate, throughput, hours saved, scale) so "finished" can be sized.
- Concurrency, OS, or distributed-systems flavor is a plus when honest — CS-fundamentals familiarity the JD names, not a requirement to lead with kernel work.
- Differentiator is flavor, not a second spine: zero-trust / data-protection / cyber-resilience excitement is an interest filter, not a prior-AppSec or malware-research requirement. Do not lead with notebook ML because intern projects *may* include ML models.
- Anti-patterns: tutorial-grade projects; Skills-only Python/C++/JavaScript; notebook ML as the lead; club-ops without engineering; invented Java/Go/security-research; Awards padding; thin filler.
