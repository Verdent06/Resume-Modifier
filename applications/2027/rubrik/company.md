# Rubrik

Rubrik (NYSE: RBRK) is a Security and AI Operations company built around Zero Trust Data Security™. Rubrik Security Cloud (ML-powered) secures data across enterprise, cloud, and SaaS so customers can keep integrity and availability, monitor risk, and restore after attack. Rubrik Agent Cloud adds monitoring, guardrails, and undo for trusted AI-agent deployments. This intern req is generic product SWE at Palo Alto HQ — not a malware-research or ML-training seat, even though intern projects *may* include ML models, eng-tooling, security features, or exploratory research.

## Stack & Hiring Signal

- **Languages:** JD names Java, Go, Python, C++, Objective-C, JavaScript *or*. Screen for languages the candidate actually has — **Python, C++, JavaScript/TypeScript through use**. Do **not** invent Java, Go, Objective-C, Kubernetes, Snowflake, Databricks, Copilot, Fusion.
- **Domains:** Generic product SWE on a zero-trust data-security / cyber-resilience platform. Possible intern projects include ML models, eng-team tooling, security features, or exploratory research — those are assignment options, not a second doctrine track.
- **What wins:** Because the intern bottleneck is the **OA** then tech (`companies.md`; `recruiting.md` Part I §1 OA-gated), LeetCode/DS&A fluency is the real first filter. The resume still must pass the 7-second scan and hold up in the people-leader project grill: shipped systems, JD languages in bullets not Skills alone, production/debug, concurrency or systems flavor if honest (`resume.md` Part III §12 / `recruiting.md` Part III §11). Anti-patterns: notebook ML as the lead, club-ops without engineering, invented Java/Go/security-research.
