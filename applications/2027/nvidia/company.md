# NVIDIA

NVIDIA pioneered GPU-accelerated computing — CUDA, data-center GPUs, and the software stack (CUDA, cuDNN, TensorRT, networking) that trains and serves modern AI. Hardware is the brand; intern SWE seats sit across development tools, cloud/storage infrastructure, chip-design tooling, and MLOps, not a single CUDA-kernel team. `reference/companies.md` S-TIER Notes flag GPU/AI dominance and white-hot prestige with limited SWE intern seats; this 2027 posting is still a generic polyglot SWE catch-all, not a CUDA/ML research req.

## Quick Facts

- **Tier:** S-TIER — Elite / Resume Gold (`reference/companies.md`)
- **HQ / offices:** Santa Clara, CA (HQ). This req: US-CA-Santa Clara (Workday); Canada also listed on some surfaces of the same intern program.
- **Valuation / signal:** Public (NASDAQ: NVDA); GPU/AI market leader; intern SWE prestige is lottery-ticket scarce (`companies.md`: ~2–4%)
- **Product focus:** Accelerated computing — GPUs, CUDA software stack, AI training/inference platforms, developer tools, and cloud/data-center infrastructure
- **Intern comp (2027 Software Engineering Intern):** $20–$71 USD/hour (JD: position, location, year in school, degree, experience) + intern benefits
- **Work model:** Paid 12-week full-time 2027 internship; rolling review; recruiter outreach if experience fits one of many internship opportunities. This posting is for an existing vacancy.
- **Clearance / eligibility:** Must be actively enrolled in a B.S., M.S., or Ph.D. in Electrical Engineering, Computer Engineering, or a related field for the full internship duration. Anticipated graduation date (month and year) must be on the resume/CV. NVIDIA uses AI tools in recruiting.

## Interview Process

| Stage | Format | Notes |
| ----- | ------ | ----- |
| Resume screen | Human + Workday ATS | Rolling review; catch-all posting routes into Development Tools, Cloud, Tools Infrastructure, or MLOps. Grad month+year is a stated filter. |
| OA | No standard OA (`companies.md`) | Web reports (2026–27 intern guides): many SWE roles still send a HackerRank (2–3 LC-medium coding + MCQs on C/C++, OS, DS&A). Treat as team-dependent, not the doctrine default. |
| Recruiter / tech screen | Phone or coding | Fit, enrollment, language depth; coding often LC-medium in C++ or Python |
| Tech rounds | 3–4 rds total (`companies.md`) | Med–Hard live coding + CS-fundamentals (memory, threading, C++ internals); light system design; project deep-dive |
| Behavioral | Culture / ownership | Passion for accelerated computing; collaboration; return-to-school eligibility |

**Estimated funnel:** 3–4 rounds · Med–Hard · No standard OA (HackerRank reported on some SWE teams) · Light sys design · Bottleneck: tech rounds · ~2–4% (`reference/companies.md` NVIDIA row)

## Stack & Hiring Signal

- **Languages:** Java, JavaScript (Node/React/Vue), SQL, C, C++, CUDA, OOP, Go, Python, Git, Perforce — role-dependent, not all required (JD)
- **Domains:** Development tools (debug, Jenkins, OS/scheduling/virtualization coursework); cloud storage/data platforms (distributed systems, containers); tools infrastructure (Unix/Linux, Docker, Kubernetes, chip-design tooling); MLOps (GPU computing, cuDNN, TensorRT, NCCL) — placement after the screen
- **What wins:** A full-stack intern spine (`resume.md` Part III §12 / `recruiting.md` Part III §11) with JD languages shown in bullets (especially Python and C++), plus visible systems / performance / real-time / inference-adjacent depth so the page is memorable at a GPU company. Do not invent CUDA, Kubernetes, or MLOps evidence. Workday knockouts (enrollment, grad date) are absolute (`recruiting.md` §8). Bottleneck after the PDF is tech rounds, not the resume (`companies.md`).
