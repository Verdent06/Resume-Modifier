# NVIDIA 2027 Internships: Software Engineering Intern (JR2023495)

## Role Summary

A paid 12-week full-time 2027 software engineering internship (US-CA-Santa Clara; Canada appears on some program surfaces). Comp is $20–$71/hr plus intern benefits. The posting is a catch-all early-career pipeline, not a single CUDA team: recruiting may place the intern on Development Tools, Cloud, Tools Infrastructure, or Machine Learning Operations. Surface work is design / build / debug / ship software in role-dependent languages (Python, C++, JavaScript/React, SQL, Java, Go, CUDA, etc.). Company identity is GPU-accelerated computing — CUDA, data-center GPUs, developer tools, and the software that makes accelerated systems usable — not a consumer web product and not an ML-research lab seat. Resumes are reviewed on an ongoing basis; a recruiter reaches out if experience fits one of many internship opportunities. Graduation month and year must appear on the resume.

## Track Decision

- **screen_track:** full-stack (general SWE)
- **differentiator:** accelerated-computing / GPU software (systems performance, C++ depth, developer tools / cloud infra adjacency — not a CUDA-kernel or MLOps-research internship)
- **track_divergence:** true

The literal requirements test current-student status in EE/CE or related, a visible graduation month+year, and demonstrated use of one or more listed languages depending on placement. That is a general SWE screen (`recruiting.md` Part III §11; `resume.md` Part III §12), so the resume spine is full-stack: shipped applications, APIs, data systems, Python/SQL/JavaScript-family delivery, containers/CI where real. They do not name training/inference frameworks, ROS, or Kubernetes as a hard floor for every seat, so the spine is not `ai-ml` or `dev-ops`. The company-fit signal is software that has to be correct next to accelerated hardware — C++ performance/memory/concurrency, on-device or inference-adjacent systems, tools and infra that make compute usable — without fabricating CUDA, TensorRT, or cluster-scheduler internships. Lead with the full-stack spine and keep systems / C++ / performance evidence prominent and deep.

## Team & Bar

The reviewer is an S-tier GPU-company university recruiter (Workday; 3–4 rounds; Med–Hard; no standard OA in `companies.md`, HackerRank reported on some SWE teams; bottleneck: tech rounds; ~2–4%). They route a generic intern resume onto a tools, cloud, infra, or MLOps team. What wins on paper: listed languages shown inside bullets, not Skills alone; a shipped application or data pipeline with ownership and impact metrics; and enough C++/systems discipline to be believable next to GPUs. Recruiter voice is "can this person write, debug, and ship software that belongs at an accelerated-computing company?" — not "did they write CUDA kernels." Prestige is a tiebreaker (`recruiting.md` §8). Enrollment through the internship plus month+year on the resume is a stated filter. After the PDF, coding and C++/OS fundamentals are the binding filter.

## Screen Criteria

- Demonstrates JD languages through use in bullets — especially Python and C++, plus SQL or JavaScript-family (React) where the work actually used them — not Skills-list only. Java, Go, CUDA, C-as-distinct-from-C++ are named as role-dependent; absence is a gap only if the page also fails to prove real language depth another way — not a fabrication invitation.
- Shows shipped application, API, or data-system delivery (REST, ETL, databases, test/debug, production ownership, containers/CI) so Development Tools / Cloud / Tools Infrastructure routing is obvious.
- Keeps C++ systems / performance / memory / concurrency / real-time or inference-adjacent evidence visible in the top half as the GPU-company differentiator, framed as engineering tools or systems software — never as an invented CUDA, TensorRT, Kubernetes, or MLOps internship.
- Uses impact metrics (latency, cost, failure recovery, scale, hours saved) rather than vanity counts.
- Anti-patterns: claiming CUDA/Java/Go/Kubernetes/Jenkins/Ansible/Perforce the page cannot defend; a pure agentic/LLM product resume with no systems or application delivery; notebook ML without delivery; club-ops filler; burying the systems/C++ signal below the fold at a GPU company; missing graduation month+year.
