# PayPal

PayPal is a publicly traded digital-payments company whose two-sided network connects hundreds of millions of merchants and consumers across ~200 markets. Engineers ship proprietary checkout, wallet, and payout rails — PayPal, Venmo, Braintree, Xoom, Paydiant — not a thin wrapper on card networks. The US campus SWE intern is a generic full-stack seat (front-end and back-end, Java / Python / Node.js / React / SQL / REST) that may land on any product team; the company's identity is still high-scale connected payments. Prestige has declined versus peak fintech (`companies.md`); the intern program remains large and OA-gated.
