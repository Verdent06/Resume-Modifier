# Full-Stack Software Engineer Internship (Summer 2027) at Castleton Commodities International

## Role Summary

Front Office Software Engineering Intern on CCI's Global Data Science & Technology team in Stamford, CT. The intern builds software that commercial trading and analytics users actually run: Python microservices and APIs, data-visualization dashboards (Streamlit called out), cloud-native work on AWS (Kubernetes/Kafka mentioned), and DevOps hygiene (Git, Docker, Helm, CI/CD). They sit next to traders and data scientists — re-engineering pricing models, decision tools, and workflows, and helping wire ML-driven analytics into those tools. JD surface is Python full-stack for a trading desk, not a research internship. Company identity is an energy commodities merchant whose edge is a front-office analytics platform (Python, AWS, APIs, Snowflake).

## Team & Bar

CCI is Unrated in `companies.md`. Recruiter voice: technically skilled students who already write Python in real projects, can talk to commercial users, and want financial/commodity markets — not tourists applying to every intern req. Campus cycle is late July through **September 1, 11:59 pm EST**; high volume; they only email first-round invites (`cci.com/careers/students`). Eligibility window is Winter 2027 or Spring/Summer 2028 — class year on the page is a knockout. Bar is below S-tier HFT math screens and above generic C-tier intern mills: production Python + data/API shipping plus a credible markets curiosity.

## Screen Criteria

- Python proven in bullets — Pandas/NumPy-class data work and API/service delivery, not Skills-only. This is the floor language.
- Shipped internal or external tools: REST APIs, ETL/pipelines, dashboards or visualization, cloud deploy (AWS preferred). Outcome metrics beat architecture-only claims.
- Git and software-development hygiene in project context (CI/CD, Docker) — JD lists these as real work, not résumé garnish.
- Markets / trading-systems curiosity that a commercial team would believe — coursework or financial-data products help; jargon without engineering does not.
- Collaboration signal: stakeholder-facing delivery (researchers, principals, paying clients) maps to "work with the commercial trading team."
- Class-year on page: Expected graduation in Winter 2027 or Spring/Summer 2028.

## Anti-Patterns

- Screening as ML research / GenAI-agent intern because the JD mentions integrating ML analytics or because sibling DS&T tracks include ML and GenAI.
- Kubernetes, Kafka, Helm, or Snowflake named in Skills with zero honest evidence — keyword stuffing on preferred infra.
- C++/audio-DSP or robotics-CAD as the lead story for a Python front-office tools intern.
- Club-ops or coursework-only pages with no shipped API/pipeline.
- Finance-jargon padding (P&L, "prop desk") without the engineering that this req tests.
- Streamlit claimed without using it — visualization via a real dashboard library is the signal; inventing Streamlit is worse than honest React/Python viz.
