# Google

Google builds large-scale consumer and cloud products (Search, Ads, YouTube, Android, Chrome, Cloud) on shared distributed-systems infrastructure. Intern SWE seats are not a single product team: recruiting routes a generic BS intern resume onto a project, and may classify SWE vs SRE from the page. `reference/companies.md` S-TIER Notes flag STEP for sophomores and SWE for juniors; this 2027 posting is the BS SWE intern catch-all, not STEP and not the MS intern req.

## Quick Facts

- **Tier:** S-TIER — Elite / Resume Gold (`reference/companies.md`)
- **HQ / offices:** Mountain View, CA (HQ). This BS intern req lists a large US office set including Mountain View, NYC, Seattle, Austin, Cambridge, Chicago, and many others; intern must be located in the United States for the duration.
- **Valuation / signal:** Public (NASDAQ: GOOGL); strongest intern brand; intern SWE prestige is lottery-ticket scarce (`companies.md`: ~4–5%)
- **Product focus:** Ads, Chrome, Android, YouTube, Search, Cloud — intern works on one specific project critical to Google’s needs (design, test, deploy, maintain); SRE intern path also exists (reliability/performance at scale)
- **Intern comp (2027 Software Engineering Intern, BS):** US $98,000 – $131,000 (USD) + 0% bonus target (JD)
- **Work model:** Paid Intern & Apprentice; 12–14 weeks; Summer 2027; rolling review; anticipated close September 25th, 2026 (may close earlier if projects fill); responses can take 90+ days; apply early
- **Clearance / eligibility:** US posting. Pursuing a Bachelor's (or post-secondary/training) with software-development focus. Preferred: attending a US degree program, available full-time 12 weeks outside term, returning to a degree program after the internship. English proficiency required. JD application materials: resume/CV (PDF preferred) plus current unofficial or official transcript in English (Degree Status = “Now attending”).

## Interview Process

| Stage | Format | Notes |
| ----- | ------ | ----- |
| Resume screen | Human + Google Careers ATS; referral-heavy | Rolling; host-match later uses the resume to route SWE vs SRE and team. JD warns 90+ day responses. |
| OA | None (`companies.md`) | Web reports for some 2026 US intern pipelines describe a timed coding OA / hiring assessment before the live loop. Treat as a possible extra filter, not the doctrine default. |
| Technical rounds | 2–3 rds · Easy–Med · Google Docs (no IDE) | DS&A; intern loop has no systems design (`companies.md`). Language of choice. |
| Host match | Team / hiring-manager conversations | Bottleneck. After technical pass, matching to a real intern project; unmatched candidates do not convert. |
| Behavioral | Filter, often folded into host-match / recruiter | Collaboration, returning-to-school, Googliness — not the differentiator (`recruiting.md` §6). |

**Estimated funnel:** 2–3 rounds · Easy–Med · Google Docs (no OA) · No sys design · Bottleneck: host match · ~4–5% (`reference/companies.md` Google row)

## Stack & Hiring Signal

- **Languages:** JD minimum is two or more of C, C++, Java, JavaScript, Python (etc.); preferred is three or more of C, C++, C#, Java, JavaScript, Go, Python or similar. Host match is polyglot, not one stack.
- **Domains:** Preferred experience areas include AI/ML, infrastructure, web application development, Unix/Linux, mobile, distributed and parallel systems, information retrieval, NLP, networking, large software systems, security. Placement is after the screen.
- **What wins:** A full-stack intern spine (`resume.md` Part III §12 / `recruiting.md` Part III §11) with JD languages shown in bullets (especially Python and C++, plus a JS-family language), plus visible distributed / large-system / production-shipping depth so a host can imagine a Google project. Do not invent Java, Go, mobile, or Google-internal infra. Referral plus early apply matter (`recruiting.md` §4, §8). Binding filter after the PDF is Google Docs DS&A plus host match, not the resume.
