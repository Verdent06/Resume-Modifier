# Sentry

Sentry is a developer-first application monitoring platform — error tracking, tracing, performance monitoring, and session replay that catches crashes and slow paths in production before users report them. Founded in 2012 by David Cramer as an open-source side project for Python/Django apps, `getsentry/sentry` is now one of the most-used open-source developer tools (44k+ GitHub stars) with SDKs across 100+ languages and frameworks (JavaScript/TypeScript, Python, Ruby, Go, Java, React, Next.js, Django, Flask). The stack is a Python/Django backend and a React/TypeScript frontend; the product processes hundreds of billions of events monthly for 130,000+ organizations and ~4M developers. Sentry is building its "AI-native future" (launched MCP Server Monitoring in 2025) and runs a hybrid open-source + self-serve SaaS model, so interns contribute to public open-source code that real developers depend on daily.

## Stack & Hiring Signal

- **Languages:** Python (Django backend), JavaScript/TypeScript (React frontend); polyglot SDK surface (Go, Ruby, Java, Rust)
- **Domains:** Developer tooling, observability/monitoring, open source, distributed event ingestion, AI-native developer workflow
- **What wins:** Real code shipped to production for real users; comfort with GitHub branching/PRs/code review; a dynamic language (Python or JS/TS) demonstrated in shipped work, not just a Skills line; end-to-end project ownership (spec → build → test → ship); genuine open-source or public-GitHub footprint; using AI tooling as part of the engineering workflow. Sentry explicitly rejects the HackerRank-style screen, so a defensible, narratable full-stack product and a live GitHub matter more here than raw LC volume.
