# Software Engineer, Intern (Summer 2027) at Sentry

## Role Summary

A 12-week Summer 2027 internship where the intern is matched to a Product or Infrastructure Engineering team and owns a project end-to-end — tech spec, scoping, implementation, testing, and shipping to production for a codebase used by millions of developers. The JD surface is a general SWE intern (enrolled in CS or related; proficient in Python, JavaScript, or a similar dynamic language; solid DS&A; comfortable with GitHub branching/PRs/code review; team collaboration; picks up new languages fast; at least one prior internship). The company identity is open-source developer tooling and observability — a Python/Django backend and React/TypeScript frontend, contributed to public open source daily, with AI tooling used as part of the real engineering workflow. Explicitly "No HackerRank": the screen rewards defensible, shipped engineering over algorithm-puzzle volume.

- **screen_track:** full-stack (general SWE requirements — production ownership, dynamic-language proficiency Python/JS, APIs, data, deploy, end-to-end shipping)
- **differentiator:** open-source developer tooling / observability — Python + JavaScript/TypeScript full-stack, real production shipping, and AI-native workflow fluency
- **track_divergence:** false

The differentiator does not pull toward a different track; it sharpens emphasis within full-stack toward Python/TS breadth, production-to-real-users evidence, open-source/public-GitHub footprint, and AI-tooling-in-the-workflow signal. The single full-stack track grounds ordering, lead entry, and skills.

## Team & Bar

Sentry is a ~$3B, ~418-person developer-tools scale-up with an unusually strong engineering brand and a self-serve open-source funnel — a human reads the PDF early (Ashby ATS), so resume signal carries real front-end weight, unlike an OA-gated big-tech pipeline. The recruiter voice: an intern who already ships real code to production, can own a scoped project with real (not scheduled) mentorship, is fluent with GitHub and code review, and cares about craft — not a tutorial-repo hobbyist and not an algorithm-only competitor. Because the screen is explicitly "No HackerRank," the binding evidence is a defensible product and a live GitHub, plus a prior internship. Hybrid San Francisco with housing/relocation covered; enrollment and return-to-school eligibility are binary gates; the candidate is US work-authorized without sponsorship.

## Screen Criteria

- Production shipping with measurable impact — an API, pipeline, or app deployed to real users, narrated as an owned end-to-end project (spec → build → test → ship), not a tutorial clone.
- Python and/or JavaScript/TypeScript demonstrated inside bullets (the decision that justified the tool), not asserted in a Skills line alone — a dynamic-language floor signal at a Python/Django + React/TS shop.
- Full-stack breadth with depth in at least one layer — frontend framework, backend service/API, a datastore, a cloud/deploy path, and ideally a CI step, with trade-offs the candidate can defend.
- GitHub / open-source / public-code footprint that a recruiter can click — live repos beat a skills list here specifically.
- AI-tooling or agentic/LLM workflow evidence as a plus when tied to a shipped pipeline or eval — reads as "builds in the AI-native middle," not a research-only pivot.
- Class-year on page shows current enrollment (`Expected May 2028` satisfies Summer 2027 intern eligibility; rising senior returning to school after).
- Prior internship / hands-on titled experience visible — the JD names it as a requirement.

## Anti-Patterns

- Skills-list Python/JavaScript with zero bullet evidence at a company where those are the core stack.
- Tutorial-grade or notebook projects with no deploy path, no users, and no defensible trade-offs.
- Pure-frontend or pure-quant/GTM framing with no backend/production/systems depth as the lead.
- Agentic/LLM buzzwords without pipeline architecture, metrics, or delivery.
- Thin single-bullet filler entries that dilute a strong production + full-stack spine.
- No visible GitHub/open-source footprint for an open-source-first employer.
