## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has (**Python**, **TypeScript**, **SQL**). Keyword-through-use in bullets, not Skills-only (`resume.md` §2). JD names no languages — do **not** invent Java, Spring, Copilot, Fusion, Snowflake, Databricks, or Tableau.
- Shipped full-stack or backend software: REST/APIs or services, a real web surface, a persistence decision, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Data-platform / pipeline analogs match "data platforms."
- SDLC through use: design → build → **test** → **deploy** → improve, not coursework-only. Automation and Git/CI in project context beat Skills-line stuffing.
- Agile / stakeholder delivery to real users or clients.
- Finance-adjacent or payments/banking flavor on that spine: production APIs, financial or regulated-data workflows, scoring/research tools for financial users — memorable here without replacing the SWE spine.
- AI-enabled tools / ML *concepts* as plus (productivity/concept flavor), never as the lead story for a generic SWE intern req, and never invented Copilot metrics.
- Class-year on the page: `Expected May 2028` satisfies Rising Senior graduating Dec 2027–May 2028.

**Anti-patterns:**

- Skills-line Java / Spring / Copilot / Fusion / Snowflake / Databricks / Tableau with zero bullet evidence (fabrication smell; none of these are in this JD as required languages).
- Agentic-AI / LoRA / notebook-ML lead as if this were the Data Analytics and AI intern sibling (JR0309690) or an ML-research seat.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/cloud/data/full-stack SWE.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + banking/payments spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Confusing this employer with Fidelity Investments.
