# C.H. Robinson

C.H. Robinson (Nasdaq: **CHRW**) is a global third-party logistics (3PL) and freight-brokerage company founded in 1905. FY2025 total revenues were **$16.2B** (10-K). Q2 2026 investor materials: **37 million shipments**, 75k customers, 450k contract carriers, and **$23B** freight under management (this intern JD still copies **19 million shipments** / a ~$22B figure — lead with the 10-K / investor numbers). Flagship TMS is **Navisphere**; ~800 technologists. **Lean AI** automates quoting-to-appointment. This intern (Workday **R49323**) is a generic full-stack seat on proprietary systems used by thousands of users — HTML/CSS/SASS, JavaScript, React/Redux, REST, CI/CD — with a C# .NET Web API / SQL Server / Jenkins + GitHub shop. **Not** a C#-only knockout and **not** an ML-research intern. JD also asks for curiosity about production-grade automation and autonomous agents in an enterprise environment.
