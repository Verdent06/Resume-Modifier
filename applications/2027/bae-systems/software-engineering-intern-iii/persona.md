# Software Engineering Intern III, Summer 2027 (Onsite) at BAE Systems

## Role Summary

A Summer 2027 onsite software internship in San Diego on a BAE Systems Electronic Systems team, inside the nationwide LEAP intern program. Daily work is general software engineering: write new code, resolve critical problems, and improve system stability and resilience. The JD surface is a polyglot intern SWE req — CS/CE/SE (or other coding degree), data structures and OOP, and proficiency in **one of** Java, C++, C#, Python, or JavaScript — plus a long preferred list spanning Angular/React, Spring/Docker, AWS/Git, PostgreSQL/Redis, and optional PyTorch/GIS. The company's memorable identity is mission-critical defense electronics: software that has to stay up, not hardware technician work and not an ML-research internship.

The reviewer is a defense-electronics recruiter/engineer at a B-tier traditional prime (peer to Northrop / L3Harris: 2–3 easy rounds, no standard OA on this posting, bottleneck = resume, ~15–20% offer band). ## Screen Criteria

- Demonstrates at least one JD language **through use in bullets** (Python, C++, or JavaScript/TypeScript). Java and C# are listed alternatives, not a fabrication target — honest absence beats a Skills-only lie.
- Shows shipped software with real users or a release artifact, not tutorial-grade coursework.
- Makes system stability / resilience / critical-problem solving visible: fault tolerance, failure recovery, deterministic constraints, or a diagnosed-and-fixed production defect with a before/after number.
- Covers preferred stack through use where it exists (Angular or React, Docker, AWS, Git, PostgreSQL/Redis) rather than stuffing unused tools.
- Uses impact metrics (failure rate, latency, throughput, scale) rather than vanity counts or club-ops filler.
- Anti-patterns: inventing Java, Spring, Kubernetes, GIS, hardware, or an existing clearance; leading as an ML-research or PE-deal-sourcing intern; Skills-list keyword stuffing with no backing bullet; notebook ML without delivery; a resume that reads purely agentic-LLM product with no reliability/systems evidence.
