# Vital Lyfe

Vital Lyfe builds personal water-making hardware — portable systems that turn naturally occurring sources, including seawater, into purified water where infrastructure cannot. Founded ~2024 by former SpaceX engineers Jon Criss and Andrew Harner. The intern software work is not the purification stack itself: it is the internal tools, integrations, dashboards, and backend/cloud that let engineering and operations see and run manufacturing as they spin production up from scratch.

- **Languages:** JD required: **Python or TypeScript** (at least one). Nice: React (or similar frontend), SQL / structured data / dashboards, AWS or cloud, live backend. Do **not** invent IoT, MES, Grafana, Node, Next, Snowflake, Databricks, Tableau, Copilot, Fusion.
- **Domains:** Internal tools for production/manufacturing visibility; integrations and scripts that keep data reliable; operational dashboards; backend and cloud infrastructure; test and debug next to senior engineers. Hardware-software intersection is the company, not a ROS/firmware intern bar.
- **What wins:** Python and/or TypeScript through use in bullets; a shipped API + datastore + deploy path; a dashboard or operator-facing UI; named debug on a live system; ops/data-reliability evidence so manufacturing-tooling work looks like real product.
