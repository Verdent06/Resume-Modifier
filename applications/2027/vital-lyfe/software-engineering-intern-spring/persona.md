# Software Engineering Internship - Spring 2027 at Vital Lyfe

Recruiter lens shared by the writer and grader. Abstract bar signals only — no candidate entry names, no include/omit table.

## Role Summary

A paid Spring 2027 software engineering intern on a small consumer-hardware team spinning manufacturing up from scratch. The intern builds internal tools that give engineering and operations real-time visibility into production workflows, writes integrations and scripts that keep data reliable across systems, designs operational dashboards, and helps with backend and cloud infrastructure — then debugs, tests, and ships next to senior engineers. JD *requirements* are generic intern SWE: programming fundamentals, Python or TypeScript, APIs / web applications / cloud familiarity, ownership, and comfort at a software-hardware intersection. Company identity is **water-autonomy hardware + manufacturing-ops software** — not a consumer CRUD shop, not firmware/ROS, and **not** an ML-research rotation.

## Track Decision

- **screen_track:** `full-stack`
- **differentiator:** manufacturing-ops / water-autonomy hardware
- **track_divergence:** true

Required qualifications test general product/ops SWE (`resume.md` Part III §12; `recruiting.md` Part III §11): one modern language (Python or TypeScript), APIs or web apps or cloud, ownership, debug. They do not name ROS, perception, training/inference, or SRE as the filter, so the spine is not `robotics`, `ai-ml`, or `dev-ops`. The differentiator is Vital Lyfe's C-tier hardware identity (`companies.md`: portable water-making systems; manufacturing from scratch; internal production tools). The resume leads with a full-stack spine (API + datastore + dashboard or operator-facing UI, ideally a deploy/test step) **and** keeps ops/data-reliability or water-adjacent operational work prominent and deep. It does not collapse into notebook ML, PE deal-sourcing as the whole page, or hobby-audio as the identity.

## Team & Bar

The reviewer is a C-tier early-stage hardware screener on Ashby (`companies.md`: human-read PDF, no published OA, no intern system design, bottleneck: resume + Torrance 5-day onsite, ~15–25% **[directional]**). With no OA, the PDF is the gate (`recruiting.md` intern funnel; startup Greenhouse/Lever-class). Recruiter voice: can this intern ship internal tools and data plumbing other people depend on — APIs, scripts, dashboards, a live backend — with enough ops seriousness to sit next to manufacturing, not a tutorial CRUD app and not an LLM intern. Strong signals: JD languages demonstrated inside bullets (Python and/or TypeScript; React if honest); shipped software with real users or a live product; APIs and a database through use; named debug; metrics that size reliability, time saved, or scale. Prestige is a tiebreaker, not a gate (`recruiting.md` §8). Torrance onsite is a form knockout, not a resume line. No class-year gate on this JD; `Expected Month Year` must still parse.

## Screen Criteria

- JD languages the candidate actually has (Python, TypeScript) demonstrated **in bullets**, not Skills alone. SQL, React, and AWS through use match nice-to-haves; inventing IoT, MES, Grafana, Node, Next, Snowflake, Databricks, Tableau, Copilot, or Fusion is worse than omitting them.
- Full-stack / ops-tools spine visible: backend API + datastore + a dashboard or operator-facing UI, with a deploy or test path the candidate can narrate (`resume.md` §12).
- Differentiator visible in the top half: operational data reliability, live backend, manufacturing-adjacent tooling, or honest water-domain work — without turning the page into a PE-sourcing packet or inventing a hardware/manufacturing internship.
- Impact metrics that size time saved, reliability, throughput, or user-facing outcomes — the intern debugs and ships next to senior engineers.
- Production or stakeholder-facing delivery so internal-tooling work looks like real product, not a class assignment.
- Anti-patterns: inventing IoT / MES / Grafana / Node / Next / Snowflake / Databricks / Copilot / Fusion / Tableau; Python or TypeScript only in Skills; leading with agentic/LLM or LoRA-research framing as if this were an AI intern; a pure consumer-web page with zero ops/data/dashboard signal at a manufacturing-hardware company; club-ops filler; metric-free "built X" claims; two-page or ATS-broken formatting.
