# Viget

Viget is an independent digital product agency — designers, engineers, and strategists who brand, design, and build products and platforms for clients. Legal name **Viget Labs, LLC**; incorporated **27 December 1999** (Andy Rankin); co-founder and CEO **Brian Williams**. Flagship craft is Ruby on Rails application development plus JavaScript/React client-side work, with code review, automated testing, and pair programming as the shop culture. Featured work includes Flipboard, NationalParks.org, and SnapAttack; the Boulder office also cites Cheyenne Mountain Zoo, Hippo Health, and Craig Hospital. ## Stack & Hiring Signal

- **Languages:** JD Application Developer track: **Ruby on Rails, or a similar web framework in Python or Elixir**. JavaScript/React is the sibling JS-intern track, not this req. HTML/CSS is the UI-intern track. Screen on languages the candidate actually has — **Python** (Flask/FastAPI analog to Rails) plus TypeScript/React/Angular through use. Do **not** invent Ruby, Rails, or Elixir.
- **Domains:** Web application development; TDD (write tests before code); pair programming; designer collaboration; client-meeting exposure; intern personal project that mirrors client work.
- **What wins:** Resume-first Lever screen (`recruiting.md` intern: knockouts, then the PDF, then a human-read video). Evidence of a shipped web app (REST + persistence + deploy) with a metric; Python web-framework analog in bullets not Skills-only; UI work that can sit next to designers; stakeholder- or client-scoped delivery. Honest absence of Ruby/Rails/Elixir is correct — stuffing them is a fabrication smell (`resume.md` §8). Authentic, specific essays and a practiced ~2 min video — Viget explicitly screens out AI-produced submissions.
