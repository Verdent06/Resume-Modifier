## Screen Criteria

**Pass signals (abstract):**

- JavaScript-family through use in bullets (`resume.md` §2 keyword-through-use). TypeScript / Angular / React covering the preferred JavaScript line. **Do not invent Java or Jira.**
- Shipped full-stack or backend software: REST/APIs or services, persistence, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12).
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an Easy–Med coding/tech talk if invited.
- Bank-IT / GTS flavor on that spine: production APIs, financial or messy/regulated-data workflows, reliability-minded delivery — memorable here without replacing the SWE spine.
- Applied-AI / ML **interest** visible (product, inference, or agentic workflow), never as a notebook-ML or LoRA-research lead for a generic GTS SWE co-op.
- Class-year and GPA on the page: `Expected May 2028` and GPA 3.66 satisfy May 2028 preferred + 3.2 preferred.
- Modern practices through use: Git, tests or CI, stakeholder or production delivery.

**Anti-patterns:**

- Invented Java, Jira, Snowflake, Databricks, Copilot, Fusion, or Tableau.
- Invented core-banking, payments-rail, or TD-platform claims because the company is a bank.
- Agentic-eval / LoRA / notebook-ML as the first-pass identity (AI is required *interest*, not an ML intern seat).
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests generic SWE + bank-IT + AI interest.
- Skills-only JavaScript with zero bullet evidence; Skills-line Java with zero bullet evidence (fabrication smell).
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + bank-IT spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
