# 2027 Summer- Software Engineer Intern at CHAOS Industries

## Role Summary

A paid, in-person, 12-week Summer 2027 software engineering internship in El Segundo, CA (Greenhouse; API office Los Angeles). The intern writes firmware that runs on sensor nodes and the software that keeps those nodes synchronized — real-time work under timing, power, thermal, and radio constraints. Project buckets on the posting also include developer experience for CHAOS engineers, scalability and reliability of platforms, and Storage and Data Infrastructure. The JD surface is generic SWE: data structures, storage systems, cloud infrastructure, front-end frameworks, and working proficiency in C/C++, Java, Python, or JAX, plus embedded exposure and willingness to work on hardware in a group. Company identity is defense CDN™ — coherent distributed sensing — so the memorable signal is real-time / embedded-adjacent systems discipline, not a consumer web app.

## Screen Criteria

- JD languages shown through use in bullets — C++ and/or Python at minimum — not only on the Skills line. Java and JAX are named; absence in bullets is a gap only if the page also fails to prove the or-list another way. Do not treat Skills-only C or invented firmware as proof.
- Broad SWE fundamentals on the page: APIs or services, storage/data, cloud or deployment, and some frontend/client work (`resume.md` §12 keywords-through-use).
- Differentiator visible in the top half: real-time constraints, C++ systems, lock-free or deterministic resource discipline, hardware-adjacent work — without turning the resume into a fabricated MCU/RTOS/firmware internship.
- Embedded exposure as the JD means it: coursework, projects, competition teams, or internships that touch hardware-adjacent or hard-real-time software. A competition-team or group-built systems project counts; club-ops membership does not.
- Metrics that size real outcomes (latency, failure recovery, cost, throughput, scale) — reliability and constraints are the job, not a nice-to-have.
- Ownership and collaboration via shipped systems and stakeholder or team delivery — the JD asks for group work on embedded-plus-hardware, not a lone tutorial.
- Anti-patterns: Skills-only polyglot stuffing; notebook ML or JAX-shaped claims with no inventory; a consumer-SaaS page with zero systems/C++ signal at a sensor-sync company; metric-free architecture claims; inventing firmware, oscilloscope, ROS, Java, or C-as-C; club-ops filler.
