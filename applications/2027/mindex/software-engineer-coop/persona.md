## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has. JD names Java, Angular, Oracle, OpenShift, Python, and/or ASP.NET as a familiarity or-list — **do not invent Java**. Keyword-through-use for Python / TypeScript / SQL / Angular / REST / Git / Docker in bullets, not Skills-only (`resume.md` §2).
- Shipped full-stack or backend software: REST/APIs, a real frontend (Angular preferred; React acceptable), a persistence decision (SQL/Postgres), and deploy/CI or tests tied to an outcome (`resume.md` §12).
- Production debug analog: a user-facing failure, investigation, fix, witness metric — maps to the JD's debugging + test-automation + working-software lines.
- Prior co-op or client-delivery title (the JD's "prior Co-op experience" or-clause) with stakeholder/Scrum-adjacent scoping.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an easy practical screen if one is issued.
- Class-year on the page: `Expected May 2028` — honest junior standing for a Jan–Aug 2027 co-op.
- Applied AI only as tool-use humility if present at all — **not** ML-research, LoRA, or notebook-only modeling (`recruiting.md` §13 applied vs research split).

**Anti-patterns:**

- Skills-line Java / Oracle / OpenShift / ASP.NET / C# / Copilot with zero bullet evidence (fabrication smell at a Java/Oracle shop).
- Invented SchoolTool, ClearTrack, MTSS Edge, or NY-district SIS ownership.
- ML-research / LoRA / "research assistant" lead as if this were a GenAI-research co-op. The JD's AI line is Copilot-class tooling ethics, not publications.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests Angular, REST, SQL, debug, and Agile delivery.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + production-debug spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Answering the Rochester boolean as if currently based there when the address is Michigan.
