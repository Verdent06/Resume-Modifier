# Ibotta

Ibotta (NYSE: **IBTA**) is a performance-marketing / digital-promotions platform: CPG brands deliver offers through the Ibotta Performance Network (IPN) and pay when campaigns convert. The JD cites 200 million+ consumers and $2.6 billion+ in shopper earnings since 2012; it was Colorado's largest tech IPO. Founded 2012, headquartered in Denver. Engineering on this intern req is consumer-scale product SWE — features used by millions, AWS daily, testing/CI/CD, REST/microservices, databases — not an ML-research seat and not promotions-domain ownership as a knockout.

- **Languages:** JD names **Python, Java, Ruby, Javascript, Typescript** as *exposure*. Screen for proof in languages the candidate actually has — **Python / TypeScript / SQL through use**. Adjacent FT SWE names TypeScript/Java/Kotlin/Node/React + SQL/NoSQL + AWS serverless/Terraform — company intel, not intern knockouts
