## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has. JD names Python, Java, Ruby, Javascript, Typescript as *exposure* — **do not invent Java, Ruby, or Javascript**. Keyword-through-use for Python / TypeScript / SQL / REST / AWS / Git / Docker / GitHub Actions in bullets, not Skills-only (`resume.md` §2). Include every JD-listed language the candidate possesses in Skills (Python, TypeScript).
- Shipped full-stack or backend production software: REST/APIs or services, a real user or stakeholder, a persistence decision, and deploy/CI (Docker / AWS / GitHub Actions) tied to an outcome (`resume.md` §12). "Features used by millions" is the JD's intern bar — analog is shipped-to-real-users, not a user-count claim.
- Testing and CI/CD through use: pytest / eval harness / a named production defect with a before/after, plus GitHub Actions (or equivalent) on a real pipeline — the honest analog; do not invent Jenkins.
- AWS through use in a delivery bullet (EC2, S3) — the JD's daily infrastructure — not a Skills-only cloud line.
- Database design/query through use (SQL, Postgres, or equivalent) tied to a decision.
- AI as *flavor on a product spine*, never as the first-pass identity and never invented Copilot: only if a bullet honestly describes AI-assisted product/testing work. This is not an ML intern.
- Microservices / distributed architectures only if a bullet honestly supports workers, queues, or independently deployed services — do not invent service-mesh.
- Collaboration analog: code review, design discussion, stakeholder-scoped delivery — not a Scrum-cert line.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an Easy–Med coding assessment if one is issued.
- Class-year on the page: `Expected May 2028` — honest junior standing; satisfies the Juniors must-have.

**Anti-patterns:**

- Skills-line Java / Ruby / Javascript / Kotlin / Node.js / Snowflake / Databricks / Copilot / Fusion / Tableau with zero bullet evidence (fabrication smell).
- Invented Ibotta, IPN, CPG promotions, cash-back, or retailer-network ownership.
- Invented microservices architecture because the JD named the concept.
- Routing the page as DevOps/SRE (homelab, Terraform, Kubernetes) because AWS and CI/CD are listed, or as ML-research (LoRA, publications, notebook `model.fit()`) because AI tools are listed.
- Hard-real-time C++/audio-DSP as the *first-pass identity* when the role tests product-team SWE, REST, AWS, testing, and CI — systems depth can support, not lead, a promotions-platform screen.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a production-app spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Keyword stuffing REST/CI/CD/AWS/AI in Skills with no supporting system.
