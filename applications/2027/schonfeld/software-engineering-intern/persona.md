# 2027 Software Engineering Intern at Schonfeld

## Role Summary

Ten-week NYC onsite SWE intern on Schonfeld Technology. The intern designs, develops, deploys, and supports applications and platforms in an Agile team, writing software that improves functionality, performance, stability, efficiency, and scalability of the research and trading platform. Assignment is **Treasury Technology** or **Compliance Technology** — financing/collateral/margin systems or intraday surveillance / regulatory reporting — not a PM seat and not a quant-research internship. The JD surface is generalist intern SWE: technical/quantitative degree, demonstrated engineering (internship, competition, or publication), a language such as C++ / Java / Python, basic Git and databases, ownership, and interest in capital markets. Finance experience is a plus, not a requirement; the firm will teach the business.

## Track Decision

- **screen_track:** full-stack (general SWE — the JD requirements literally test design/develop/deploy, a language from C++/Java/Python, Git, databases, Agile)
- **differentiator:** multi-manager hedge fund / research-and-trading platform (Treasury + Compliance tech — performance, stability, scalability on internal trading-adjacent systems)
- **track_divergence:** false — the differentiator is flavor on a general-SWE spine, not a second track. The screen still reads as general SWE (`reference/recruiting.md` III §11, `reference/resume.md` III §12). Do not re-target to ai-ml research, HFT matching-engine claims, or DevOps-only infra.

The spine is general SWE: ship real, defensible software; C++ and Python (Java is named but not exclusive) proven in bullets; Git and a database through use; DS&A for a timed OA. The differentiator is production platform work plus honest markets curiosity — kept prominent, without becoming an ML-research page or a fake trading-desk page.

## Team & Bar

Schonfeld is B-TIER (`reference/companies.md`) — multi-manager hedge fund with A-band intern cash ($125–145k annualized), not Citadel/HRT prestige. Recruiter voice (Greenhouse 8180089): students who already ship, can interview in C++ or Python, know Git and a database, and care about capital markets without faking a desk. Campus recruiting (Jennifer Kaplan) screens for structured problem-solving, intellectual humility, and attention to detail. Class-year on the posting is “student pursuing a degree”; Greenhouse asks whether the candidate graduates summer/fall 2027 — Expected May 2028 is **No**. Prior finance is not required.

## Screen Criteria

- C++ **and** Python demonstrated in bullets, not Skills-alone — they are the honest pair from the JD language list. Inventing Java is worse than omitting it.
- Git and a **database** through use (SQL, Postgres, or a DAL) — named floor on the posting, not a Skills token.
- Shipped software with ownership: internships, a live product, or a release-ready systems project — matches “demonstrated software engineering skills” and “strong ownership.”
- Performance / stability / efficiency / scalability visible somewhere: latency, throughput, fault-tolerance, or a real-time constraint — the research-and-trading-platform differentiator.
- Markets curiosity on an engineering spine: financial-data systems, CS + economics coursework — not jargon and not a fabricated trading internship.
- CS fundamentals (DS&A, stats) visible for a timed OA; a live GitHub backing the claims.
- Class-year on page shows a current student (Expected May 2028). Do not imply a summer/fall 2027 graduation.

## Anti-Patterns

- Re-targeting to an ML-research / LoRA / agent-pipeline lead because a financial-research project exists — this is a general-SWE intern on Treasury or Compliance tech.
- Claiming or implying a **trading-desk internship**, OMS/EMS authorship, or Java the candidate cannot interview in.
- All-CRUD / all-web-app page with no systems-performance or production-ownership signal.
- Git or databases named in Skills with zero bullet evidence.
- Finance-jargon padding (P&L, “prop desk,” invented securities-lending work) without the engineering the req tests.
- Thin single-bullet filler that dilutes a strong shipping + C++ + database spine.
- Snowflake, Databricks, Copilot, Tableau, Fusion, or Sentry — not in inventory and not on this JD.
