# Internship: Full Stack Software Engineer at Revel

## Role Summary

A paid Summer 2027 (June–August) on-site internship in Los Angeles or San Francisco. The intern builds the software interfaces and services hardware operators use: browser-based UIs in React and TypeScript/JavaScript, backend services and APIs, and data flows from physical hardware through backends into engineer-facing apps. Work includes greenfield product, tests, cross-stack debugging, and code review next to experienced engineers and operators. JD *requirements* are generic full-stack intern gates: enrolled CS/CE (or related), rising junior or senior graduating 2027 or 2028, JS or TS plus React familiarity, basic backend/APIs/databases/web services, debugging, UX attention, ITAR US person. Company identity is **hardware test and command/control** — RevelTest, RevelC2, RevelCode; SpaceX-founded; aerospace / defense / energy / automotive / manufacturing — not a consumer CRUD shop and not an ML-research rotation.

## Team & Bar

The reviewer is a B-tier hardware-control startup screener on Ashby (`companies.md`: human-read PDF, no published OA, no intern system design, bottleneck: resume, ~5–10% **[directional]**). With no OA, the PDF is the gate (`recruiting.md` intern funnel; startup Greenhouse/Lever-class). Recruiter voice: can this intern ship a browser UI and a backend service other people depend on, with enough systems seriousness and UX taste to belong next to operators running critical hardware — not a tutorial CRUD app, not a notebook-ML intern. Strong signals: JD languages demonstrated inside bullets (TypeScript/React or honest JS-family UI; Python for backend delivery; C++ for systems/real-time depth); shipped end-to-end software with real users; APIs and a database through use; live-data, real-time, or event-driven adjacency; metrics that size latency, reliability, or scale. Prestige is a tiebreaker, not a gate (`recruiting.md` §8). ITAR US person is a binary apply-form knockout, not a resume line. Class year on the page must read as graduating 2027 or 2028 (`Expected Month Year`).

## Screen Criteria

- JD languages the candidate actually has (TypeScript, Python, C++) demonstrated **in bullets**, not Skills alone. JavaScript as a Skills label is not required when TypeScript/React/Angular is the honest through-use signal; do not relabel TypeScript as JavaScript. Rust, Node.js, and Next.js are bonus-or-similar — inventing them is worse than omitting them.
- Full-stack spine visible: browser UI (React or honest JS-family) + backend/API + datastore, with trade-offs the candidate can narrate (`resume.md` §12).
- Differentiator visible in the top half: real-time constraints, systems/performance discipline, live-data visualization, or hardware-adjacent rigor — without turning the page into a hobby-audio specialist packet or inventing a hardware-control internship, ITAR work, or a clearance.
- Impact metrics that size latency, reliability, throughput, or user-facing outcomes — the intern debugs across frontend, backend, and data systems.
- Production or stakeholder-facing delivery so operator-tooling work looks like real product, not a class assignment.
- Anti-patterns: inventing Node.js, Next.js, Rust, Snowflake, Databricks, Copilot, Fusion, Tableau, a hardware internship, or a clearance; React/TypeScript only in Skills; leading with agentic/LLM or LoRA-research framing as if this were an AI intern; a pure consumer-web page with zero real-time/systems/hardware adjacency at a C2 company; club-ops filler; metric-free "built X" claims; two-page or ATS-broken formatting.
