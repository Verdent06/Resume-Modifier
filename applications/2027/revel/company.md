# Revel

Revel (Revel Software Corp.) builds a unified software platform for hardware test and command/control — RevelTest (design and run hardware tests), RevelC2 (facility-wide / high-availability industrial command and control), and RevelCode (a compiled, runtime-safe hardware-control language). The stack is a browser-based operator interface, a specialized language for hardware control, and a high-performance runtime, sold into aerospace, defense, energy, automotive, and manufacturing. Founded by SpaceX veteran Scott Morton; team from SpaceX, Anduril, and Palantir. Customers named on revel.io include Impulse Space, Astro Mechanica, Gravitics, and Orbital Operations. Not Revel nightlife and not Revel fintech.
