# Backend Developer Intern at Eulerity

## Role Summary

Summer 2027 backend internship (May–August, hybrid, NYC tri-state, ≥20 hrs/week, $17–$19/hr) at a small NYC martech company building an agentic marketing operating system for multi-location brands. The intern develops, tests, and maintains backend services — using AI coding agents to accelerate the work — ships features from design to deployment, prototypes product ideas with AI tooling, collaborates on releases, and helps with documentation and support. The JD surface is generic backend SWE plus mandatory Java and hands-on coding-agent fluency. Eulerity's identity is marketing automation: unifying paid, organic, listings, reputation, and call tracking in one agentic stack.

## Track Decision

- **screen_track:** full-stack
- **differentiator:** marketing-automation / agentic-marketing (Java services + AI tooling)
- **track_divergence:** true

Requirements literally test backend services, APIs, Java, and AI-agent-assisted engineering — not ML training, not robotics, not DevOps-as-SRE. That is a full-stack/generic-backend intern screen. The company-fit signal is the martech / agentic-marketing OS: production services that automate marketing workflows and evidence of LLM/agent frameworks or AI-assisted product development. The resume spine is backend/API delivery; agentic-product and marketing-automation-adjacent systems stay prominent in the top half rather than buried.

## Team & Bar

The reviewer is a small NYC SaaS hiring intern on a Greenhouse posting. Funnel is resume-first (`recruiting.md`: startups/mid-size, human reads the PDF early), plus a required Dev Matcher form; no named OA. The bar is: can this person build and maintain backend services, integrate third-party APIs, and actually use coding agents / LLM tooling to ship — not just list them. Java with ~1 year of backend solutions is the JD's stated language floor. Strong abstract signals: REST/service ownership with deployment, API integration with a failure or scale number, agentic pipelines or eval/consensus discipline, quantified reliability or speedups. Anti-patterns: Java named without bullet proof (or claimed when absent); Copilot/Cursor as a Skills trophy; notebook ML; club-ops filler; a page that reads pure frontend or pure DSP.

## Screen Criteria

- Backend services shown through use: REST/API design, workers/queues or a data layer, and deployment (cloud or containers) — not implied by a title.
- JD languages demonstrated in bullets, not Skills alone, when the candidate actually has them. Java is the JD floor; absence of Java on the page is a real screen gap, not a formatting miss.
- Third-party API integration with a concrete failure, retry, or scale story.
- LLM / AI-agent-framework / AI-assisted product development in bullets (orchestration, evals, on-device inference) — coding-agent brand names (Copilot, Cursor) are examples of *how they work*, not keywords to stuff. Copilot is also a company benefit; listing it as personal inventory is a fabrication smell if it is not earned.
- Agentic or marketing-automation-adjacent systems visible in the top half (track_divergence): the differentiator is martech/agentic marketing, not a competing engineering track, but it must not be buried under unrelated lanes.
- Quantified impact (latency, cost, throughput, qualification rate, hours saved) so "design to deployment" reads as shipped work.
- Anti-patterns: tutorial-grade CRUD; Skills-only Java or agent names; hard-real-time audio DSP or club leadership as the lead; metric-free architecture tours; claiming Snowflake, Databricks, Copilot, Fusion, Tableau, or Sentry as candidate tools.
