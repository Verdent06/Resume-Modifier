**Pass signals (abstract):**

- Shipped full-stack or backend software: UI or REST/APIs or services, persistence, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Keyword-through-use in bullets, not Skills-only (`resume.md` §2).
- Polyglot proof for languages the candidate actually has. This JD names **no** languages — **do not invent Java, C#, or .NET as requirements.** Python, TypeScript/JavaScript, SQL, or C++ through use beats a Skills-only claim.
- Process-improvement / Bank-IT flavor on that spine: a workflow that used to be manual, a production defect that got fixed, a wrap-up-ready stakeholder delivery — memorable here without replacing the SWE spine.
- Finance-adjacent or messy-regulated-data pipelines as flavor (ingest → transform → serve) — still not an `ai-ml` re-route.
- Cloud / automation / CI through use (AWS, Docker, GitHub Actions) without inventing Kubernetes, Terraform, or core-banking packages.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an Easy coding screen if invited.
- Honest class year and standing on the page: `Expected May 2028` plus GPA ≥ 3.0.

**Anti-patterns:**

- Invented Java, C#, .NET, core-banking, Snowflake, Databricks, Copilot, Fusion, or Tableau.
- Invented First Citizens / SVB platform claims because the company acquired Silicon Valley Bank.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat (analytics is one accountability word, not the job).
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests process improvement, technology enhancements, and a CIO presentation.
- Cloud/SRE-only framing because the site is a data center (the title is Software Developer).
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + process-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
