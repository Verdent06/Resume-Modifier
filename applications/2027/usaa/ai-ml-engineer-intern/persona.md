## Screen Criteria

**Pass signals (abstract — the writer discovers which entries carry them):**
- Python demonstrated through use in bullets, not only the Skills line. SQL / database work through use (JD names SQL and database concepts as foundational).
- End-to-end applied ML or generative-AI workflow: data or eval set → model or LLM pipeline → measured quality (accuracy, faithfulness, latency, cost) → serving analog (API, pipeline, container). Preprocessing through evaluation beats `model.fit()` (`resume.md` §14).
- Production AI evidence: deploying or operating a model/pipeline in a real environment (API, Docker, cloud, monitoring analog). Preferred MLOps / cloud-native is flavor when real, not a license to invent SageMaker/Kubeflow.
- LLM / prompt-engineering / genAI as real pipeline work (orchestration, eval, RAG, fine-tune) — not a one-line ChatGPT mention.
- ML framework through use (PyTorch or equivalent actually in the work).
- Software-development proof (the preferred "coursework or project experience involving software development"): APIs, tests/CI, or a shipped app — secondary to the ML spine.
- Quantitative coursework (stats, calc) visible in Education; GPA on the page; `Expected May 2028`.
- Leadership analog only when it is real engineering ownership, not club-ops filler (JD lists demonstrated leadership as foundational).

**Anti-patterns:**
- Generic SWE / full-stack product resume that never shows a model, LLM pipeline, eval, or production AI analog — wrong role.
- Notebook ML / `model.fit()` with no delivery, no pipeline, no measured quality.
- Voice-AI, audio-DSP, or embedded C++ as the *identity* with no ML/genAI/production-AI analog in the lead window.
- Skills-only Python / SQL / LLMs / ML frameworks with no bullet proof.
- **Inventing TensorFlow, scikit-learn, Keras, NumPy-as-skill, Jupyter, Snowflake, Databricks, Copilot, Fusion, Tableau, Power BI, Java, Kubernetes, Kubeflow, SageMaker, USAA/insurance-policy platforms, Palantir, or military service** (`resume.md` §8 fabrication smell).

- Vanity metrics (uptime, LOC, coverage %) standing in for impact.
