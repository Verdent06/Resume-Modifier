# Software Development Intern (Summer 2027) at RTX / Raytheon — Tewksbury

## Role Summary

A Summer 2027 exclusive-onsite software development internship in Tewksbury, MA (Concord building, 50 Apple Hill Dr). The intern designs, develops, and maintains software applications for complex systems; collaborates with cross-functional teams on features, integration, and scalability; debugs and optimizes existing code for performance; and participates in code reviews. The JD surface is general SWE in higher-level object-oriented languages (C++, C, Java, Python, Ada *or related*) across the software development lifecycle, with Unix/Linux, DS&A / systems software design, Agile/Scrum, DevOps, and test automation preferred. Company identity at this site is radar and air-defense product software (Patriot / Missile Defense Sensors) — high-performance, complex, often real-time C/C++ systems — not manufacturing/avionics test software.
