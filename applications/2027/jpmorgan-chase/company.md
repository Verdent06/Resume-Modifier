# JPMorgan Chase

JPMorgan Chase runs one of the largest technology organizations in financial services, with a real software engineering division that builds and operates digital products at global scale — not a "bank IT" side desk. Tech for Social Good / Code for Good is the early-careers social-impact hackathon path into the Software Engineer Program: students ship a nonprofit tech solution over a weekend alongside JPM technologists, then may be considered for the Summer 2027 SWE internship. The engineering bar is generalist SWE — design, develop, test, secure coding, SDLC automation — inside a firm that invests heavily in modern delivery and approved AI-assisted development tooling.

## Quick Facts

- **Tier:** B-Tier in `reference/companies.md`
- **HQ / offices:** NYC HQ; internship locations include Chicago, Columbus, Houston, Jersey City, New York Metro, Palo Alto, Plano, Tampa, Wilmington
- **Valuation / signal:** Large tech investment; real SWE division; not a typical bank role
- **Product focus:** Enterprise financial-services platforms and digital applications serving millions globally; Code for Good nonprofit tech solutions as the early-careers entry wedge
- **Intern comp (2027 Software Engineer Program):** not stated in JD
- **Work model:** Paid Software Engineer Program Summer Internship 2027; Code for Good is a Friday–Saturday hackathon (travel covered under certain conditions); rolling fill
- **Clearance / eligibility:** Graduation Dec 2027–June 2028 (or by June 2028); CS/IS/IT/Data Science/AI/Big Data or related; must be authorized to work in the U.S. — no sponsorship, OPT, or CPT assistance; Section 19 FDIA applies

## Stack & Hiring Signal

- **Languages:** At least one programming language with secure, high-quality coding (JD does not mandate a specific language)
- **Domains:** full-stack / general SWE — design, develop, test, troubleshoot; SDLC automation; secure coding; collaborative delivery; AI-assisted-dev fluency as a developer habit (prompting, code gen, refactoring, test creation, documentation) with validation and ownership
- **What wins:** Evidence of shipping reliable software with real collaboration and secure-coding discipline; automation/tooling across the SDLC; clear written/verbal communication of technical problems. Per `reference/recruiting.md` Part III §11 (General SWE / Full-Stack) and Part I §1 (OA as a high-elimination stage at scale), the resume clears the screen and supports team-match; HackerRank is a hard gate before deeper review. Social-impact / real-world problem framing is a plus for Code for Good, not a substitute for engineering depth.
