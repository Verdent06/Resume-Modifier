# Code for Good / Software Engineer Program Summer Internship 2027 at JPMorgan Chase

## Role Summary

Early-careers path: Code for Good (Tech for Social Good hackathon) may lead to consideration for the 2027 Software Engineer Program Summer Internship. As an SWE intern, the work is generalist — design, develop, test, and troubleshoot software that serves millions; write secure, high-quality code in at least one language; collaborate across engineers, managers, and stakeholders; apply automation and modern tooling across the SDLC; and use approved AI-assisted development tools (code generation, refactoring, test creation, documentation) with peer review, automated testing, and ownership of correctness/security. The JD surface is classic full-stack SWE inside a large financial-services tech org; the Code for Good framing adds social-impact delivery and networking with recruiting, not a separate engineering specialty.

## Track Decision

- **screen_track:** full-stack (general SWE)
- **differentiator:** fintech-scale SWE delivery with visible AI-assisted-development fluency as a developer habit, plus openness to real-world / social-impact problem solving
- **track_divergence:** false

The screen spine is general SWE/full-stack per `recruiting.md` Part III §11 and `resume.md` Part III §12 — design/develop/test, secure coding in at least one language, SDLC automation, collaboration. The JD's AI-tool language (prompting approved AI tools, critically evaluating outputs, responsible AI practices) describes **developer tooling fluency**, not AI/ML systems engineering. Treat it as a plus layered on the full-stack bar (same pattern as Capital One's AI-coding-tools preferred), not as a track pivot to ai-ml.

## Team & Bar

JPMorgan Chase is B-tier per `companies.md`: large tech investment, real SWE division, not a typical bank role. Funnel is ~3 rounds, Easy–Med coding, HackerRank OA required before further review, no system design; bottleneck is tech rounds; ~8–12% estimated offer rate. At this scale, the resume must clear ATS/human screen cleanly and support post-OA team-match; HackerRank is a hard gate (`recruiting.md` Part I §1). Recruiter voice: looking for interns who already ship reliable software with collaboration and secure-coding discipline, communicate clearly, and treat AI tooling as accountable productivity — not as a substitute for ownership. Social-impact curiosity helps Code for Good framing but does not replace engineering evidence.

## Screen Criteria

- Secure, high-quality code in at least one real programming language proven in bullets (not Skills-only).
- End-to-end shipping signal: design → build → test/troubleshoot on a real system, with trade-off fluency (why this stack/decision).
- Collaboration evidence: working with others to understand problems, share feedback, deliver reliable solutions — not solo tutorial projects only.
- Automation / modern SDLC tooling tied to shipped work (CI, testing, delivery efficiency) where present.
- AI-assisted development as a **habit with validation** (productivity + ownership of quality/security) is a differentiator/plus — absence is not an automatic reject given the core bar is general SWE; presence without ownership/validation language is weaker than presence with it.
- Clear written communication of technical problems (documentation, articulation) as supporting signal.
- Open-ended / ambiguous problem-solving (break down, experiment, iterate) reads well for both hackathon and internship.
- Class-year and degree field must match JD gates on the page (Expected May 2028 / CS is in range).

## Anti-Patterns

- Screening as AI/ML systems engineer solely because the JD mentions AI coding tools — wrong track for this req.
- Skills name-dropping (secure coding, CI/CD, AI tools) with no bullet or tech-stack-line proof.
- Club-ops or community-growth framing with no engineering depth.
- Notebook ML or research-only entries as the lead when the JD tests generalist SWE delivery.
- Vanity metrics (bare uptime %, test-coverage %) as the sole quantitative payload.
- Thin single-bullet filler entries that dilute a strong full-stack spine.
