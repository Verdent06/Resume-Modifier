# Software Engineer Intern at LPL Financial

## Role Summary

Summer 2027 SWE intern building web applications, APIs, and cloud tooling for LPL's independent-advisor wealth-management platform — client-facing interfaces, backend services, CI/CD automation, and AI-assisted development workflows. JD surface is classic full-stack: Python/Java/C#/JavaScript, React/Angular, Node/.NET/Spring Boot, AWS/Azure/GCP, Git, REST. Company identity is regulated fintech at scale — advisor workflows, portfolio operations, and platform reliability matter as much as feature velocity.

## Screen Criteria

- Polyglot proof: Python and/or JavaScript demonstrated in bullets — not Skills-only; Java/C# are JD languages but only required where the candidate inventory supports them.
- Full-stack or backend shipping: REST APIs, web frontends (React or Angular), cloud deploy (AWS preferred per stack intel) with outcome metrics.
- CI/CD and Git in project context — JD lists both as preferred; bullet evidence beats Skills mention.
- Fintech or financial-data platform signal — research tools, transaction/compliance-adjacent pipelines, or production APIs serving financial workflows register the company differentiator.
- Production ownership over coursework demos — contracted delivery, co-op shipping, or live products with users.
- Class-year on page must show current enrollment (`Expected May 2028` satisfies Summer 2027 internship eligibility).
