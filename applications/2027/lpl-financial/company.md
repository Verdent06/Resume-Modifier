# LPL Financial

LPL Financial is the nation's largest independent broker-dealer and a custodian/technology provider for independent financial advisors — a hybrid wealth-management platform company, not a traditional bank IT shop. Advisors use LPL's Client Works and related tooling for portfolio management, client onboarding, compliance workflows, and practice operations; the engineering org builds web applications, backend services, and cloud infrastructure that thousands of RIAs depend on daily. Recent hiring signals point to Java/Spring and .NET on core transactional systems, AWS for cloud compute, React/Angular on client-facing surfaces, and emerging investment in AI-assisted development (Cursor, RAG) for advisor productivity.
