## Screen Criteria

**Pass signals (abstract):**

- Shipped full-stack or backend software: UI or REST/APIs or services, persistence, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Keyword-through-use in bullets, not Skills-only (`resume.md` §2).
- Polyglot proof for languages the candidate actually has. This JD names **no** languages — **do not invent Java, C#, .NET, or Angular as requirements.** Python, TypeScript/JavaScript, SQL, or C++ through use beats a Skills-only claim.
- Finance-adjacent / farm-credit flavor on that spine: production APIs, credit-or-messy-data workflows, rural-infrastructure or agribusiness analogs, reliability-minded delivery — memorable here without replacing the SWE spine.
- Data-pipeline or integration evidence (ingest → transform → serve) as a plus that maps to both Full Stack integrations and the Data Engineering example team — still not an `ai-ml` re-route.
- Cloud / automation / CI through use (AWS, Docker, GitHub Actions) without inventing Kubernetes, OpenShift, Terraform, or ServiceNow.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an Easy coding screen if invited.
- Honest class year and standing on the page: `Expected May 2028` sits inside Dec 2027–May 2029.

**Anti-patterns:**

- Invented Java, C#, .NET, Angular-as-requirement, OpenShift, ServiceNow, Snowflake, Databricks, Copilot, Fusion, or Tableau.
- Invented core-banking, farm-credit, or CoBank-platform claims because the company is a cooperative lender.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat (AI/ML is one example team, not the job).
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests UIs, backend services, integrations, and enterprise delivery.
- Cloud/SRE-only framing (DevOps is one example team in a pool, not the filter).
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + finance-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
