# Anduril Industries

Anduril builds defense technology for U.S. and allied military customers, with Lattice OS as the software layer for real-time command, control, autonomy, sensor fusion, and networking. For a software intern, the screen is broad SWE, but the company signal is mission-critical autonomy: code has to work under operational constraints, not just in a demo.

## Quick Facts

- **Tier:** A-TIER -- Excellent / Strong Signal
- **HQ / offices:** Costa Mesa, CA; role locations include Atlanta, Boston, Costa Mesa, Irvine, Reston, and Seattle
- **Valuation / signal:** Defense-tech category leader; doctrine row notes $14B+ valuation and CNBC #1 Disruptor signal
- **Product focus:** Lattice OS and fielded defense/autonomy systems
- **Intern comp (2027 SWE):** $40-$55/hr from the JD
- **Work model:** Paid, in-person, 12-week Summer 2027 internship
- **Clearance / eligibility:** U.S. Person status required for export-controlled work; rising senior and returning to school after the internship

| Stage | Format | Notes |

**Estimated funnel:** 3 rounds · Medium LC/practical · HackerRank · practical system design · Bottleneck: 4-hour onsite · ~3-5% estimated offer rate

## Stack & Hiring Signal

- **Languages:** C++, Go, Rust, Java, Python, plus role-dependent frontend/backend tools
- **Domains:** Autonomy, real-time systems, sensor fusion, networking, cloud infrastructure, deployed customer-facing software
- **What wins:** Shipped systems with clear ownership, polyglot programming evidence, debugging/monitoring maturity, and evidence that the candidate can reason about software that affects real-world operations.
