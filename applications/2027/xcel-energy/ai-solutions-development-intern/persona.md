## Screen Criteria (abstract)

Pass signals:
- Hands-on AI solutions and agents (multi-step orchestration, tool/model integration, structured output or eval) — not a thin chatbot wrapper or a notebook demo.
- Automation / workflow improvement with a before/after: pipelines that replace manual work, scored throughput, or recurring workers — the JD's second responsibility bullet.
- Agent testing / validation discipline: eval harnesses, tests, faithfulness/quality lifts, or "development and testing of AI-powered solutions and agents."
- Analytics + SQL/Python through use: ingest, normalize, score, or dashboard data for process optimization — not Skills-only SQL.
- APIs or applications/websites shipped to users (JD preferred: building applications, websites, or technical projects; familiarity with APIs). TypeScript/React or Flask/FastAPI through use covers the JavaScript/apps *or similar* line without inventing JavaScript.
- Stakeholder delivery analog: documenting or serving output to non-ML users (demos, user guidance, contract/API ownership).
- Metrics that size impact (hours saved, quality/faithfulness, throughput), landed as the closer (`resume.md` §4).
- Utility-adjacent operations or regulated-industry data work is a plus for the differentiator, but not a fabricated electric-utility or Copilot internship.

Anti-patterns:
- ML-research framing: publications, novel methods, LoRA/`model.fit()` as the identity with no agent, no automation, no delivery (`recruiting.md` §13 research vs applied split). This req is Enterprise AI Enablement.
- Off-axis lead: pure C++ audio-DSP, club-ops, or a generic SWE identity with agents buried.
- Agentic/LLM claims only in Skills with no supporting system.
- Inventing Microsoft Copilot, GitHub Copilot, Power Platform, Microsoft 365 as a skill, Snowflake, Databricks, Tableau, Fusion, or Sentry.
- Claiming JavaScript (vs TypeScript in inventory), low-code, or Xcel/electric-utility platform internships the page cannot defend.
- Metric-free architecture bullets the recruiter cannot size.
- No live GitHub on an intern engineering resume (`resume.md` §3).
