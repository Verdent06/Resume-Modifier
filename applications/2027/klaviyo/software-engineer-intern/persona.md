## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has that the JD names (**Python**; **TypeScript**). Keyword-through-use in bullets, not Skills-only (`resume.md` §2). **Do not invent Go or Django.** React through use if claimed. PostgreSQL in a bullet is the honest MySQL analog (legal swap only if the selected bullet actually has PostgreSQL).
- Shipped full-stack or backend software: REST/APIs, a real frontend or client surface, a persistence decision, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Ownership of write → test → ship matches "full lifecycle of your code."
- Production debug with a witness metric (failure-rate drop, timeout, queue drain analog) — the JD's "slow-loading UI / query timing out / queue that won't drain" bar.
- Data-platform / messaging flavor on that spine: ETL or rankings over messy source data; Redis/workers/queues; serving stored data to a UI — memorable at Klaviyo without replacing the SWE spine.
- Prior titled SWE intern or co-op visible on the page (JD must-have). Do not invent a second named SWE internship.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in a practical CodeSignal OA (the intern bottleneck).
- Class-year on the page: `Expected May 2028` satisfies May/June 2028.

**Anti-patterns:**

- Skills-line Go, Django, Terraform, Cassandra, Clickhouse, Kafka, Jenkins, Buildkite, Snowflake, Databricks, Copilot, Fusion, or Tableau with zero bullet evidence (fabrication smell). Copilot/AI-first is a JD *workflow*, not inventory.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat because of the AI & Analytics pillar.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/API/customer-facing SWE (systems depth can support, not lead).
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + shipped-product spine.
- Claiming Klaviyo, CDP, email/SMS/WhatsApp messaging infra, or Django/Go production the page cannot defend.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Inflating contract/consulting work into extra SWE internships.
