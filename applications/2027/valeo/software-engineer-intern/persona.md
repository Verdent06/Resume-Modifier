# Software Engineer Intern at Valeo

## Role Summary

A full-time Software Engineer Intern (REQ2026076575) in Troy, MI on Valeo's Engineering Software / R&D trainee track. The intern helps design C++ middleware, APIs, and OS components for Software-Defined Vehicles; implements, tests, and debugs C/C++ and Python on embedded and Linux platforms; builds backend services and programmable interfaces for personalized, AI-enhanced in-cabin UX; analyzes logs and troubleshoots connectivity/performance; integrates algorithms with automotive hardware; learns ISO 26262; and uses AI tools to improve CI/CD and automated testing in an Agile SDLC.

JD surface vs company identity: the only hard requirement is a current Bachelor's in CE, SWE, or a related field. Responsibilities are generic SWE — languages, APIs, backend services, debug, CI/CD — at a Tier-1 automotive supplier whose memorable identity is SDV middleware and hardware-software integration, not a consumer web product and not an ML-training lab.

## Screen Criteria

- JD languages demonstrated *inside* architectural decisions — C++ and Python in bullets, not Skills alone. C is named on the JD; do not invent C-only work.
- Backend services / APIs / programmable interfaces shown through real delivery (REST or equivalent), not a course list.
- Implement / test / debug evidence with sized outcomes (failure recovery, latency, performance) — log analysis and troubleshooting are first-class on this req.
- CI/CD or automated-testing curiosity backed by use (a real pipeline), not a bare Skills token.
- Company-fit differentiator visible in the top half: real-time or systems C++, hardware-adjacent or lock-free/embedded-style constraints, Linux-class discipline — without turning the page into a hobby-audio or robotics-only resume.
- Full-stack spine still present: shipped services, data, deploy, ownership of something used by others (`resume.md` §12).
- Class-year on page shows current enrollment (`Expected May 2028` is a current student for a 2027 intern cycle).

## Anti-Patterns

- Skills-list C++/Python/Linux with zero bullet proof — the floor signal at an auto-supplier SWE intern screen.
- Leading with notebook ML or agentic-LLM product framing as if this were an applied-ML internship; AI here is UX backends and CI tooling.
- A purely web resume with the systems/C++ signal buried or omitted at an SDV middleware team.
- Claiming ISO 26262, AUTOSAR, QNX, or automotive ECU work that was never done.
- Club-ops or thin single-bullet filler that dilutes shipped engineering.
- Tutorial clones with no API, no debug story, and no deploy.
