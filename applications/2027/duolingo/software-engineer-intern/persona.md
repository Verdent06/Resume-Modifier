- Code-review / collaboration analog: stakeholder-scoped delivery or cross-team quality, not a Scrum-cert line.

- Class-year on the page: `Expected May 2028` — honest junior standing; satisfies the Dec 2027–Aug 2028 gate.

**Anti-patterns:**

- Invented Duolingo, language-learning, lesson-content, iOS/Android native, or A/B-framework ownership.

- Routing the page as DevOps/SRE (homelab, Terraform, Kubernetes) because the JD named infrastructure, or as ML-research (LoRA, publications, notebook `model.fit()`) because a past project named GPT-4.
- Hard-real-time C++/audio-DSP as the *first-pass identity* when the role tests product-team SWE, Python services, and full-stack features — systems depth can support, not lead, an edtech product screen.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a production-app spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
