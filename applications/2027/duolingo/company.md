# Duolingo

Duolingo (NASDAQ: DUOL) is the largest language-learning app in the world: hundreds of millions of learners, ~250 courses, plus Duolingo English Test and a Math course. Engineering is product-and-experimentation first — A/B tests, observability on those experiments, and native mobile plus web/backend shipping (Python/Java backends; Kotlin Android; Swift iOS; React web). Interns on this University SWE seat sit in Engineering and ship full-stack features, services, and infrastructure used by learners or internal tools — not an ML-research seat, not a mobile-only knockout.

## Stack & Hiring Signal

- **Languages:** JD or-list **Java, Python, Kotlin, or Swift**. Official OA: Python / Java / JavaScript. Screen for proof in languages the candidate actually has — **Python through use**. Do **not** invent Java, Kotlin, Swift, Snowflake, Databricks, Tableau, Copilot, or Fusion CAD. Java/Kotlin/Swift are training-on-the-job if absent from inventory.
- **Domains:** Generic University SWE intern: full-stack features and services, services/infra, code review, quality and scalability. Past intern projects (examples, not requirements): GPT-4 internal tools, A/B + observability, audio lessons, Math course, iOS/Android/web ports, SRE dashboards, new microservices. Thrive flavor: small-group real-world SWE project + accessible-education mission.
- **What wins:** Because Karat is the binding filter after a human+AI resume screen (`companies.md`; `recruiting.md` OA-gated intern), a one-page PDF that shows shipped full-stack or backend services in Python, tests and code-review analogs, and a defensible DS&A story — without claiming mobile native or A/B-framework ownership the pool does not have. Mission-driven product shipping is memorable; notebook ML or club-ops is not. Thrive additionally requires the Dec 2028–Aug 2029 window.
