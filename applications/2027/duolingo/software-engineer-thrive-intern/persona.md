## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has. JD names Java, Python, Kotlin, Swift as *one-or-more* — **do not invent Java, Kotlin, or Swift**. **Python must appear in bullets** (keyword-through-use), not Skills-only (`resume.md` §2). Include every JD-listed language the candidate possesses in Skills (Python).
- Shipped full-stack or backend software: REST/APIs or services, a real user or stakeholder, a persistence decision, and deploy/CI tied to an outcome (`resume.md` §12). Thrive's intern bar is a challenging real-world SWE project — analog is shipped engineering, not a user-count claim about 500M learners.
- Consumer-product or education-adjacent flavor on that spine (learning product, voice/audio for a learner, shipped app other people used) — memorable at Duolingo without replacing the SWE spine.
- Experimentation / fact-based-decision flavor: a named production defect with before/after, an eval harness, or held-out measurement — not invented A/B tests or Duo experiments.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in CodeSignal + Karat medium DSA (`companies.md` bottleneck).
- GPA on the page if ≥3.5 (JD exceptional). Honest `Expected Month Year` on Education (`resume.md` §2).
- Collaboration analog: small-group / stakeholder-scoped delivery — Thrive is a hosted group project.

**Anti-patterns:**

- Skills-line Java / Kotlin / Swift / Snowflake / Databricks / Tableau / Copilot / Fusion with zero bullet evidence (fabrication smell).
- Python only in Skills — JD language as a floor signal at a company that interviews in Python (`resume.md` §2; `companies.md` OA languages).
- Invented Duolingo, streaks, language-learning pedagogy, spaced-repetition, or 500M-learner ownership.
- Routing the page as ML-research (LoRA / publications / `model.fit()` as identity) or DevOps/SRE because the company experiments and runs at scale.
- Hard-real-time C++/audio-DSP as the *first-pass identity* when the role tests product SWE + Python — systems depth can support, not lead, an edtech intern screen.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a production-app spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Leading as PE/search-fund GTM or campaign-finance analytics with no consumer-product or education-adjacent signal in the lead window (`track_divergence`).
