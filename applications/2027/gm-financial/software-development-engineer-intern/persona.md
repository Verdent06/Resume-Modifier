- Production-first analog through use: reliability, triage/debug of a live issue, pipelines/CI or static-quality tooling, scale — without vanity uptime metrics (`resume.md` §4).
- Agile / Scrum / stakeholder delivery; communication that would survive a capstone to business leaders.
- Captive auto-finance / fintech-backend flavor on that spine: production APIs, financial or messy-data workflows, reliability-minded delivery — memorable here without replacing the SWE spine.
- AI-enabled tools / responsible AI as **plus** (preferred), never as the lead story for a generic SDE intern, and never invented Copilot.
- Class-year and GPA on the page: `Expected May 2028` and GPA 3.66 satisfy ≥1 semester remaining and the 3.0 floor.

**Anti-patterns:**

- Skills-line Java / Copilot / Kubernetes / Snowflake / Databricks / Tableau / Fusion with zero bullet evidence (fabrication smell; none required on this intern JD).
- Invented auto-lending, dealer-OMS, or GM Ultifi/vehicle-embedded claims because the parent is GM — this seat is captive *finance* SDE, not Detroit/Warren vehicle SWE.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML intern (AI tools are preferred environment, not the job).
- SRE-only or k8s-platform framing (DevOps/vuln/prod-support are *assist*, not the exclusive spine).
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web, mobile, API, and data-marketplace features.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + production-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
