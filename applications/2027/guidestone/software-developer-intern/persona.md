Location: **Dallas, TX Headquarters**, **#LI-Hybrid**. Comp unlisted (C-tier intern $22–38/hr band). Posted **2026-09-22**. **Not** a Mission:Dignity intern sibling.

Senior (grad Aug/Dec 2027) is **preferred, not required**. **`eligibility_verdict: eligible`.**

## Team & Bar

Screener is a university / HR recruiter plus a software-development hiring manager on a C-tier Workday intern funnel (`companies.md`: resume → recruiter → unpublished Easy project walk + STAR; bottleneck **resume** · ~15–25%). Evidence that wins: JD languages the candidate actually has, demonstrated in bullets not Skills alone; a shippable web app or production API with tests/CI or named debug; Git through use; HTML/CSS/JS-family through use; SQL through use; finance-adjacent or high-reliability delivery as flavor. Intern-stage weighting still favors engineered projects plus live GitHub (`resume.md` Part II intern). Prestige is a tiebreaker (`recruiting.md` §8).

`Expected May 2028` is the honest class-year line (student throughout Summer 2027). GPA 3.0 is a hard floor; 3.66 clears. Permanent US work-auth / no student visa is a knockout if asked, not a resume line. Apply in the first wave (posted 2026-09-22).

## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has that the JD names (**SQL**, **HTML/CSS**; TypeScript covering JavaScript-family) through use, not Skills alone (`resume.md` §2). **Do not invent C#.**
- Shipped full-stack software: REST/APIs, persistence, front-end (Angular or React), and cloud/deploy/CI tied to an outcome (`resume.md` §12). Automated tests, debugging, or PR/code-review discipline through use matches write/test/debug + Azure Pipelines analog.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an Easy project walk.
- Retirement-services / fintech-backend flavor on that spine: production APIs, financial or regulated-data workflows, reliability/defect recovery — memorable here without replacing the SWE spine.
- Class-year on the page: `Expected May 2028` (current student throughout the intern program). GPA ≥ 3.0 if shown.

**Anti-patterns:**

- Skills-line C# / Razor / MVC / WebForms / Azure / Visual Studio / SSMS with zero bullet evidence (fabrication smell at a Microsoft shop).
- Invented Snowflake, Databricks, Copilot, Fusion, Tableau, or GuideStone platform ownership.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/SQL/Git/enterprise SWE.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + finance-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Confusing this employer with a generic Microsoft consulting shop or a Mission:Dignity program intern.
