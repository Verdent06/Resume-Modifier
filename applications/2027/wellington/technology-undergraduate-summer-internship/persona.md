## Screen Criteria

**Pass signals (abstract — the writer discovers which entries carry them):**

- Shipped software application or production API with a database or cloud deploy — coding through use, not a skills dump (`resume.md` §12). Matches "identify, design, build, test and deliver a software application."
- **Python** through use in bullets (ETL, API, pipeline, analysis) — the JD's named language floor. Skills-only Python fails.
- Data analysis through use: ingest messy real-world data, normalize/aggregate, serve a ranking or API — analog to "data analysis" and "analyze user needs."
- Testing / iterative delivery through use: CI, pytest, eval harness, or a named defect with a before/after metric. Vanity coverage % is not the signal (`resume.md` §4).
- Stakeholder / collaborative delivery: scoped with non-engineer users, cohort-shaped ownership, or sole-engineer contract delivery inside a fixed window — analog to "partnering closely with teammates and stakeholders."
- Applied AI-tool curiosity as real systems work (agentic pipelines, eval/judgment, on-device inference) — matching the look-for without becoming an ML-research resume. Do not invent Copilot/Fusion.
- Investment-management / fintech-backend flavor on that spine: production APIs over financial or research-adjacent data, scored pipelines, PE/AM-adjacent delivery — memorable here without stuffing "AUM" into unrelated bullets.
- Class-year on the page: `Expected May 2028`; GPA 3.66; CS + Economics coursework visible.

**Anti-patterns:**

- TAP / Business Associate / investment-analyst framing.
- Notebook ML or `model.fit()` / LoRA as the lead as if this were an ML-research intern.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests applications, Python, data analysis, and stakeholder delivery.
- Skills-only Python / Docker / SQL / Git with no bullet proof.
- Invented Snowflake, Databricks, Copilot, Fusion, Tableau, or Kubernetes (fabrication smell — `resume.md` §8).
- Club-ops or community-growth filler occupying prime slots.
- Thin single-bullet entries that dilute a full-stack + AM-tech spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact.
- Claiming day-one ownership of Wellington fund-accounting, trading, or Client/Infrastructure/Investment platforms.
