- REST / web architecture and Git (plus Docker/AWS/CI when present) tied to delivery, not a tools list. JD stack beyond Python/REST/SQL/Git is "learn on the job," not a fabrication target.
- Vertical-SaaS / marketplace flavor as *product* evidence (real users, procurement/ops-adjacent data, shipped APIs) visible without converting the page to GTM-only scoring or notebook ML.
- Metrics for latency, reliability, cost, or delivery so "bugs that affect users" and "iterate on product" read as engineering.
- Anti-patterns: Skills-only Python/SQL; Django claimed without inventory; frontend-only polish; hard real-time C++ DSP as the lead identity; GTM/quant scoring as the opening story; invented Canadian work permit, Vancouver residency, or Fall 2026 availability; Snowflake / Databricks / Copilot / Fusion / Tableau / Sentry.
