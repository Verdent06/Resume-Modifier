# Software Engineering Internship — Summer 2027 at Chicago Trading Company (CTC)

## Role Summary

SE Intern on CTC technology teams building trading tools and risk applications that traders and quants use to price, trade, and manage risk in real time. Release cycles are measured in days — code reaches production and affects the desk almost immediately. Practical exposure may include Java, C++, and Python. The 8-week Chicago program (mid-June–early August 2027) pairs SE interns with QT interns for Basics of Options, Mock Trading, and Quant Curriculum. JD surface is generalist trading-tech SWE: DS&A + OOP, collaborative shipping, interest in tech/trading/pricing/risk (no prior finance required). AI coding assistants and agentic tooling are daily engineer habits; CTC also builds AI into trading/research/engineering systems — interns are encouraged to use them to ship faster. That AI language is developer-tooling fluency and platform adjacency, not an ML-systems internship.

## Track Decision

- **screen_track:** full-stack (general SWE)
- **differentiator:** trading-tech / low-latency production systems fluency (C++/systems depth + fast ship cycles) + AI-assisted-dev as developer habit (NOT ai-ml track)
- **track_divergence:** false

The screen spine is general SWE per `recruiting.md` Part III §11 and `resume.md` Part III §12 — ship working software, DS&A foundation, language depth in Java/C++/Python. The differentiator is flavor on that spine (production tools for desk users, short-cycle delivery, systems/latency culture), not a second track. Do not pivot the resume to ai-ml research or agentic-product lead framing.

## Team & Bar

CTC is Unrated in `companies.md` but sits in the Chicago prop / options market-making peer set (funnel family near IMC). Funnel: resume → coding OA → behavioral (values) + technical (programming in preferred language). Recruiter voice: looking for interns who already demonstrate CS fundamentals, ship under short cycles, communicate clearly, and fit a collaborative / humble / competitive desk culture. Comp is top-of-market for intern ($14.5k/mo + signing + housing) — bar is selective. Resume must prove at least one of Java/C++/Python in real work; interview language preference is asked at apply. Eligibility window Dec 2027–June 2028 is a hard gate on the page.

## Screen Criteria

- At least one JD language (Java, C++, or Python) proven in bullets — not Skills-only. Polyglot across the list is a plus; inventing Java when absent is worse than honest Python + C++ depth.
- End-to-end shipping with production impact and short-cycle / ownership signal (tools that reach users, reliability, measurable outcomes).
- Systems or performance depth that reads as trading-tech adjacent (real-time constraints, concurrency, latency, or similar) without requiring prior finance.
- DS&A / OOP foundation visible via coursework and engineered projects that can be defended in a coding interview.
- Collaboration and clear technical communication — not solo tutorial-only pages.
- AI-assisted development as a **habit with shipping speed** is a plus layered on the SWE bar — absence is not an automatic reject; leading with ML research / LoRA / agent pipelines as if this were an ML internship is an anti-pattern.
- Class-year on page must fall in Dec 2027–June 2028 (Expected May 2028 is in window).

## Anti-Patterns

- Screening as AI/ML systems or research engineer because the JD mentions AI assistants / agentic tooling.
- Java named in Skills with zero bullet evidence (fabrication / keyword smell) when the pool has no Java.
- Club-ops or community-growth framing with no engineering depth.
- Soft, metric-free shipping claims where production impact is the firm's selling point.
- Thin single-bullet filler that dilutes a strong production + systems spine.
- Finance-jargon padding without engineering substance (prior finance is explicitly not required).
