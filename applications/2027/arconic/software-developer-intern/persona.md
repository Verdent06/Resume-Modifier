## Screen Criteria

**Pass signals (abstract — the writer discovers which entries carry them):**

- Shipped full-stack or web/enterprise software: REST/APIs or services, a database, HTML/CSS and a JS-family or React client tied to an outcome (`resume.md` §12). Keyword-through-use in bullets, not Skills-only (`resume.md` §2).
- **Polyglot proof** for languages the candidate actually has that the JD names (**SQL**, **HTML/CSS**). TypeScript/Python/C++ through-use is honest "similar language" OOP proof. **Do not invent Java, C#, Visual Basic, JavaScript-as-a-claimed-inventory-token if the pool only has TypeScript, .NET, or ServiceNow.** TypeScript is not Java; C++ is not C#.
- Preferred React through a real UI bullet if the pool supports it — not Skills-only React.
- SQL through use (queries/tables/data in a bullet), not Skills alone.
- Git / CI/CD analog: source control and an automated build/test/deploy path through use (GitHub Actions counts).
- Application testing analog: diagnosed a real failure or customization, fixed it, with a before/after — maps to "application testing of configurations, migrations, and customizations."
- Enterprise-automation / stakeholder-workflow analog: replace a manual business process with a shipped pipeline or API a non-engineer actually used — hours saved or quality lift as the closer (`resume.md` §4). This is the differentiator carrier, not mill-floor metallurgy.
- SDLC flavor as *kinds* of evidence (build, test, deploy, maintain) — not a Scrum-cert line.
- Class-year on the page: `Expected May 2028`. GPA 3.66 ≥ 3.0 belongs on the page.

**Anti-patterns:**

- Invented Java / C# / Visual Basic / .NET / ServiceNow / Power Platform / Kawneer CAD / mill-metallurgy / Snowflake / Databricks / Tableau / Copilot / Fusion (fabrication smell at a mill IT shop).
- Skills-only SQL, HTML/CSS, React, or Git with zero bullet evidence (JD floor/preferred signals).
- Leading as a PLC/OT/controls technician or stuffing mill-DCS internships the page cannot defend.
- LoRA / notebook ML / agentic-AI product framing as if this were Howmet **119494** or an ML-research intern.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/SQL/Git/enterprise automation.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + industrial-IS spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Confusing this mill IT Applications req with Pittsburgh ServiceNow / Digital Solutions / IT Systems siblings or Howmet Corporate IT AI.
