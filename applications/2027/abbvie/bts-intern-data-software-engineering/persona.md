# 2027 Business Technology Solutions Intern - Data & Software Engineering (Undergraduate) at AbbVie

## Role Summary

An 11-week onsite Summer 2027 BTS intern on either Data Engineering or Software/Application Engineering, most often in Lake County, IL (North Chicago HQ area), with possible placement at other U.S. AbbVie or Allergan Aesthetics sites. The intern helps design, build, and run enterprise applications (UI, APIs, microservices, full-stack ownership) and/or the data infrastructure — databases, pipelines, integration, warehousing, visualization — that lets scientific and commercial teams answer questions. This is Fortune-class pharma enterprise IT, not an R&D bench role and not an ML-research internship. Comp posted $21–37.80/hr; SmartRecruiters; rolling.

## Screen Criteria

**Pass signals (abstract — no pool entries):**
- Python, SQL, and TypeScript/JavaScript (or HTML) appear inside architectural decisions in bullets, not only on the Skills line (`resume.md` Part I §2).
- End-to-end application or data-system delivery: UI or API + server-side logic + database or pipeline + a measured outcome (`resume.md` Part III §12; `recruiting.md` Part III §11).
- Data infrastructure analog: ingest → transform/integrate → store efficiently → serve analytics or an application — hours saved, throughput, quality, or scale (`recruiting.md` applied data; this JD's Data Engineering track).
- APIs used to move or expose data; production-shaped delivery (cloud VM, container, REST) as supporting evidence, not a Skills dump.
- Public code portfolio implied by GitHub in the header (JD: GitHub/GitLab/Bitbucket highly preferred).
- Generative-AI-on-custom-software is a plus when it sits on real software or data work — not a research-paper lead.
- Impact metrics (latency, cost, hours saved, precision, scale), not vanity counts (`resume.md` Part I §4).

**Anti-patterns:**
- Skills-only Java, Vue.js, NodeJS, R, or APEX — or inventing those stacks. Preferred, not required; absence is honest.
- Notebook ML / `model.fit()` as the lead with no pipeline, API, or application (`resume.md` Part III §14 anti-pattern; this is not an ML-research seat).
- Club-ops or community-growth filler in prime slots (`resume.md` Part I §8).
- Pure audio-DSP / hobby systems as the lead with no application or data-infrastructure analog.
- Claiming AbbVie, pharma, Spring Boot, or Salesforce APEX internships the page cannot defend.
- Two-column/graphics formatting; year-only graduation date (`resume.md` Part I §2).
