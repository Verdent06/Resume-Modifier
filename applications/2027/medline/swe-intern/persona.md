# Software Engineering Intern - Summer 2027 at Medline

## Role Summary

A paid Summer 2027 hybrid software-engineering internship at Medline (Nasdaq: MDLN) in Northbrook, Illinois (CORP) — 10 weeks, early June through mid-August, $23.25–$33.75/hr, req R2617623. The intern works with experienced engineers to design, develop, test, deploy, and support applications that drive Medline's Warehouse Management Systems and e-commerce platforms. Surface work is full SDLC on business and e-commerce apps: new features, defect/production debug, code reviews, unit and automated tests, technical documentation, and solution-design discussions in an agile team. Company identity is healthcare supply-chain software (WMS + e-commerce) at the largest U.S. med-surg manufacturer/distributor — not device firmware, not an ML-research seat, and not a generic consumer-product intern rotation with no ops/commerce analog.

**Pass signals (abstract — no pool entries):**
- JavaScript-family (TypeScript / JavaScript) demonstrated through use in bullets — Angular or React on a real UI — not Skills-list only. Java is optional when JS-family is present; do not invent Java or Spring.
- HTML/CSS and a named modern front-end (React or Angular) inside an architectural decision (`resume.md` Part I §2). Next.js is a plus, not a gate; absence is honest.
- End-to-end application delivery: UI or API + server-side logic + database or pipeline + deploy + a measured outcome (`resume.md` Part III §12; `recruiting.md` Part III §11).
- SQL / relational data through use, not Skills only.
- Git (and CI or tests if real) through use; unit/automated-testing analog when present.
- Defect/production debug: a diagnosed failure with a before/after number — analog to "analyze, debug, and resolve software defects."
- Cloud (AWS) and Selenium as pluses when they sit on real work — Selenium may appear as a tool the candidate can interview in; do not invent Jasmine, Karma, Azure, or GCP.
- Impact metrics (failure rate, latency, hours saved, throughput, quality), not vanity counts (`resume.md` Part I §4).
- Class-year visible (`Expected May 2028` = rising senior for Summer 2027); GPA on the page if ≥ 3.5.

**Anti-patterns:**
- Skills-only Java, Spring, Hibernate, Maven, Next.js, Jasmine, Karma, Azure, GCP — or inventing those stacks. Preferred/plus, not required.
- Claiming Snowflake, Databricks, Copilot, Fusion, Tableau, Sentry, or a Medline/WMS/healthcare internship the page cannot defend.
- Notebook ML / agentic-LLM product as the lead with no application, SQL, or front-end analog.
- Club-ops filler; pure audio-DSP / hobby systems as the lead with no business-app or e-commerce analog.
- Two-column/graphics formatting; year-only graduation date (`resume.md` Part I §2).
