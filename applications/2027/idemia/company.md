# IDEMIA

IDEMIA Public Security (a division of IDEMIA Group) ships government-grade biometric identity — iris, fingerprint, and facial recognition — for public security, justice, travel, identity, and access control. The intern seat is **not** a computer-vision or ML-research rotation: it is IT software on **low-code / drag-and-drop** (Boomi named; Power Apps / OutSystems preferred) for data and task automation, data quality, and governance. IDEMIA Group is privately held (Advent International majority), Courbevoie HQ, **€2.8B+** 2024 revenue, **12,500** employees, **~3,000** R&D engineers. Public Security cites **4000+** employees and **150+** partners. North America HQ is Reston, VA (driver’s licenses, TSA PreCheck / IdentoGO, criminal-justice programs).
