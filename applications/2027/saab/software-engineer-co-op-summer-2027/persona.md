## Role Summary

A Summer 2027 (May–August) full-time onsite software co-op/internship in East Syracuse, NY (Collamer) on Saab, Inc.'s **Surveillance Software** team. Daily work is software development for **air traffic management systems in use at today's airports** — putting CS/SE/CE coursework onto real products that support a safer society. The JD *surface* is generic intern SWE: object-oriented design and programming with C++, Python, and/or Java; scripting; Linux or Unix. Preferred extras are design patterns, Git/Subversion, JavaScript/HTML/CSS, unit-test frameworks, and Database/SQL. Company identity (`company.md` / `companies.md`) is safety-critical ATM / airport surveillance software for the FAA and DoD — not a radar-hardware technician seat, not ML-research, and not a generic defense-IT helpdesk.

## Team & Bar

The reviewer is a defense/security engineering screener on a C-tier Saab Inc. funnel (`companies.md`: Workday resume → recruiter phone → possible technical video in C++/Python/Java OOP → panel; Easy; no standard intern OA; no intern sys design; bottleneck: resume; ~20–25%). With no named OA, the PDF is the front door (`recruiting.md` intern funnel — resume carries more weight at mid-size/non-tech-tech than at OA-gated big tech).

They reward a CS/CE/SE student who can write object-oriented software in a listed language they can actually interview in, who has seen a real SDLC (code, test, Git, delivery), and who would not drown on a C++/Python product team shipping ATM software. Strong signals: JD languages demonstrated **inside bullets** (C++ for systems depth, Python for scripting/delivery; HTML/CSS and SQL through use where the work exists); object-oriented design in real components; unit-test / CI adjacency; shipped software with real users or a release artifact; deterministic or real-time constraints with metrics (latency, failure recovery, allocation/lock discipline). Prestige is a tiebreaker (`recruiting.md` intern §8). U.S. citizenship and possible security investigation are binary apply-form knockouts, not resume lines — do not claim an existing clearance. Class-year on the page must read as still enrolled through Summer 2027 (`Expected Month Year`); GPA 3.0 is a JD floor.

## Screen Criteria

- At least one JD language demonstrated **through use in bullets**, not Skills-only — C++ and Python (candidate-possessed). Java is a listed alternative, not a fabrication target.
- Full-stack / general-SWE spine: shipped applications, APIs/services, integration, test/CI, Git, object-oriented design — the literal intern filter.
- ATM / surveillance differentiator visible in the top half: real-time or deterministic constraints, concurrency/memory discipline, safety-adjacent systems, C++ OOP with a release artifact — without turning the page into a hobby-audio specialist packet or inventing radar/ADS-B/Linux-as-environment.
- Preferred stack through use where it exists (JavaScript/HTML/CSS, SQL, Git, unit tests) rather than stuffing unused JUnit/GTest/Subversion.
- Impact metrics that size performance, reliability, or scale — not vanity (uptime, LOC, coverage %).
- Anti-patterns: inventing Java; inventing Linux as a homelab; claiming an existing clearance; leading as an ML/agentic PE-deal intern; Skills-only language with no bullet evidence; club-ops filler; notebook ML without delivery; a pure web page with zero systems/real-time adjacency at an ATM software site.
