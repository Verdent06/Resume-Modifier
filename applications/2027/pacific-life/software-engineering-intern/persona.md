## Screen Criteria (abstract)

Pass signals:
- Shipped applications: frontend framework + backend/API + persistence or deploy, narrated decision-by-decision (`resume.md` §12). Keyword-through-use for Python, AWS, TypeScript/SQL if present — not Skills alone (`resume.md` §2).
- Business-problem-with-code: a manual process replaced, or a defect diagnosed, with a witness metric — the JD's "solving business problems with code" line.
- Delivery / automation analog: Docker, CI, or cloud deploy (EC2/S3) — the JD's software-delivery/automation and cloud-engineering exposure.
- Polyglot proof for languages the candidate actually has. JD names Java / C# as *or* with Python — **do not invent Java or C#**. Python through use beats a Skills-only claim.
- Finance-adjacent or complex business-workflow evidence as the company-fit differentiator (not invented policy-admin platforms).
- Cloud through use (AWS). Azure/GCP are "will consider," not fabrication targets.
- Metrics that size impact (error-rate, hours saved, latency, throughput), landed as the closer (`resume.md` §4).
- Class-year on the page: `Expected May 2028` — honest Junior / rising-junior standing for Summer 2027.
- SWE identity, not Data Engineering intern identity — a DE sibling is posted the same day at the same location.

Anti-patterns:
- Skills-line Java / C# / Azure / GCP / Snowflake / Databricks / Copilot / Fusion / FactSet / Azure DevOps with zero bullet evidence (fabrication smell).
- Inventing those tools, or claiming Pacific Life / policy-admin / actuarial internships the page cannot defend.
- Leading as a Data Engineering intern (title + ETL-only story) when a DE sibling req exists.
- ML-research / LoRA / notebook `model.fit()` as the first-pass identity when the role tests application delivery and business-problem-with-code (`recruiting.md` §13 applied vs research split).
- Off-axis lead: hard-real-time C++/audio-DSP or club-ops fronting an enterprise financial-services application-delivery intern req.
- Metric-free architecture bullets the recruiter cannot size.
- No live GitHub on an intern engineering resume (`resume.md` §3).
