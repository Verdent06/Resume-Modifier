# AMD

AMD designs CPUs, GPUs, and adaptive SoCs — Ryzen and EPYC on the CPU side, Radeon and Instinct on graphics and AI accelerators — and competes directly with NVIDIA in accelerated computing while remaining a full-stack silicon company. Intern SWE seats sit across application software, tools, drivers, and platform enablement, not a single chip-design desk. `reference/companies.md` B-TIER Notes flag that competition and a strong intern program, and rate AMD **B for SWE, not chip engineering**: this 2027 undergrad posting is a generic polyglot SWE catch-all (apps, SDLC, scripts, debug), not an RTL or physical-design req.

## Quick Facts

- **Tier:** B-TIER — Good / Solid Resume Addition (`reference/companies.md`)
- **HQ / offices:** Santa Clara, CA (HQ). Also Austin, TX (highest intern volume per program guides). This req: San Jose, CA or Santa Clara, CA.
- **Valuation / signal:** Public (NASDAQ: AMD); CPU/GPU competitor to NVIDIA; intern SWE prestige is solid B, not S-tier GPU lottery (`companies.md`: ~5–8%)
- **Product focus:** x86 CPUs, GPUs, and AI accelerators — plus the software that builds, tests, and ships them
- **Intern comp (2027 Undergrad Software Engineer Intern/Co-op):** USD $64,064.00/Yr – $96,096.00/Yr (JD)
- **Work model:** Paid full-time 40 hrs/week; hybrid or onsite for the full term. Terms: Spring/Summer Co-op Jan 15–Aug 13 2027; Summer intern May 24–Aug 13 2027 (semester) / Jun 21–Sep 10 2027 (quarter); Summer/Fall co-op May 24–Dec 10 2027 (semester). This posting is for an existing vacancy.
- **Clearance / eligibility:** Currently enrolled US-based university, Undergrad, CE/EE/CS or related. This role is not eligible for visa sponsorship. AMD may use AI to screen applicants.

## Stack & Hiring Signal

- **Languages:** C/C++, Python, JavaScript, Java, Perl, PowerShell, Linux shell — encouraged, not all required (JD)
- **Domains:** Application software (design/build/test/deploy); automation scripts; debugging; UNIX/Linux; databases (MySQL/PostgreSQL/MongoDB); cloud (Azure named); web frameworks (Django/Rails/Spring Boot); Git/GitHub/Perforce; security (OAuth/SSL/TLS); PC/CPU architecture and embedded/microcontroller as placement-adjacent, not the screen floor
- **What wins:** A full-stack intern spine (`resume.md` Part III §12 / `recruiting.md` Part III §11) with JD languages shown in bullets (especially Python and C++), plus visible systems / performance / real-time / embedded-adjacent depth so the page is memorable at a chip company. Do not invent Azure, Java, Perl, PowerShell, Django, Rails, Spring Boot, MongoDB, MySQL, Perforce, or UML. Workday-class knockouts (enrollment, no-sponsorship) are absolute (`recruiting.md` §8). Bottleneck after the PDF is tech rounds (`companies.md`).
