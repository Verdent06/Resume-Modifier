# Target (Tech)

Target is a Fortune 50 omni-channel retailer (NYSE: **TGT**) whose engineering org — **Target Tech** — builds the systems behind guest shopping online and in stores, plus the tools team members use to run the enterprise. The intern program is a real SWE seat at Target Headquarters (Brooklyn Park / Minneapolis), not a store job (`reference/companies.md` Notes). Interns pair into an engineering team for a 10-week summer and work on design, lifecycle, automation, debugging, and data-source/metadata literacy — generic product/platform SWE at retail scale.

This folder is the **Software Engineering Summer Internship-Minneapolis, MN (Starting June 2027)** Workday req **R0000451082** (`Software-Engineering-Summer-Internship-Minneapolis--MN--Starting-June-2027-_R0000451082`). Guest + store + team-member systems at Fortune 50 retail scale. Not Cloud/Compute platform, Developer Platform, or Cybersecurity sibling reqs.
