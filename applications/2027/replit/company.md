# Replit

Replit is the agentic software creation platform: a cloud browser IDE with real-time collaboration that lets anyone build applications in natural language. The product problem is developer-tools plus AI-agent infrastructure — an AI-powered development environment and the cloud systems that make fast multiplayer coding possible — aimed at removing traditional barriers to shipping software. Interns sit in a hybrid Foster City loop and are expected to ship real features to a large existing user base, not tutorial-grade side work.

## Quick Facts

- **Tier:** A-TIER (`reference/companies.md`)
- **HQ / offices:** Foster City, CA; intern hybrid with Mon/Wed/Fri in HQ
- **Valuation / signal:** $9B (Series D Mar 2026, $400M); targeting $1B ARR; 50M+ users; 501–1,000 employees
- **Product focus:** Agentic software creation / cloud browser IDE — AI-powered development environment plus collaboration infrastructure
- **Intern comp (2027 SWE):** Not listed in JD
- **Work model:** 12-week paid internship; Hybrid, Foster City, CA; Summer 2027
- **Clearance / eligibility:** Currently pursuing Bachelor's, Master's, or PhD in CS, CE, or related technical field; at least one semester of schooling remaining after internship completion. No citizenship gate in JD.

## Interview Process

| Stage | Format | Notes |
| ----- | ------ | ----- |
| Resume screen | Human + Ashby ATS | Human reads PDF earlier than Workday OA-gated big-tech; bottleneck starts here |
| Apply-gate (historical) | Timed Replit challenge | Built and submitted on Replit itself, typically <1 hour; no third-party OA |
| Recruiter | Phone / video | Career journey, goals, mission/operating principles; enrollment / remaining-semester check |
| Hiring manager | Deep dive | Experience and technical ability vs role expectations |
| Technical | Live or take-home, reviewed together | Project walkthrough, coding challenge, or take-home — practical, Replit-native, not LeetCode-first |
| Panel / Project Day | Team + stakeholders; some loops run a virtual Project Day | Technical, problem-solving, and behavioral; self-direction under a scoped mini-project |
| Offer | — | After panel |

**Estimated funnel:** 3–5 rds · Practical (Replit editor) · Timed Replit challenge (historical apply gate) / no third-party OA · Light · Bottleneck: resume + project day · <3%

## Stack & Hiring Signal

- **Languages:** TypeScript, Python, Go (company ship stack; JD names no required language beyond “at least one” plus full-stack comfort)
- **Domains:** Developer tools, cloud IDE / real-time collaboration, AI-agent tools and infrastructure, full-stack product, automation / self-healing systems
- **What wins:** Shipped full-stack work (web + API + deploy) with TypeScript or Python in bullets; visible agentic-product / eval / automation depth without flipping the page to ML research; cloud/container discipline; stories that show independent shipping plus cross-functional communication. Practical Replit-native loop, not LC grind (`recruiting.md` §5 startup/Ashby; §11 full-stack).
