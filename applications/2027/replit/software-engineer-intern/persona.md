# Software Engineer Intern at Replit

## Role Summary

Summer 2027 Software Engineer Intern — 12-week paid, hybrid Foster City, CA (Mon/Wed/Fri HQ). The intern ships real features on Replit's platform to a large developer user base, collaborates with engineers, designers, PMs, and AI researchers, and works across developer experience and the AI tools/infrastructure that power agentic software creation. JD surface is generic SWE intern: one language, full-stack comfort, remaining-semester eligibility, interest in developer tools / AI / accessibility. Company identity is an agentic cloud IDE — AI-powered software creation and the infrastructure behind fast collaboration — not an ML-research rotation.

## Track Decision

- **screen_track:** full-stack
- **differentiator:** agentic software creation / AI-powered cloud IDE / developer-tools + AI-agent infra
- **track_divergence:** true

Requirements literally test web/full-stack comfort plus proficiency in at least one programming language (`resume.md` Part III §12 / `recruiting.md` Part III §11). There is no training, inference-research, or data-pipeline bar, so the spine is not `ai-ml`. The differentiator is the company's product identity: agentic software creation, an AI-powered cloud IDE, and developer-tools plus AI-agent infrastructure. The resume leads with a full-stack spine and keeps differentiator-aligned evidence (agentic product, eval, automation, cloud/containers) prominent and deep — it does not flip the page into research ML.

## Team & Bar

Replit is A-TIER (`companies.md`): Ashby ATS, human reads the PDF earlier than Workday OA-gated big-tech; historical apply-gate is a timed challenge on Replit itself (no third-party OA); official loop is Recruiter → Hiring manager → Technical (live or take-home, reviewed together) → Panel / Project Day → Offer. Estimated funnel 3–5 rounds, practical not LeetCode-first; bottleneck is resume + project day; acceptance <3%. Recruiter voice: an intern who already ships full-stack features, can work independently, explains technical work to mixed audiences, and cares about developer tools, AI, or making building software more accessible. Strong signals: shipped systems with users; polyglot depth in bullets not Skills alone; agentic/eval/automation work that reads as engineered product; cloud/container delivery; measured reliability or self-healing — not notebook ML or club-ops.

## Screen Criteria

- Full-stack shipping with web, API, and a deploy or test path demonstrated in bullets — not Skills-only (`resume.md` §12). Breadth across the stack plus depth in at least one layer.
- At least one real language used inside an architectural decision. Company ship stack is TypeScript / Python / Go; do not treat an unnamed JD language as a hard filter, and do not invent Go.
- Differentiator visible in the top half: agentic product, eval/quality gates, automation of repetitive work, or AI-tooling/infra — not a buried AI label and not a research-track pivot.
- Cloud/container or CI evidence tied to delivery (Docker, AWS, GitHub Actions), matching a cloud-IDE company's operational bar.
- Quantified impact (latency, cost, accuracy, throughput, scale, reliability) so “ship to millions” and “self-healing / automation” claims can be sized.
- Independent ownership plus cross-functional communication somewhere on the page (sole-engineer delivery, stakeholder scoping, or a product with paying users).
- Anti-patterns: tutorial-grade projects; Skills-only TypeScript/Python; notebook ML without delivery; leading with an off-axis lane that buries developer-tools / agentic signal; thin filler; invented Copilot / Snowflake / Databricks / Fusion / Tableau.
