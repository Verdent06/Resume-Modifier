Company identity (`company.md` / `companies.md`): Fortune 100 mutual insurer and financial-services firm. Insurance/EAO applied analytics is **domain flavor on the same applied-GenAI spine**, not a second engineering track.

## Screen Criteria (abstract)

Pass signals:
- Hands-on LLMs, AI agents, and agentic workflows (multi-step orchestration, tool/model integration, structured output or eval) — not a thin API wrapper or a notebook demo.
- Retrieval / vector / RAG analog: embeddings, vector similarity search, or a retrieve-then-generate pipeline — the JD's "vector databases and RAG" line. Named pgvector/RAG through use beats a Skills-only claim.
- Evaluation / validation discipline: eval harnesses, held-out tests, faithfulness/accuracy lifts, or "robust model validation" analogs — EAO's stated methodological bar.
- Data plumbing for GenAI: ETL, freshness, serving APIs, or stores that feed a model/tool — analog to end-to-end solutions with business partners.
- Python demonstrated through use in bullets, not Skills alone. JD names Python as proficiency; orphaned AI buzzwords still fail.
- Cloud and container evidence (AWS/Docker; CI as a plus). Kubernetes is a plus, not an exclusive gate — do not invent it.
- Metrics that size impact (accuracy/faithfulness, latency, hours saved, throughput), landed as the closer (`resume.md` §4).
- Stats/technical coursework visible in Education is a plus for the "some statistical and/or technical background is preferred" line.

Anti-patterns:
- ML-research framing: publications, novel methods, notebook `model.fit()` with no agent, no pipeline, no delivery (`recruiting.md` §13 research vs applied split). This req is applied GenAI in EAO.
- Off-axis lead: pure frontend, pure audio-DSP, or club-ops fronting a GenAI intern req.
- Agentic/LLM/RAG/PyTorch claims only in Skills with no supporting system.
- Inventing TensorFlow, scikit-learn, Hugging Face Transformers-as-a-library, Kubernetes, Snowflake, Databricks, Tableau, Copilot, Fusion, or Sentry.
- Claiming insurance-domain internships, claims/underwriting models, or Nationwide platform experience the page cannot defend.
- Metric-free architecture bullets the recruiter cannot size.
- No live GitHub on an intern engineering resume (`resume.md` §3).
