# Honeywell Technologies

Honeywell Technologies (NASDAQ: **HON**) is the post-June-2026 **pure-play automation** company after the three-way split — buildings, industrial, and process automation — with Honeywell Technologies Accelerator and the **Honeywell Forge** intelligence layer on top of an installed-base control stack. JD copy: ~50,000 employees; Fortune 500 industrial brand. Pittsford, NY (1212 Pittsford-Victor Road) is **Honeywell Security Americas / LenelS2**: physical-security software (OnGuard, NetBox, Elements) for access control, video, and mobile credentialing, including **OnGuard Cloud** as single-tenant SaaS on AWS. Building-automation data-science work on access-control / security operational datasets sits at the same site (FTE Advanced Data Scientist analog **[directional]**). It is **not** Honeywell Aerospace (separate careers site), **not** Intelligrated/Mason OH, and **not** Experion process-controls.
