# Innovative Systems

Innovative Systems (FinScan) is a privately held Pittsburgh enterprise-software shop founded in 1968. It ships **FinScan** (AML/KYC screening used by enterprises in 60+ countries to identify potential money laundering and terrorist financing), **Enlighten** (data quality, matching, and deduplication), and **PostLocate** (global address validation). Delivery is on-prem, SaaS, and hybrid. Production full-time SWE analog is C# / .NET Core / Azure / SQL Server / REST (C + C# for CLIs); the intern posting is still generic Software Engineering — C# is not a knockout.
