# Software Engineering Internship Summer 2027 at United Launch Alliance (Denver)

## Role Summary

A Summer 2027 onsite software internship in Centennial / ULA–Denver (40 hours, ≥10 weeks). The intern architects, designs, develops, integrates, tests, and deploys software for applications environments, engineering simulation environments, and **embedded launch-vehicle flight and ground control**; maintains engineering software infrastructure for real-time systems, labs, and CI/CD; collaborates with hardware and analysis engineers on embedded and simulation software; applies SDLC standards and software quality control; does technical planning, requirements, system integration, V&V, cost and risk analysis; writes software that simulates physical systems and real-time operations; and builds GUIs / visualization tools — under mentors, with some shadowing of operations. The JD *requirements* are generic SWE intern gates: completed sophomore, GPA 3.00 cumulative no rounding, STEM bachelor, enrolled Fall 2027, 10 weeks Denver, **one of C++ / C / JavaScript / Python / Shell / Perl**, Microsoft Office, communication skills, U.S. Person / ITAR. Company identity is **launch-vehicle software** — Vulcan/Atlas-class flight and ground control, engineering simulation, mission-critical discipline — not SpaceX, not a mechanical intern, not an ML-research rotation. AI engineering is a subskill list item, not the requirements filter.
