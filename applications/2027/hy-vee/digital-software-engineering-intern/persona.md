# Persona — Digital Software Engineering Intern (Summer 2027)

Recruiter lens shared by the writer and grader. Abstract bar signals only — no candidate entry names, no include/omit table.

## Role Summary

A paid Summer 2027 in-person internship at Hy-Vee's Helpful Smiles Technology (HST) center in Grimes, Iowa (Workday req **R250133**; ATS location Corporate Office, Westown Pkwy, West Des Moines). Workday `remoteType` is **In Person**. Comp unlisted; up to (and potentially exceeding) 40 hours/week. Pre-employment drug screen.

Day-to-day is **grocery digital / business-application SWE**: collaborate with a development team, contribute to design and development of business applications, write unit tests for existing applications, develop reports in Microsoft Reporting Services, and support research projects with data retrieval and analysis in Microsoft SQL Server — Agile, coding standards, on-time attendance. Company identity (`company.md` / `companies.md`): employee-owned Midwest grocer whose HST campus ships e-commerce, mobile, supply chain, finance, and DW/BI systems. Surface work is generic intern SWE plus a SQL/reporting flavor — not an ML-research rotation, not a store job, and not the sibling Data Integration Intern.

## Team & Bar

Screener is an HST hiring manager plus a university recruiter reading Workday — resume-first intern funnel at a C-tier grocer IT campus, not a high-volume OA gauntlet (`recruiting.md` intern: OA binds at big-tech scale; here the resume carries the front-end weight). Funnel: resume screen → recruiter (auth, Grimes onsite, enrollment) → likely Easy tech + behavioral. Bottleneck is the resume (~15–25%). Evidence that wins: a shipped business application (API + data plumbing to a real stakeholder); SQL through use (queries, freshness, relational store) as analog to SQL Server retrieval; a dashboard/report analog; unit tests or a named production defect with a before/after; metrics that size impact. Recruiter voice is practical — "can this person ship an app, write tests, and pull data?" — not "did they intern in grocery POS" and not "did they publish an ML paper."

No GPA floor; 3.66 is a plus if they look. Working toward CS/MIS/SE/ME is the degree gate. US work-auth is a knockout if asked, not a resume line. Intern-stage weighting still favors engineered projects + a live GitHub (`resume.md` §9). SSRS and Microsoft SQL Server are intern tasks they will train on — do not invent them.

## Screen Criteria (abstract)

Pass signals:
- Shipped business application: REST/API or service, a real stakeholder or user, persistence or ETL, deploy analog (`resume.md` §12). Keyword-through-use for Python / TypeScript / SQL / React / Flask or FastAPI / Git / Docker in bullets, not Skills alone (`resume.md` §2).
- SQL / data-retrieval analog: queries, relational store, freshness, or ETL that replaces manual pulls — the JD's Microsoft SQL Server line. Honest SQL through use beats claiming SQL Server.
- Reporting / dashboard analog: a UI or served view over stored data — the JD's Microsoft Reporting Services line. Do not invent SSRS.
- Tests or production debug with a witness metric (unit tests for existing applications).
- Metrics that size impact (hours saved, failure-rate drop, throughput, precision), landed as the closer (`resume.md` §4).
- Class-year on the page: `Expected May 2028` — honest junior standing; satisfies working toward a degree for Summer 2027.

Anti-patterns:
- Inventing Microsoft SQL Server, SSRS, C#, .NET, Java, Snowflake, Databricks, Tableau, Copilot, Fusion, or Sentry.
- ML-research framing: LoRA-as-lead, publications, notebook `model.fit()` with no application, no tests, no delivery (`recruiting.md` §13 research vs applied split). This req is grocery digital SWE.
- Off-axis lead: pure audio-DSP, club-ops, or agent/RAG-as-the-job when the role tests business apps + SQL/reports.
- SQL / reporting / testing claims only in Skills with no supporting system.
- Claiming grocery, POS, Hy-Vee platform, or Aisle-app internships the page cannot defend.
- Metric-free architecture bullets the recruiter cannot size.
- No live GitHub on an intern engineering resume (`resume.md` §3).
