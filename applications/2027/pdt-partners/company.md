# PDT Partners

PDT Partners is a systematic quantitative investment manager founded in 1993 by Peter Muller as Process Driven Trading inside Morgan Stanley and spun out as an independent firm in 2013. Roughly 250 scientists, engineers, and professionals sit in New York and London; the firm is known for a scientific, model-driven approach to markets and a reputation that tracks quality of process rather than AUM size. Software engineers build and maintain the technology that enables the full trading life cycle — large-scale financial-data handling, real-time events, batch processing, infrastructure tooling, and dataset maintenance — not a customer-facing product org. Interns work on individual projects with senior developers; PDT does not currently run a quantitative-research internship.

## Quick Facts

- **Tier:** S-Tier (quant / systematic; added to `reference/companies.md` — C++/Python trading-lifecycle tech, $180k intern annualized)
- **HQ / offices:** New York, NY (this internship, onsite); London
- **Valuation / signal:** Privately held; 30+ year track record; Morgan Stanley spin-out; elite systematic-quant prestige; ~250 people
- **Product focus:** Proprietary trading-lifecycle technology — financial data, real-time event systems, batch processing, infra tooling, large-scale datasets
- **Intern comp (2027 SWE intern):** $180,000 (JD; not inclusive of bonus) — annualized intern quote
- **Work model:** Paid, onsite New York; 10 weeks (early June–mid August); individual projects + senior-developer mentorship
- **Clearance / eligibility:** Current Bachelor's / Master's / PhD in a rigorous technical field (e.g. CS, Computer Engineering); graduating Fall 2027 or later; eligible for full-time roles starting 2028 or 2029. Rolling review; feedback within ~3 weeks. Listing window reported ~July 30–August 30 2026.

## Stack & Hiring Signal

- **Languages:** C++ and Python are load-bearing for trading-lifecycle SWE (FT infra listings also name Java). Intern JD does not list languages; prove C++ and Python in bullets, not Skills-only.
- **Domains:** Real-time events, large financial-data handling, batch processing, infrastructure management tooling, large-scale datasets; program correctness (resource management, exception safety, reentrancy/thread safety), maintainability (unit testing, coding standards), efficiency (data structures/algorithms, parallelization).
- **What wins:** Strong CS fundamentals for a coding screen; real-time / concurrency / memory-discipline systems work that maps onto trading-lifecycle tech; Python data/batch/infra evidence; shipped, defensible projects. Prior trading-desk internship is not required — PDT teaches markets on the job. Do not screen as a quant-research intern (that program does not exist).
