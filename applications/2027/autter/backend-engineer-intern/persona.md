# Backend Engineer Intern (Agentic AI) at Autter

## Role Summary

An early-stage internship (full-time or near full-time on IST hours; remote, US-eligible) building and maintaining the backend services that power Autter's runtime-aware AI merge gate. The intern writes Node.js or Python backend code for PR analysis, works on agentic orchestration pipelines over LLM APIs (OpenAI/Anthropic), integrates the GitHub API and processes webhook events, writes scripts/tooling for analysis and testing pipelines, and helps improve the accuracy and speed of existing detection engines. The JD surface is backend software engineering; the company identity is developer tooling for AI-generated code — sandboxed PR execution, dependency verification, and detection engines. The memorable angle is agentic backend depth: LLM-API orchestration and evaluation discipline applied to a code-review product, not notebook ML and not pure frontend.

## Track Decision

- **screen_track:** full-stack (backend SWE)
- **differentiator:** agentic-AI / LLM-orchestration + developer-tooling (GitHub-App code review; detection-engine accuracy/speed)
- **track_divergence:** false

The JD's requirements literally test backend engineering (Node.js or Python services, REST/webhooks, GitHub API, scripting/tooling) fused with agentic orchestration over LLM APIs — so the resume spine is full-stack/backend, and the company's agentic-AI dev-tooling identity is carried by the *same* evidence rather than a competing track. This is not an ML-research screen (no training/inference required) and not a robotics or pure-frontend screen. The page should lead with a shipped, backend-heavy agentic system and keep LLM-API orchestration, containerized deployment, and eval/consensus rigor prominent; classic REST-API-on-cloud backend work reinforces the "can build and maintain services" bar.

## Team & Bar

The reviewer is effectively a founder at a 1–10 person startup reading resumes directly — a resume-first, ship-with-ambiguity funnel, not a high-volume campus OA. They reward candidates who have actually built agentic pipelines on LLM APIs (real orchestration, tool use, evals — not a single API call wrapped in a script), who own production backend services end to end (REST endpoints, queues, data layer, deployment), who show Docker/containerized delivery, and who demonstrate they can read and extend a codebase they did not write. Evidence of measurably improving a system's accuracy or latency maps directly to "improve accuracy and speed of existing detection engines." Genuine LLM curiosity (prompting, tool use, model trade-offs) and developer-tooling / open-source exposure are pluses. Anti-patterns: LLM/agent keywords listed in Skills with no bullet proof; notebook `model.fit()` with no service or pipeline; a page that reads pure frontend or pure data-analysis with backend bolted on; unquantified single-bullet entries where a system's impact should be sized.

## Screen Criteria

- A shipped, backend-oriented **agentic pipeline over LLM APIs** demonstrated in bullets — multi-step orchestration, tool use, or consensus/eval gates — not a bare "LLM" or "LangGraph" Skills mention.
- **Production backend service** evidence: REST API design, async queues/workers, a real data layer, and deployment (cloud or containerized) — the "build and maintain backend services" bar shown, not implied.
- **Docker / containerization** shown through real use (packaged pipeline or deployed stack), since it is a JD preferred and the product runs code in sandboxes.
- **Measured accuracy or latency improvement** on a system — a before/after number that maps to improving detection-engine accuracy and speed.
- **LLM-API integration and evaluation discipline** (OpenAI/Anthropic/Gemini prompting, adversarial evals, faithfulness/consensus gates) read as the skill the role wants sharpened.
- **GitHub API / webhooks** is a JD preferred; REST + webhook literacy and CI (GitHub Actions) reinforce it even when a verbatim "GitHub App" bullet is absent — do not fabricate it.
- Python demonstrated in bullets (JD accepts Node.js *or* Python; Python is the covered language) and present in the Languages skills line.
- Anti-patterns: leading with an off-axis lane (hard real-time audio DSP, fintech deal-sourcing without agentic/backend substance) that buries the agentic-backend story; agentic/LLM tools named only in Skills; metric-free ML/agent claims a founder cannot size.
