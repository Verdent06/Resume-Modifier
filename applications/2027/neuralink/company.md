# Neuralink

Neuralink builds implantable brain-computer interfaces — the N1 implant and supporting surgical robotics — that translate neural signals into actions so people can control computers and devices with thought. The company sits at the intersection of neuroscience, firmware, and production software: implant communication, manufacturing acceptance, design-control verification, and device monitoring are first-class engineering problems, not research notebooks. Culture is Musk-adjacent and meritocratic — high autonomy, urgency, and a stated preference for production-grade systems over research-grade prototypes. `reference/companies.md` has no Neuralink row; nearest published peers are SpaceX / Tesla (Musk-adjacent C++/Python systems, B-tier) and Medtronic (regulated medical-device software, B-tier).

- **Tier:** Unrated (`reference/companies.md` has no Neuralink row). Nearest peers: SpaceX, Tesla (Musk-adjacent brand + systems/embedded culture); Medtronic (medical-device / regulated software).

Clinical implants in humans since 2024; tiny intern cohort vs. FAANG volume.

- **Work model:** Paid, on-site required (Austin or South San Francisco). No intern relocation assistance. Interns excluded from equity / parental leave / flexible PTO; 401(k) after 1,000 hours. Form asks intern season and ideal start date.
- **Clearance / eligibility:** No class-year gate stated. Form asks US work authorization and sponsorship. On-site acknowledgment and self-funded relocate if not local.

## Stack & Hiring Signal

- **Languages:** Python and C or Rust (JD; “don’t get hung up — exceptional software engineer matters above all”). Linux/Unix + command line required. C++ is the common adjacent systems language in SWE interview writeups, not a named Implant-intern requirement.
- **Domains:** Implant / charger SDKs, firmware build tooling, manufacturing-line acceptance, design-control verification, implant recorder and monitoring — safety-critical / production software next to hardware.
- **What wins:** A full-stack intern spine (`resume.md` Part III §12 / `recruiting.md` Part III §11) with Python (and C or Rust if present) shown in bullets, plus visible production-vs-research discipline and real-time / systems / safety-adjacent depth so the page is memorable at a BCI company. Greenhouse + the exceptional-ability essay mean humans read the PDF early (`recruiting.md` §1: startups/mid-size Greenhouse — resume carries front-end weight). Club-ops filler and Skills-only language claims fail.
