## Screen Criteria (abstract)

Pass signals:
- Shipped web applications and APIs: frontend framework + REST/backend + persistence or deploy, narrated decision-by-decision (`resume.md` §12). Keyword-through-use for TypeScript, Angular (plus), REST, GitHub, cloud — not Skills alone (`resume.md` §2).
- Polyglot proof for languages the candidate actually has. JD names Java as *such as* / plus — **do not invent Java**. TypeScript / Python / SQL through use beats a Skills-only claim.
- Production support / troubleshooting analog: a user-facing failure, investigation, fix, witness metric — the JD's enhance/test/support and troubleshooting line.
- Client-facing or stakeholder delivery: scoped work with non-engineer partners (BA/PO analog), shipped inside a window.
- Cloud and CI evidence (AWS/Docker; GitHub Actions as GitHub/DevOps analog). Jenkins / SonarQube / JFrog are plus, not exclusive gates — do not invent them.
- Metrics that size impact (error-rate, hours saved, latency, throughput), landed as the closer (`resume.md` §4).
- Class-year on the page: `Expected May 2028` — honest incoming-junior standing for Summer 2027.

Anti-patterns:
- Skills-line Java / Jenkins / SonarQube / JFrog with zero bullet evidence (fabrication smell).
- Inventing insurance admin platforms, Snowflake, Databricks, Copilot, Fusion, or Tableau.
- ML-research / LoRA / notebook `model.fit()` as the first-pass identity when the role tests web apps, APIs, and production support (`recruiting.md` §13 applied vs research split). Approved AI tools are coding assistance, not the job.
- Off-axis lead: hard-real-time C++/audio-DSP or club-ops fronting an enterprise application-development intern req.
- Claiming National Life, LSW, inforce, or policy-admin internships the page cannot defend.
- Metric-free architecture bullets the recruiter cannot size.
- No live GitHub on an intern engineering resume (`resume.md` §3).
