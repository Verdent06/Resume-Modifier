# Full-Stack Web Developer Intern at Qorvo (req 10616)

## Role Summary

A paid Summer 2027 onsite intern in Qorvo's High Performance Analog group in Richardson, TX ($31–$42/hr). The intern owns architecture and front-end visualization of an internal engineering-documentation system: evaluate a web platform to host technical files, build a Python backend on MariaDB, and design a clean UI so analog engineers can view and interact with complex data. This is software next to RF/power silicon — not firmware, RTL, IC layout, or a generic SWE catch-all. Qorvo (NASDAQ: QRVO) supplies RF and power semiconductors for consumer, IoT, automotive/EV, infrastructure, healthcare, and aerospace/defense. Specific projects follow business need at assignment time.
