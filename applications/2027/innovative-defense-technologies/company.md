# Innovative Defense Technologies (IDT)

Innovative Defense Technologies (IDT) is a privately held defense-technology company that builds automated software testing, data analysis, and cybersecurity tools for U.S. Department of Defense mission-critical systems. Flagship identity is patented Automated Test and ReTest (ATRT) plus digital engineering / high-fidelity virtualization so new capability can be integrated, tested, and fielded faster on complex weapon and combat systems. Founded 2006; HQ Arlington, VA; offices also Massachusetts, New Jersey (Mount Laurel), and California (San Diego). This folder is the **Software Engineer Intern** Summer 2027 Pinpoint posting (**JobID-0308**, Mount Laurel, NJ) — catch-all SWE on Java/PostgreSQL backends and TypeScript/React UIs, not the Arlington **JobID-0302** Missile Defense intern sibling and not Software Test / Systems Engineer intern siblings.
