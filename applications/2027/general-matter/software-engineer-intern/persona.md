# Summer 2027 Internship - Software Engineering at General Matter

## Role Summary

A paid, onsite, 12-week Summer 2027 software engineering internship at General Matter's South Bay Los Angeles HQ ($32–$46/hr plus housing stipend). The intern writes performant, safe C++ and Python in an environment where reliability, performance, and safety are first-class — coordinating control systems, managing state across distributed hardware, processing high-throughput sensor telemetry, and building CI/CD/observability for production that has physical consequences. Cross-functional with EE, chemical, manufacturing, nuclear, materials, and physics. The JD surface is generic SWE: C++ and/or Python, algorithms, data structures, concurrency, system design. The company's identity is domestic uranium enrichment (LEU/HALEU) for advanced reactors — Founders Fund–incubated, hardware-adjacent, mission-critical — so the company-fit signal is systems discipline next to physical plant, not a consumer web app.

Prestige is a tiebreaker, not a gate (`recruiting.md` §8). Clearance eligibility and South Bay commute are apply-form knockouts, not resume lines.

## Screen Criteria

- JD languages shown through use in bullets — C++ and/or Python at minimum — not only on the Skills line. Both on the page is stronger than one; Skills-only C++ at a C++/Python floor company is a material gap.
- Broad SWE fundamentals on the page: services or APIs, data/pipelines, and some testing, CI/CD, or deployment (`resume.md` §12 keywords-through-use). Concurrency or system-design evidence in a bullet, not a coursework name alone.
- Metrics that size real outcomes (latency, throughput, failure recovery, cost, scale) — reliability and performance are listed job duties, not nice-to-haves.
- Differentiator visible in the top half: real-time constraints, C++ systems, fault-tolerant recovery, hardware-adjacent or safety-adjacent discipline — without turning the resume into a DSP-only or robotics-only document.
- Ownership and bias for action via shipped systems, defect/root-cause stories, and cross-functional or stakeholder delivery — not club-ops or membership filler.
- Anti-patterns: Skills-only polyglot stuffing; notebook ML or demo robotics with no engineering; a consumer-SaaS page with zero systems/C++ signal at an enrichment company; metric-free architecture claims; tutorial-grade projects; infra-buzzword stuffing (Kubernetes/Terraform) with no demonstrated use.
