# Software Engineering Intern, Backend (Summer 2027) at Robinhood

Recruiter lens shared by the writer and grader. Abstract bar signals only — no candidate entry names, no include/omit table.

## Role Summary

Campus backend SWE intern (Greenhouse **8123225** / req **1903**) on a Robinhood engineering team. Summer 2027 paid internship in **Bellevue, WA**, **Menlo Park, CA**, or **New York, NY**, hybrid **≥3 days/week** in office. Interns own a high-impact backend project from scoping through launch, partner with a mentor, and design/build/test/release software that meets the **correctness and scale** of a live financial platform. JD surface is generic backend SWE: CS fundamentals, communication under ambiguity, prior SWE from internships/hackathons/projects, familiarity with **Python/Django or Go**, and **relational databases and transactions**. Named stack as *such as*: Python/Django, Go, PostgreSQL, Kafka, Redis, Memcached, AWS, Kubernetes — company codebase, not a fabrication target. Company identity (`company.md` / `companies.md`) is **fintech-backend**: brokerage, crypto, and payments at consumer scale — not a trading desk, not an ML-research seat, and not SRE-as-primary.

- **differentiator:** fintech-backend
- **track_divergence:** false

Do not force an ML-training, autonomy/ROS, or hard-real-time C++/audio-DSP lead. Finance-adjacent correctness, transactions, and high-reliability production shipping are flavor on the same spine.

Intern-stage weighting still favors engineered projects plus live GitHub (`resume.md` Part II intern).

## Screen Criteria

**Pass signals (abstract):**

- Shipped backend or full-stack software: an API surface, a persistence decision (relational DB and/or cache), and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Tests, named debug, or a production defect through use matches "design, build, test, and release" on a live platform.
- Keyword-through-use for Python, PostgreSQL/Redis, backend, transactions or data integrity, scalability/correctness — not Skills-only (`resume.md` §2). JD languages are Python **or** Go; demonstrate Python in bullets. **Do not invent Django or Go.**
- CS fundamentals visible: DS&A coursework plus engineered work defensible in a Med–Hard CodeSignal OA (the post-screen equalizer; 800+ bar).
- End-to-end ownership of a scoped project (the intern's summer shape): problem → implementation → launch, not club-ops.
- Fintech-backend flavor on that spine: APIs, relational data, transactions/correctness, reliability or named production defects — memorable here without replacing the SWE spine.
- Class-year on the page: `Expected May 2028` satisfies Winter 2027 / Spring 2028.

**Anti-patterns:**

- Invented Django, Go, Kafka, Kubernetes, Memcached, Copilot, Snowflake, Databricks, Tableau, or Fusion.
- Claimed Robinhood employment or brokerage/crypto-protocol work that is not on the page.
- Agentic-AI / LoRA / notebook-ML as the first-pass identity.
- Hard-real-time C++/audio-DSP as the lead story when the role tests backend Python + relational data.
- Club-ops, community-growth, GTM/deal-sourcing, or coursework-only framing with no shipped backend.
- Thin single-bullet entries that dilute a production backend spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Skills-line technologies with zero bullet evidence where the recruiter would treat them as floor signals (Python, PostgreSQL, Redis).
