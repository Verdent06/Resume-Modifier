# RF-SMART

RF-SMART (legal: Information & Computing Services, Inc.; founded 1982) is a privately held warehouse-management, barcode, and inventory SaaS company. The flagship is native WMS for NetSuite (2,800+ customers / 40+ countries in `companies.md`) plus Oracle Cloud SCM and healthcare (SOC 2 / HIPAA); this intern posting cites 3,000+ customers across healthcare, manufacturing, and wholesale distribution. The Oracle Cloud product team builds mobile-first software that integrates with Oracle Cloud so warehouse teams scan, pick, and count with fewer errors.
