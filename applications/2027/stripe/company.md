# Stripe

Stripe builds programmable financial infrastructure: payments APIs, billing, payouts, fraud/risk, and adjacent money-movement products that businesses use as core production systems. More than ~5 million businesses run on Stripe; 2025 letter figures put total volume at $1.9T (~1.6% of global GDP). The intern SWE seat is a generic engineering rotation across the stack — recent intern projects include Payments Foundation Model / anomaly detection, fraud controls, safer payouts, and merchant checkout/pricing tooling — but the company's identity is high-reliability payments APIs, not a trading desk, not a consumer-app startup, and not an ML-research lab. `companies.md` A-TIER: top fintech eng bar; best fintech name on a resume.

## Stack & Hiring Signal

- **Languages:** Intern JD names **Ruby, Java, Javascript, Go, Scala** and states new languages can be learned if CS fundamentals are present. Screen tests languages the candidate actually ships — **do not invent Java, Ruby, Go, Scala, or a Skills-only Javascript token**. TypeScript is the honest JS-family analog when present
- **Domains:** Production financial APIs, payments, fraud/payouts, merchant checkout; code review; cross-functional delivery; AI tooling with critical review of outputs. Payments Foundation Model intern *examples* are project flavor, not an ML-framework hiring filter
- **What wins:** Shipped full-stack or backend software with APIs, persistence, and deploy/CI, plus finance-adjacent or high-reliability production shipping (`resume.md` Part III §12; `recruiting.md` Part III §11). Tech rounds are the bottleneck after the page; intern-stage weighting still favors engineered work plus live GitHub (`resume.md` Part II intern)
