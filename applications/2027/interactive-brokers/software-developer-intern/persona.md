# Software Developer Summer Internship – 2027 at Interactive Brokers

## Role Summary

Nine-week onsite SWE intern in Greenwich contributing to back, middle, and/or front-office projects: design, develop, and maintain software; own a mentored project; participate in code reviews. JD surface is generalist intern SWE — CS/SWE enrollment, GPA 3.5+, programming in C++, Java, or Python, DS&A/problem-solving, independent and collaborative delivery. Company identity is a technology-first electronic broker (automated execution and custody) whose production floor is high-performance C++/Java systems, not a generic web-app shop and not a quant research desk.

## Screen Criteria

- A JD language (C++ or Python; Java only if actually shipped) demonstrated in bullets — not Skills-only. IBKR's production culture weights C++/Java; intern posting still accepts Python.
- Shipped software with ownership: production APIs, release binaries, or mentored-project-shaped delivery with measurable outcomes — matches "own your project" + code review.
- Performance-sensitive or systems depth that reads as brokerage-adjacent (concurrency, real-time constraints, hot-path discipline, large-data services) without claiming exchange-matching experience that is not on the page.
- DS&A / analytical foundation visible (coursework + engineered projects defensible in a coding OA).
- Financial-markets or financial-data signal is a plus on a genuine engineering spine — not jargon padding.
- Class-year and GPA on page must satisfy the JD floor (`Expected May 2028`, GPA ≥ 3.5).
