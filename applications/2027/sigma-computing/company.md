# Sigma Computing

Sigma Computing is a warehouse-native analytics company: a spreadsheet interface (pivot tables, dashboards) that queries live cloud data warehouses without moving data, plus SQL, Python, and native AI in one governed workspace. Flagship product is **Sigma** (spreadsheet BI / AI Apps / agentic analytics). Customers include AMD, Duolingo, Colgate-Palmolive, and JPMorgan Chase. Engineering identity is **cloud-scale analytics UX + SQL translation + multi-tenant backend**, not a research lab and not Tableau-as-a-desktop-tool.
