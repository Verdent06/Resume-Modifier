# Waymo

Waymo is Alphabet's autonomous-driving company: the Waymo Driver (Level 4) powers a fully autonomous ride-hail service after spinning out of the Google Self-Driving Car Project. Software Engineering owns perception, decision-making, and the planner that has to be correct on public roads. This intern seat is **not** a generic SWE catch-all and **not** an ML-training / perception-research posting — it is **2027 Summer Intern, BS, Software Engineer, Driver Refinement Foundations** (Greenhouse **8224900** / req **5451**) on the Reasoning Platform team (foundational APIs and frameworks for Reasoning; interfaces from reasoning logic into the rest of the Waymo Planner, on and off the vehicle). The intern writes performant C++ autolabeler code to mine events from everyday driving, labels ground truth, evaluates autolabeler quality, and experiments on approaches and metrics.
