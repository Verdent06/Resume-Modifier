# 2027 Summer Intern, BS, Software Engineer, Driver Refinement Foundations at Waymo

## Role Summary

A paid hybrid-onsite Summer 2027 BS software internship in Mountain View ($60/hr). The intern sits on Waymo's Reasoning Platform team — foundational APIs and frameworks that connect reasoning logic to the rest of the Waymo Planner, on and off the vehicle — and writes performant C++ autolabeler code to mine useful events from everyday driving, labels ground truth, evaluates autolabeler quality, and experiments on approaches with reported metrics. The JD surface is C++ SWE plus algorithms, testing, and data/metrics — not an ML-training, perception-research, or ROS controls posting. Waymo's identity is Level 4 autonomy (the Waymo Driver); the company-fit signal is systems discipline on safety-adjacent driving software, not a consumer web app.

## Screen Criteria

- JD language shown through use in bullets — **C++** at minimum — not only on the Skills line. Python is the field's other core but is not named on this req; absence of Python in bullets is not a language-floor fail.
- Data + metrics on the page: pipelines, scoring, quality evaluation, or experiment-and-measure — the intern will evaluate autolabeler quality and design metrics.
- Testing or verification discipline visible (unit/integration/regression, CI, audit of a hot path) — Skills-only "testing" fails.
- Differentiator visible in the top half: C++ systems, real-time constraints, or event-mining / quality-eval analog — without inventing ROS, AV internships, or onboard planner work.
- Algorithms/data-structures credibility via coursework plus systems bullets a DS&A interviewer can probe; collaboration via shipped stakeholder or team-adjacent delivery.
- Anti-patterns: Skills-only C++; notebook ML as the lead; club-ops; claiming Linux/ROS/autonomous-robot software the page cannot defend; metric-free architecture claims; a pure agentic/SaaS page with C++ buried below the fold.
