# Software Engineer Intern — Summer 2027 at CACI (Ypsilanti RST)

## Role Summary

A Summer 2027 onsite software internship in Ypsilanti, MI on CACI’s Radar and Sensor Technologies Portfolio (ARKA/Willow Run heritage). The intern converts algorithm definitions and prototypes into software applications, learns radar phenomenology, participates in and leads code reviews, builds automated test and verification tools, writes well-tested code, works the full SDLC, and modernizes legacy code into current languages under mentors. The JD *requirements* are generic SWE intern gates: willingness to obtain Top Secret, a CS/EE/Math/Physics (or related) degree in progress, interest in remote sensing, and programming skill in **C++, Java, Rust, CUDA, or Python**, plus independent tasking on a large codebase. Company identity at this site is **SAR / low-observables / electro-optical remote-sensing software** — not Reston federal IT, not the Sarasota CACI intern, not an ML-research rotation.
