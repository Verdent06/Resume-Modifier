## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually ships (**Python**, **TypeScript**, **SQL**, **C++** if used). Keyword-through-use in bullets, not Skills-only (`resume.md` §2). **Do not invent Node.js, NestJS, Kubernetes, or React Native** — intern JD names no stack.
- Shipped full-stack or backend software: REST/APIs, a real frontend or client surface, a persistence decision, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12).
- Prior SWE internship **or** substantial personal/academic projects the candidate can narrate decision-by-decision (JD "You Bring").
- CS fundamentals visible: DS&A coursework plus engineered work defensible in a Technical / HM screen if invited.
- Modern practices through use: Git/version control, tests or CI, stakeholder or production delivery.
- Consumer-fintech / embedded-finance / fintech-backend flavor on that spine: production APIs, financial or regulated-data workflows, reliability/latency or named production defects — memorable here without replacing the SWE spine.
- Class-year on the page: `Expected May 2028` satisfies Fall 2027 / Spring 2028.

**Anti-patterns:**

- Skills-line Node.js / NestJS / Kubernetes / React Native with zero bullet evidence (fabrication smell at a TypeScript-on-Nest shop).
- Invented Snowflake, Databricks, Copilot, Fusion, or Tableau — banned; not in this JD and not in inventory.
- Invented banking-core, card-rail, or NestJS/K8s claims because the adjacent full-time posting named that stack.
- Agentic-AI / LoRA / notebook-ML lead as if this were the separate AI Research intern seat.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests generic SWE plus consumer-finance delivery.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + fintech-backend spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
