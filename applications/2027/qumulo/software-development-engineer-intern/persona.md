# Software Development Engineer Intern (Seattle, 2027) at Qumulo

## Role Summary

A paid 2027 internship (Winter, Spring, or Summer) on Qumulo's core engineering team in hybrid downtown Seattle (~3 days/week; $100,000 annualized / $1,900 per week plus relocation/transit as applicable). The intern is a full member of the product team — design, code review, pair programming, architecture with area leads — shipping customer-facing and internal features in C, Rust, and Python on a distributed storage engine, then debugging test failures and product issues. Not a siloed intern project. Company identity is a software-defined unstructured-data platform: a userspace distributed storage operating system (erasure-coded block layer, transactional file system, quotas/snapshots/replication) where 99% correct does not ship. Surface requirements are general SWE (DS&A, well-tested code, one of C/C++/Rust/Java/Go, CS/CE enrollment). Form knockouts (US work auth, no sponsorship, Seattle residency for the term) are apply-form gates, not resume lines.

## Screen Criteria

- JD languages the candidate actually has shown through use — **C++ and Python** in bullets, not Skills alone (`resume.md` §12 keywords-through-use). Rust/C/Java/Go are or-list floors, not a license to fabricate.
- Concurrent programming, memory discipline, or OS-adjacent hot-path constraints visible in the top half as the storage-company differentiator — framed as real-time/system software, never as an invented kernel, filesystem, or distributed-storage internship.
- Shipped application or service delivery (API, ETL, production debug, tests) so the full-stack spine is obvious: this intern still writes Python features and fixes test failures.
- Database *concepts* through use (schema, persistence, query path) if honest; do not invent Qumulo's block layer, NFS/SMB, or erasure coding.
- Metrics that size outcomes (latency, failure recovery, scale, hours saved) rather than vanity counts.
- Anti-patterns: Skills-only C++/Python; invented Rust/C/Java/Go/Linux; notebook ML or LoRA as the lead; club-ops filler; a PE/search-fund or voice-AI product story that buries concurrency and C++; claiming OS/compiler/storage-engine internships the page cannot defend.
