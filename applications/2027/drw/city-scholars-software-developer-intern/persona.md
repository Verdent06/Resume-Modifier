## Screen Criteria

- Production data ingest / catalog / serve evidence — pipelines that take messy feeds to a queryable or API-backed store — not notebook ETL.
- Real-time or high-performance systems depth: concurrency, memory discipline, latency/throughput, correctness under a hard constraint — the analog to networking / binary hot paths without faking exchange protocols.
- At least one interviewable systems language (C++ or Python) proven in **bullets**, not Skills-only. The JD lists no languages; inventing Java is worse than honest Python + C++.
- Cloud or production deploy in bullets (AWS/Docker/workers) — the JD names cloud scale.
- End-to-end ownership with metrics (latency, throughput, %, scale). Soft, metric-free shipping reads thin at a firm that cites 180B msgs/day.
- CS fundamentals visible (DS&A coursework + engineered systems) for an on-campus technical assessment.
- Markets curiosity without finance-jargon padding: econ/stats coursework or a rigorously evaluated financial-data system is enough; prior trading-desk experience is not required.
- Class-year on page shows a current CS (or related) undergraduate who returns to school after Spring 2027 (Expected May 2028 is in the form's Dec 2027–August 2028 bucket).
