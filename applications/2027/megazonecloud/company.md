# Megazone Cloud

Megazone Cloud (MegazoneCloud) is a Korea-founded 1998 cloud MSP and professional-services firm: first official AWS partner in Korea, APAC's largest AWS Premier consulting partner, and a Google Cloud partner. Directional scale is ~$1.8B revenue, ~2,700 people globally, 8,000+ clients. The US subsidiary (Ashby: Megazone Cloud US) is headquartered at 300 Willowbrook Office Park, Perinton/Fairport, NY; CEO Bob Moore (RIT CS alum; EagleDream Technologies founder → PwC AWS alliance). This req is a Rochester onsite **Software Engineer Co-op** on the US Tech team — client-facing full-stack delivery on internal and customer engagements — not the sibling **Data Engineer Co-op 2027** (Ashby `fde09888-986f-4207-88fe-3ff5b921a1fa`). RIT co-op is a named US hiring pipeline.

## Stack & Hiring Signal

- **Languages:** JD *or*-list: Python, Java, JavaScript, or Go. Screen on languages the candidate actually has — **Python through-use**; TypeScript / React / Angular as the JavaScript analog. Do **not** invent Java, Go, Azure, Terraform, Kubernetes, or AWS certifications.
- **Domains:** Full-stack design/dev/test/deploy; client-facing professional services; cloud infrastructure troubleshooting (AWS named; Azure as interest); CI/CD and Infrastructure as Code as *practices to lean into*, not a platform-SRE bar. GenAI / MLOps / Databricks / Snowflake are **bonus** on this SWE req — not the screen, and **not** to be invented.
- **What wins:** Resume-first C-tier MSP/consulting screen (`recruiting.md` intern: knockouts, then the PDF). Evidence of shipped full-stack (API + UI or a deployed backend), Python (and JS-family) in bullets not Skills alone, AWS/Docker/Git/CI through use, and client- or stakeholder-facing delivery. Do not lead as an ML-training intern because GenAI is a bonus. Do not flip to `dev-ops` solely because CI/CD/IaC appear as practices.
