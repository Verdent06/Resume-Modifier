# Apex

Apex (Apex Technology, Inc. / Apex Space) manufactures productized, configurable satellite buses — Aries, Nova, and Comet — at Factory One in Playa Vista, Los Angeles. Founded in 2022 by Ian Cinnamon (CEO) and Max Benassi (CTO), the company treats spacecraft as a manufacturing problem: software, vertical integration, and hardware designed for rate production rather than one-off custom buses. Ground software is the stack that operates those satellites (communication, control, telemetry, mission ops); it sits beside avionics, GNC, and mission services. Octopus is Apex's proprietary factory OS for inventory, scheduling, and assembly work instructions — manufacturing/ops software, not a candidate-claimable intern stack.

## Stack & Hiring Signal

- **Languages:** JD preferred: Rust, C/C++ backend, Vue or React frontend. Ground-software org (full-time postings, directional): Go, TypeScript, Python, Rust, Docker/Kubernetes/gRPC. Do not invent Rust or Vue on a resume that does not have them.
- **Domains:** Ground-segment software that operates satellites (design / develop / deploy); software architecture; backend + frontend; spacecraft ops. Distinct from the Embedded Systems intern twin (firmware / microcontrollers / flight software). Octopus is factory manufacturing OS — not this intern's claim.
- **What wins:** Shipped full-stack (architecture + backend + frontend + deploy) with C++ and/or React in bullets; systems / real-time discipline for the satellite-ops identity; no invented Rust/Vue; no firmware-only packaging (that's the Embedded twin). Greenhouse-style human PDF read on Ashby; then unpublished OA / practical + LA onsite. Club-ops filler and Skills-only C++/React fail the screen.
