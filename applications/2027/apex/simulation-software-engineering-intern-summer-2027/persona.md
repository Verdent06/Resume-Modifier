# Simulation Software Engineering Internship (Summer 2027) at Apex

## Role Summary

A paid, 12-week, onsite internship at Apex's Factory One in Playa Vista, Los Angeles ($45/hr). The intern contributes to **closed-loop spacecraft test platforms** — six-degree-of-freedom simulation (6DOF), software-in-the-loop (SITL), and hardware-in-the-loop (HITL) — and executes simulation testing strategies to validate and verify satellite performance, functionality, and reliability. The JD surface is C/C++ proficiency, a CS/CE/EE/AE (or related) degree, and modeling / embedded systems as a plus. Apex's identity is productized satellite-bus manufacturing (Aries / Nova / Comet) and mission-critical spacecraft V&V — not consumer CRUD, not the Ground Software intern twin (ops stack / architecture / frontend), and not the Embedded Systems intern twin (firmware / microcontrollers / flight software).

This application is **Summer 2027 only**. Spring requires pausing academics; the candidate is not targeting Spring.

- Real-time / closed-loop / deterministic discipline visible in the top half: hard latency bounds, lock-free or zero-allocation paths, test/audit checklists, validation gates — without turning the page into an embedded-firmware document (that's a sibling req) or a Ground Software React/architecture page (that's the other twin).
- Metrics that size real outcomes (latency, throughput, scale, failure recovery) rather than vanity counts or club-ops filler.
- Ownership via shipped systems and test/verify thinking — not membership filler, not notebook ML, not PE-deal-sourcing as the lead story.
- Anti-patterns: Skills-only C++; invented ROS / Gazebo / 6DOF / SITL / HITL / MATLAB / firmware / Octopus OS / satellite internships / clearance; Ground-Software packaging (Vue/React architecture as the spine); ML-research / LoRA / LangGraph as the lead; club-ops without engineering depth.
