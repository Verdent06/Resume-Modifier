# Ground Software Engineering Internship (Summer 2027) at Apex

## Role Summary

A paid, 12-week, onsite internship at Apex's Factory One in Playa Vista, Los Angeles ($45/hr). The intern is a fully integrated ground-software teammate contributing to the **design, development, and deployment of the software that operates Apex satellites** — scoped project ownership plus tickets across the ground stack. The JD surface is generic full-stack: software architecture; preferred Rust or C/C++ backend and Vue or React frontend; graduating Fall 2027 or Spring 2028. Apex's identity is productized satellite-bus manufacturing (Aries / Nova / Comet) and mission-critical spacecraft operations — not consumer CRUD and not the Embedded Systems intern twin (firmware / microcontrollers / flight software).

This application is **Summer 2027 only**. Spring requires pausing academics; the candidate is not targeting Spring.

The reviewer is an Apex ground-software intern screener on Ashby (human + ATS) before an unpublished OA/practical and a Los Angeles onsite (`companies.md`: bottleneck resume + tech; ~5–8% **[directional]**). Recruiter voice: can this intern design, ship, and deploy software that other people depend on, with enough systems seriousness to belong next to satellite ops — not a tutorial CRUD app. Strong signals: architecture decisions narrated in bullets; C++ and/or React demonstrated through use (JD preferred stack the page can actually prove); backend + frontend + deploy on the same page; visible real-time or systems discipline so the spacecraft-ops identity is memorable. Prestige is a tiebreaker, not a gate (`recruiting.md` §8). US Person is an apply-form knockout, not a resume line. Rust and Vue are preferred, not exclusive knockouts — inventing them is worse than omitting them.

## Screen Criteria

- JD languages shown through use in bullets where the inventory supports them — C++ and React at minimum — not only on the Skills line. Rust, Vue, and standalone C are named as preferred; absence is a gap only if the page also fails to prove architecture + backend + frontend + deploy another way. Invented Rust/Vue is an emergency-level fabrication smell.
- Software architecture visible as decisions (APIs/services, data/storage, frontend, deploy/cloud), not a Skills-line slogan (`resume.md` §12 keywords-through-use).
- Metrics that size real outcomes (latency, throughput, scale, failure recovery) rather than vanity counts or club-ops filler.
- Differentiator visible in the top half: real-time constraints, systems discipline, or mission-critical-adjacent rigor — without turning the page into an embedded-firmware document (that's the sibling req).
- Ownership via shipped systems used by others and end-to-end design/dev/deploy — not membership filler.
- Anti-patterns: Skills-only C++/React; invented Rust, Vue, C-as-distinct-from-C++, ROS, satellite/flight internships, Octopus OS, or clearance; Embedded-firmware packaging (microcontrollers, flight software, hardware bring-up as the lead story); club-ops without engineering depth; consumer-CRUD page with zero systems/real-time adjacency at a spacecraft manufacturer.
