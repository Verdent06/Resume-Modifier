Analog to reporting accuracy and sales-enablement products; not a claimed CRM admin seat.
- **Entity database → scored shortlist for a financial principal.** At Lyndbrook Capital I aggregated EPA ECHO and MassGIS into a PWSID entity database (800+ Day-1 targets), automated 15 hours/week of prospecting, and built a Review Velocity score that cut the list to 280 leads at 35% precision against the fund's revenue criteria. Analog to CRM-ecosystem / sales-enablement data, not Salesforce.
- **Data automation.** I run Vylet, a live PE/search-fund lead-sourcing product ($1,500 MRR, three paying clients). A Dockerized pipeline turned a ~30-minute manual process into 30 scored leads in 30 minutes (30x). The production DAL is asyncpg with injection-safe SQL timestamp checks that trigger re-scrapes. If you ask for a SQL impact number: the pool has none on that line — the outcome is freshness without manual intervention (`grade.md`).

I have not used Snowflake, Databricks, Copilot, Fusion, Tableau, Salesforce, Power BI, or Microsoft Access. I would ramp on GCG's approved stack rather than pretend I already have it.

I want this seat because Dimensional turns academic factor research into portfolios advisors actually use, and GCG Operations is the data layer that lets Sales see those client relationships.
