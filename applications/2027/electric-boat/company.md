# Electric Boat (General Dynamics)

General Dynamics Electric Boat is the nuclear-submarine OEM (GD business unit, est. 1899) that designs, builds, and modernizes U.S. Navy submarines. Groton, CT is HQ and the design yard; EB is prime for Virginia-class attack submarines and is in design on Columbia-class SSBNs. This intern seat is **IT / software / CS**, not hull design and not GDIT, and it is **not** the Gulfstream ASMI tooling intern. Memorable identity is shipyard IT plus the Software Engineering Group's custom automation in EB's newest CAD and PLM tools (automated CAD views, labels/dimensions, design/manufacturing interfaces, rules-based automations) — manufacturing-tooling software on a mission-critical submarine program, not a generic enterprise helpdesk.

## Stack & Hiring Signal

- **Languages:** Programming track **prefers Java** (coursework or related experience developing software applications; 1 year programming including internships/college projects). Java is preferred, not a hard knockout. Relational and object-oriented databases are desirable. Do **not** invent Java, Spring, CAD, CATIA, PLM APIs, or a clearance in hand. Honest intern proof is shipped application development (requirements → build → test/maintain) in languages the candidate actually has, plus a credible Java ramp story off-page.
- **Domains:** IT intern *pool*: Software engineering group (SEG) CAD/PLM automation; IT Infrastructure (Networks/Servers/Desktop/Storage); Cyber Security and compliance; Systems engineering (requirements for business systems); PMO; Finance and procurement; User production support. Typical tasks: requirement analysis and design; software application development (typically Java); testing and maintenance; investigation of advanced IT/software technology.
- **What wins:** Because there is no named OA, the PDF is the gate (`recruiting.md` Part III §11; mid-size/non-tech-tech is resume-first). A one-pager that shows shipped general SWE (application development, requirements, test/maintenance, relational DBs) **and** production-automation / mission-critical discipline matches SEG + shipyard IT. Do not lead as a CAD designer, a cyber-only intern (wrong req), or a GDIT contractor shop.
