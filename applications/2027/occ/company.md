# The Options Clearing Corporation (OCC)

The Options Clearing Corporation is the world's largest equity-derivatives clearinghouse (founded 1973). It is a designated systemically important financial market utility (SIFMU) under the SEC, CFTC, and Federal Reserve: central counterparty to **21** exchanges, serving **100+** clearing members for listed options, futures, and securities lending. LinkedIn **[directional]** ~2,615 employees / ~$451M. Flagship modernization is **Ovation**, the cloud successor to ENCORE. This folder is the **Summer Intern - Data** packet (Workday **REQ-4844**) — applied analytics warehouse work (SQL, Python, AWS, ETL/ELT, PostgreSQL, Tableau preferred, Claude Code in a regulated shop). **Not** Data Governance intern sibling, **not** Year-Round Intern - Data. Do not invent Tableau, Snowflake, Databricks, Kafka, Collibra, or Claude Code production claims.
