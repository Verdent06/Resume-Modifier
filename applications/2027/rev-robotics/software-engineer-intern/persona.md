# Software Engineering INTERN 2027 at REV Robotics

## Role Summary

A paid, **onsite Carrollton, TX** college internship ($18–$22/hr) providing software support for new and existing REV products. The intern contributes to **firmware for specific parts** *or* **end-user libraries and reference/example code** students use to program robots, plus testing, debugging, documentation, and demo/prototype robot programming. The JD surface is generic intern SWE: current Engineering/CS/Engineering-Technology student; C, Java, or JavaScript/TypeScript; Git/GitHub a plus; IDEs; independence. REV’s identity is educational robotics hardware for FIRST and STEM classrooms (SPARK MAX, Control Hub, student libraries) — not a ROS/autonomy research lab and not a consumer SaaS shop.

## Track Decision

- **screen_track:** full-stack
- **differentiator:** educational robotics / embedded firmware / student-facing libraries / FIRST hardware
- **track_divergence:** true

Required qualifications test current-student status and **one of** C / Java / JavaScript/TypeScript, plus independent work — the general SWE intern filter (`recruiting.md` Part III §11; `resume.md` Part III §12). They do not name ROS, SLAM, perception, or ML frameworks as a screen. The differentiator is the company’s FIRST-hardware identity (`companies.md`: firmware or student libraries; C++ a plus). The resume leads with a full-stack spine **and** keeps firmware-adjacent / real-time C++ / test-debug evidence prominent and deep. It does not become a hobby-audio-only page, a notebook-ML intern packet, or a fabricated FIRST/firmware/Java/C page.

## Team & Bar

The reviewer is a D-tier educational-robotics screener on Rippling before an unpublished small-office loop (`companies.md`: no OA; bottleneck resume + FIRST-preferred essay; ~20–30% directional). Recruiter voice: can this intern write C, Java, or JS/TS, follow directions, and independently help ship firmware or student libraries that FRC/FTC teams depend on? Strong signals: a JD language demonstrated inside bullets (TypeScript and/or C++); C++ real-time / deterministic / release-gate discipline so the firmware side is memorable; test, debug, or documentation-adjacent ownership; GitHub-visible collaborative work. FIRST team years are **preferred** and asked as a required long-answer — they are a form/essay signal, not a resume-line invention. Prestige is a tiebreaker, not a gate (`recruiting.md` §8). Work authorization / sponsorship and Carrollton in-office commute are apply-form knockouts, not resume lines.

## Screen Criteria

- At least one JD language demonstrated **in bullets**, not Skills-only — TypeScript (JS-family) and/or C++ (the named plus). Do not imply Java, C, or LabVIEW unless the work is real.
- Differentiator visible in the top half: real-time or embedded-adjacent C++, deterministic memory/concurrency, library-or-release packaging, test/debug on a physical-or-constrained system — without turning the page into a hobby-audio specialist packet or inventing robot firmware, WPILib, or FIRST team membership.
- General-SWE spine: shipped software, client or library users, Git/GitHub collaboration, independent delivery with metrics (failure recovery, latency, qualification rate, cost).
- Test/debug/documentation as job duties: root-cause stories and eval/release checklists beat “built an app.”
- Anti-patterns: inventing FIRST years, C, Java, LabVIEW, ROS, firmware-on-a-motor-controller, Snowflake, Databricks, Tableau, Copilot, or Fusion; C++ or TypeScript only in Skills; leading with agentic/LLM or PE-deal-sourcing framing as if this were an AI or fintech intern; club-ops filler; metric-free architecture claims; two-page or ATS-broken formatting.
