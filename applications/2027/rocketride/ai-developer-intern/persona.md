# Persona — AI Developer Intern, RocketRide

Recruiter lens shared by the writer and grader. Abstract bar signals only — no candidate entry names, no include/omit table.

## Role Summary

A hands-on applied-AI product internship at an open-source AI-infrastructure startup. The intern designs, builds, tests, and ships AI software components — vision models, LLM integrations, agentic workflows, multimodal data pipelines, and similarity search — using agentic AI code-generation tools, and the code commits to open source and deploys to production. JD surface: build real AI features across agentic orchestration, LLM integration, and data/similarity-search pipelines; gain hands-on experience with agent frameworks (OpenClaw, CrewAI), graph databases (neo4j), agent skills, MCP, and Cursor; contribute to open source and the developer community (Discord, forums, technical content, local AI events); collaborate with engineering, DevRel, and founders. Company identity: RocketRide is a developer-native, open-source AI pipeline platform (an "AIDE") whose runtime is a high-performance multithreaded C++ engine driving 13 LLM providers and 8 vector databases — so agentic-workflow fluency and vector/similarity search sit at the center, with performance-systems (C++) depth an explicit and rare "plus."

## Track Decision

- **screen_track:** `ai-ml` (applied GenAI / agentic-AI sub-bucket). The JD's requirements literally test LLM integrations, agentic workflows, multimodal data pipelines, and similarity/vector search, plus demonstrable understanding of LLMs, generative-AI applications, and agentic-AI concepts.
- **differentiator:** open-source, developer-native AI tooling built on a high-performance **C++** pipeline engine — the candidate is memorable here by pairing shipped agentic/LLM + vector-search work with (a) public/open-source contributions and (b) real C++/performance-systems depth that echoes RocketRide's engine ("C++ a plus," "the real stack, not toy projects").
- **track_divergence:** false. The company's engineering identity (open-source agentic-AI infrastructure) aligns with the JD's `ai-ml` screen track, so the resume grounds everything in `ai-ml`. C++ / performance-systems depth is a company-fit bonus surfaced within that spine, not a second track to protect.

## Team & Bar

Screener is a founder plus engineers at a small, open-source-first startup reading resumes and GitHub directly through an ATS — not a high-volume big-tech OA gauntlet. Funnel is resume-and-project-first: resume screen → technical/project deep-dive → team/founder fit. The bottleneck is a genuinely shipped agentic AI system the candidate can narrate decision-by-decision, plus evidence of open-source/public contribution and developer-community mindset (DevRel). Evidence that wins the screen: end-to-end agentic/LLM systems with real orchestration and evaluation, demonstrated similarity/vector search, Python (and TypeScript/C++) shown through use, and a live GitHub / shipped product. Prestige buys little at a small team; substance, defensibility, and open-source footprint win.

## Screen Criteria (abstract)

Pass signals:
- A shipped, end-to-end agentic AI system with real orchestration and evaluation (multi-step pipeline, tool/model integration, eval or guardrails) — not a notebook demo or a thin API wrapper.
- LLM integration and generative-AI application depth demonstrated in bullets (prompting/eval/structured output, model fine-tuning or adaptation), not asserted in Skills alone.
- Similarity / vector search demonstrated through use (embeddings + a vector store, with a latency or quality number), mirroring the platform's vector-DB core.
- Multimodal / data-pipeline engineering (ingestion → transform → serve) that shows production plumbing, not just modeling.
- Python demonstrated through use; TypeScript and especially **C++ / performance-systems depth** shown in a real entry read as a strong company-fit bonus (RocketRide's engine is C++), not padding.
- Public/open-source contribution signal: a live GitHub, a shipped/live product, or technical-content/community evidence — the JD explicitly requires public contributions.
- Metrics that size impact (accuracy lift, latency, cost/throughput), landed as the closer.

Anti-patterns:
- Agentic/LLM depth claimed only in a Skills list with no supporting shipped system.
- Off-axis lead: a pure data-engineering, pure-frontend, or non-AI entry fronting an applied-AI req.
- "Toy project" framing with no production/open-source deployment or defensible engineering decisions.
- Similarity/vector search or fine-tuning named without the decision and number that justify it.
- Metric-free bullets that leave the recruiter unable to size the work.
- No live GitHub / no public contribution evidence for an open-source-first team.
