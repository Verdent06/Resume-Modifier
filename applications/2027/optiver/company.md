# Optiver

Optiver is a technology- and research-driven market maker, founded in 1986 in Amsterdam, that provides liquidity across listed derivatives and related markets from offices including Chicago, Austin, Amsterdam, Sydney, London, and Shanghai. Engineers sit with traders and researchers and ship production software that prices, trades, and operates the firm — projects are scoped to real desk needs, not intern-only sandboxes, and code is expected to hit production. The SWE intern role is generalist high-bar engineering (C++, Python, or Java; CS fundamentals; performance, reliability, and scalability), not a quantitative-trading or research internship. Optiver is in the elite S-tier quant/HFT band alongside IMC, HRT, and Jane Street: early cycle, OA-gated, low-single-digit intern acceptance.

## Quick Facts

- **Tier:** S-Tier (quant / HFT; `reference/companies.md` row added this cycle — Chicago/Austin/AMS market-making peer of IMC)
- **HQ / offices:** Amsterdam (HQ); this internship is Chicago, IL onsite (Austin SWE intern posting is a separate req)
- **Valuation / signal:** Independent global market maker (~1,001–5,000 employees); options/listed-derivatives liquidity provider; elite resume brand in Chicago trading
- **Product focus:** Production trading systems — pricing, market-making infrastructure, reliability and performance of a global platform
- **Intern comp (2027 SWE intern, Chicago):** $80,000 USD base (JD good-faith range); Optiver-covered flights, living accommodations, and commuting stipends; breakfast/lunch/snacks
- **Work model:** Paid, onsite Chicago; ~10-week Summer 2027 internship with mentor + production project; rolling review
- **Clearance / eligibility:** Pursuing bachelor’s / master’s / PhD in Computer Science or Computer Engineering; graduate December 2027–June 2028; junior standing or higher. Sponsorship supported for this role. Global 8-month re-apply cool-off if the candidate already completed an OA or interviewed for a technology intern/grad role at any Optiver location.

## Interview Process

| Stage | Format | Notes |
| ----- | ------ | ----- |
| Resume screen | Human + ATS; often OA invite is near-immediate | Rolling; apply in the first wave |
| OA | HackerRank multi-part (~3 hrs): coding + CS-fundamentals MCQ + Zap-N / cognitive games | Highest-elimination stage; coding is OOP/implementation-heavy with sparse tests; MCQ covers DS&A, OS, networks |
| Recruiter / behavioral | ~20 min phone | Motivation, collaboration, why Optiver / why SWE not trading |
| Technical screen | Zoom / CodePair, ~45–60 min | Project deep-dive + live coding / DS implementation (queues, concurrency, OOP) |
| Super Day | 2–3 rounds: behavioral + algorithms/DS + low-level / systems design | CS theory (concurrency, memory, networking) shows up more than at generic SWE shops |

**Estimated funnel:** 4–5 rounds · Med–Hard · HackerRank (coding+CS MCQ+Zap-N) · Light intern sys design (low-level, not distributed) · Bottleneck: OA + tech rounds · ~1–2% acceptance (`reference/companies.md` S-tier; IMC peer band)

## Stack & Hiring Signal

- **Languages:** C++, Python, or Java (JD: proficient in at least one; polyglot is a plus, inventing Java is worse than honest C++ + Python depth)
- **Domains:** Performance, reliability, and scalability of production trading systems; clean architecture; CS fundamentals; collaboration with traders and business teams
- **What wins:** C++ and/or Python proven in real systems work (latency, concurrency, memory discipline, production shipping) — not Skills-only; well-architected, defensible projects; entrepreneurial ownership; genuine curiosity about how tech powers markets without finance-jargon padding. AI-enabled tools in the JD are trading/developer tooling, not an ML-research pivot. Per `reference/recruiting.md` Part I §1 the OA is the binding gate; the resume wins the human screen and team-match.
