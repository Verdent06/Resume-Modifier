# Software Engineering Intern — Summer 2027 at Collins Aerospace (RTX)

## Role Summary

A Summer 2027, full-time onsite avionics software internship in Cedar Rapids, IA. The intern joins a cross-functional agile team, works under a mentor using Collins engineering processes, and models and simulates Avionics Central Display Unit (CDU) control pages for the CDU 7000 suite that flies in US Army 160th SOAR, Marines, and Coast Guard helicopters — then demos the project at the Summer Engineering Project (SEPP) fair. The JD surface is generic SWE: enrolled in a Bachelor's+ program and coding in a higher-level language — Python first, or relevant languages C/C++/Java. The company's memorable engineering identity is object-oriented programming and threaded application development against real-time avionics display software (both are stated preferred quals), with simulation/modeling discipline on mission-critical systems.

## Track Decision

- **screen_track:** full-stack (general SWE)
- **differentiator:** real-time C++ / threaded application development (low-level OOP + multithreading/concurrency)
- **track_divergence:** true

So the resume spine is full-stack/general SWE. ## Team & Bar

The reviewer is a defense-prime engineering screener (RTX/Collins, C-tier funnel: 2–3 rounds, Easy practical difficulty, no OA, no system design, bottleneck: resume, ~20–25% offer rate). With no OA, the resume is the gate. They reward candidates who ship real, object-oriented software, can reason about threading/concurrency and real-time constraints, and would be productive on a mentor-guided simulation/modeling project. Strong signals: JD languages demonstrated inside bullets (Python prominently, C++ for the systems depth); object-oriented design and multithreaded/concurrent application development shown through real work; simulation/modeling or real-time adjacency; disciplined, defensible engineering with metrics that size outcomes (latency, throughput, failure recovery, scale); and clean agile/cross-functional delivery. Prestige is a tiebreaker, not a gate; U.S. citizenship is a separate binary apply-form knockout, not a resume item.

## Screen Criteria

- Demonstrates at least one JD language through use in bullets — Python (first-listed) prominently, and C/C++ where systems depth lives — not only in the Skills line.
- Shows object-oriented programming through real software (class modeling, encapsulation, ownership of a component), since advanced OOP is what the intern will practice and a stated preferred qual.
- Keeps threaded / concurrent / real-time application-development evidence visible in the top half (the company-fit differentiator, a preferred qual) without turning the page into a narrow embedded specialist or burying it at the bottom.
- Backs the full-stack spine with shipped, end-to-end delivery (APIs/services, data, deployment, ownership of something used by others) so the Python-forward screen is satisfied.
- Uses impact metrics (latency, throughput, performance/failure-recovery wins, scale) rather than vanity counts or club-ops filler.
- Anti-patterns: leading with agentic/LLM product framing as if this were an AI-research internship; a resume that reads purely web with zero concurrency/real-time/systems adjacency at an avionics company; skills-list keyword stuffing with no backing bullet; club membership without engineering depth; notebook ML without delivery.
