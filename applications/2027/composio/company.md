# Composio

Composio builds infrastructure so AI agents can talk to work tools — GitHub, Gmail, Notion, Salesforce, and 250+ others — through a unified API with auth, rate limits, and tool execution. The product surface this intern ships against is two web experiences: the developer dashboard ("Composio Platform") and the consumer connect flow ("Composio For You"), plus the SDK those UIs sit on. Technically the company lives at the agent–tool boundary: context and search problems, not model training. Customers named in the JD include Google, AWS, Mercor, Mintlify, Glean, and Emergent.
