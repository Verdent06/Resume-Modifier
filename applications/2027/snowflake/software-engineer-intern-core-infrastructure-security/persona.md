# Software Engineer Intern (Core, Infrastructure & Security) — Spring 2027 at Snowflake

## Role Summary

A paid Spring 2027 internship on Snowflake's core / infrastructure / security engineering org — on-site Menlo Park, CA or Bellevue, WA; $42–$60/hr; 12 weeks minimum, 16 recommended. Starts January 4 or 19, 2027; ends March 26, April 9, or May 7, 2027. The intern is team-matched across three domains: Core Engineering (platform, distributed processing, SaaS), Infrastructure Automation (release, test frameworks, cloud deploy, SPCS), and Security Engineering (encryption, SSO/OAuth, access control). Surface requirements are general SWE (Java/C++/Go/Python or-list, DS&A, systems programming / concurrency, 3rd/4th-year undergrad, enrolled during the term). DevOps tooling (Jenkins, Ansible, Terraform, Kubernetes, Docker) is a plus, not the floor. Form knockouts (sponsorship, 40-hour on-site presence, relocate/commute, US work auth, U.S. person) are apply-form gates, not resume lines. Not the AI/ML intern and not the Database Engineering intern.

## Track Decision

- **screen_track:** full-stack
- **differentiator:** data-infra / core systems (concurrency, cloud delivery, automation — Snowflake's data-cloud identity)
- **track_divergence:** true

Required qualifications test programming in a systems-family language, data structures and algorithms, object-oriented programming, and systems programming including multi-threading / concurrency. That is a general SWE intern screen (`recruiting.md` Part III §11; `resume.md` Part III §12) — not ML frameworks as the bar, not CI/CD-as-the-bar, not a crypto-research seat. The differentiator is Snowflake's data-cloud / core-infra identity (`companies.md`: distributed warehouse, multi-cloud, security and identity). The resume leads with a full-stack spine (shipped APIs, Python delivery, cloud, debug) **and** keeps C++ concurrent/memory/systems evidence prominent and deep. It does not collapse into a DSP-hobby page, a generic PE/agentic product resume with C++ buried, or an invented DevOps/K8s/Terraform resume.

## Team & Bar

The reviewer is a Snowflake university recruiter on Ashby (volume intern req; official FAQ: a coding assessment is the first interview step; `companies.md` CodeSignal, recent reports HackerRank **[directional]**). Bottleneck is **tech rounds** after the OA (`companies.md`; ~3–5%). Recruiter voice: can this intern write concurrent, correct systems-adjacent code and ship on a cloud platform — not a tutorial CRUD app, not a notebook. Strong signals: C++ and Python demonstrated in bullets; concurrency or memory-ownership decisions in the top half; a shipped system on AWS/Docker; DS&A coursework visible. Prestige is a tiebreaker (`recruiting.md` §8). Inventing Java, Go, Kubernetes, Terraform, Jenkins, or an OS class not on the Education line is worse than omitting them. On-site Menlo Park / Bellevue and no-sponsorship are form knockouts off the page.

## Screen Criteria

- JD languages the candidate actually has shown through use — **C++ and Python** in bullets, not Skills alone (`resume.md` §12 keywords-through-use). Java/Go are or-list floors, not a license to fabricate.
- Concurrent programming or memory discipline visible in the top half as the core-infra differentiator — framed as real-time/system software, never as an invented kernel, warehouse engine, or security internship.
- Shipped application or service delivery (API, ETL, production debug, cloud, CI) so the full-stack spine is obvious: this intern still writes Python features and fixes failures.
- Cloud / container evidence through use (AWS, Docker, CI) if honest; do not invent Kubernetes, Terraform, Jenkins, Ansible, or multi-cloud release automation.
- Metrics that size outcomes (latency, failure recovery, scale, hours saved) rather than vanity counts.
- Anti-patterns: Skills-only C++/Python; invented Java/Go/K8s/Terraform/OS coursework; notebook ML or LoRA as the lead; club-ops filler; a PE/search-fund or voice-AI product story that buries concurrency and C++; claiming cryptography, SSO, or warehouse-internals internships the page cannot defend.
