## Stack & Hiring Signal

- **Database Engineering languages:** JD floor is **C++ or Java** (preferred C++20/17 or Java 20/17). Screen **C++ through use**. Do **not** invent Java, C++20, Spark, Hadoop, FoundationDB, or Snowflake SQL as employer experience. SQL/Spark/Hadoop are *learn/gain*
- **Core / Infra / Security languages:** JD or-list **Java, C++, Go, and/or Python**. Screen **C++ and Python through use**. Do **not** invent Java, Go, Kubernetes, Terraform, Jenkins, Ansible
- **Database Engineering domains:** Query compilation/optimization/execution, FDB storage, Unistore HTAP, large-scale data processing, distributed systems. What wins: full-stack spine plus C++ concurrency/memory in the top half and honest database *concepts* — not a warehouse-admin intern
- **Core / Infra domains:** Distributed processing, SaaS platform, release/test/cloud deploy (SPCS), security (encryption, SSO/OAuth). What wins: C++ systems evidence **and** a shipped Python/cloud spine
- **Shared anti-patterns:** notebook ML as the lead; invented OS/compilers coursework; club-ops; PE/GTM story that buries concurrency and C++; claiming a Snowflake internship
