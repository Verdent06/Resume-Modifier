# Snowflake

Snowflake is a public data-cloud company (NYSE: **SNOW**): a multi-cloud SaaS platform for storage, compute, and governed data sharing on AWS, Azure, and GCP. The product is a distributed warehouse / data platform — query engine, cloud deployment, security and identity — not a consumer app. Intern engineering seats sit on that platform. This packet is **Software Engineer Intern (Core, Infrastructure & Security) — Spring 2027** only. Do **not** mix the sibling Spring 2027 Ashby reqs: **AI / ML** `4be290ae-dd9d-488c-9d90-56fcd69101ca` and **Database Engineering** `7bd393df-67d7-4009-ba4f-1cd79a82b0be`.

## Stack & Hiring Signal

- **Languages:** JD or-list **Java, C++, Go, and/or Python**. Preferred C++20/17 or Java 20/17. Screen for languages the candidate actually has — **C++ and Python through use**. Do **not** invent Java, Go, Kubernetes, Terraform, Jenkins, Ansible, or OS coursework not on the page.
- **Domains:** Core (distributed processing, SaaS platform), Infrastructure Automation (release / test / cloud deploy, SPCS), Security (encryption, SSO/OAuth, access control, network). Intern is team-matched across those three, not a named security-research seat.
- **What wins:** C++ systems evidence (concurrency, memory, hot-path discipline) **and** a shipped Python/cloud spine (API, AWS, Docker/CI, debug). DS&A fluency for the coding assessment. Anti-patterns: notebook ML as the lead; invented Java/Go/K8s/Terraform; a PE/GTM product story that buries concurrency and C++; claiming OS or crypto coursework the Education block does not list.
