# Axon Enterprise

Axon Enterprise (NASDAQ: AXON) builds public-safety technology used by law enforcement and first responders worldwide — TASER energy weapons, Axon body cameras and in-car systems (Axon Fleet), digital evidence management (Axon Evidence / Evidence.com), records and dispatch software, and AI-assisted tools like Draft One for report writing. Engineering ships cloud SaaS at scale on AWS alongside device firmware and real-time operations software; the stack historically centers on C#/.NET with substantial Java, Go, Python, TypeScript/React, and SQL/NoSQL data layers. For a software engineering intern, the screen tests generic OO-language product engineering end-to-end while the company identity is mission-critical public-safety cloud software where reliability, auditability, and stakeholder-facing delivery matter.

- **Languages:** C#/.NET historically dominant; Java, Go, Python, TypeScript/React, SQL per JD and public engineering footprint
