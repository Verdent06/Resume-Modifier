## Role Summary

A summer 2027 **block intern** on the Software Engineering team inside Moog's **Military Aircraft Group**, onsite in Mineral Wells, TX (Moog Avionics / former Genesys Aerosystems). Daily work is contributing to software engineering tasks, supporting engineers, and — depending on educational discipline — software development, integration, programming, and/or full lifecycle of **flight displays, radios, autopilot systems, and sensors**. The JD *surface* is generic intern SWE: enrolled in CS / CE / SE / EE, GPA 3.0+, export-controlled access, ability to relocate. Company identity (`company.md`) is mission-critical **avionics / flight-systems software** for military and special-mission aircraft — not an East Aurora actuation seat, not Space & Defense flight software, not a mechanical/design intern at the same site, and not a fabricated Ada/C/Java shop.

The reviewer is a defense/avionics engineering screener on a C-tier Moog funnel (`companies.md`: Workday resume → recruiter phone → HM/technical project walk → possible panel; Easy; no published intern OA on this Mineral Wells req; no intern sys design; bottleneck: resume; ~20–25%). They reward a CS/CE/SE/EE student who can write software they can actually interview in, who has seen a real SDLC (code, integration, test, delivery), and who would not drown on a multidisciplinary team shipping flight-display / radio / autopilot / sensor software. Strong signals: a real language demonstrated **inside bullets** (not Skills alone); shipped software with real users or a release artifact; integration of components; deterministic or real-time constraints with metrics (latency, failure recovery, allocation/lock discipline); test/CI adjacency. Prestige is a tiebreaker (`recruiting.md` intern §8). **U.S. person / citizenship** is the export-control apply-form knockout — signal eligibility honestly if asked; do **not** claim a clearance in-hand. Class-year on the page must read as still enrolled through Summer 2027 (`Expected Month Year`); GPA 3.0 is a JD floor.

## Screen Criteria

- At least one real programming language demonstrated **through use in bullets**, not Skills-only. The JD lists none — do not invent Ada, C, Java, C#, or MATLAB. Honest C++ (systems/real-time) and Python (delivery) through existing work is transferable proof.
- Full-stack / general-SWE spine: shipped applications, APIs/services, integration, test/CI, Git — the literal intern filter ("software development; software integration; software programming").
- Avionics / flight-systems differentiator visible in the top half: real-time or deterministic constraints, concurrency/memory discipline, mission-critical or safety-adjacent systems, a release or integration artifact — without turning the page into a hobby-audio specialist packet or inventing flight-display / radio / autopilot internships.
- Impact metrics that size performance, reliability, or scale — not vanity (uptime, LOC, coverage %).
- Anti-patterns: inventing Ada/C/Java/C#/MATLAB; inventing a clearance; leading as an ML/agentic PE-deal intern; Skills-only language with no bullet evidence; club-ops filler; notebook ML without delivery; a pure web page with zero systems/real-time adjacency at an avionics site.
