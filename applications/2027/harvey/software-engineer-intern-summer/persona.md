# Software Engineering Intern (Summer 2027) at Harvey

## Role Summary

Paid Summer 2027 SWE intern, Ashby location San Francisco, hybrid 3 days/week in the listed office (12 or 16 weeks; NY also on the same program family). Interns own a project end to end — code, test, deploy to production, present — on application-layer GenAI products used by lawyers doing high-stakes work. JD surface is generic SWE: CS fundamentals, one-or-more of Python / TypeScript-JavaScript / Java / Go, a prior internship, bias for action, simplicity, and daily AI-assisted development. Company identity is vertical legal AI (retrieval, assistants, enterprise agents, secure client data) — not a consumer CRUD shop and not an ML-research internship. Team match after the screen: Frontend, Backend, Full-Stack, Infrastructure, Applied AI (Agents, Assistant, Enterprise, Vault, Mobile, Infra, and others).

## Screen Criteria

- Production software demonstrated in bullets: APIs, pipelines, deploy/CI, a titled internship — not Skills-only claims.
- Prior internship visible as a titled experience — the JD names it as required.
- JD languages in bullets, not Skills alone: Python and/or TypeScript/JavaScript through use. Java and Go are or-list alternatives, not knockouts if the Python/TS spine is real.
- Full-stack product engineering with trade-offs the candidate can narrate (`resume.md` §12): frontend + backend/API + datastore + deploy.
- Retrieval / agentic / eval signal in the top half when present (company identity): semantic search, embeddings, quality gates, agent pipelines with numbers — not paper-abstract research and not a legal-internship claim.
- Shipped product used by someone other than the author (customers, operators, paying clients). Owner mentality evidenced as a diagnosed defect or end-to-end delivery (Job's Not Finished), not a slogan.
- Class-year on page: `Expected May 2028` clears December 2027 or later.

## Anti-Patterns

- Inventing Java, Go, Harvey Vault/Assistant usage, Claude Code, Codex, Kubernetes, or a legal-domain internship.
- Leading with LoRA / research-paper / `model.fit()` framing as if this were an ML-research intern seat.
- Club-ops, GTM/quant sourcing, or deal-flow work with no engineering the role tests.
- Notebook ML with no pipeline, API, retrieval, or deploy story.
- Thin single-bullet filler that dilutes a production + retrieval/agentic spine.
- Claims the candidate cannot defend in a 60-minute AI-assisted coding session.
- Remote-only or spoofed San Francisco home location on the form.
