## Screen Criteria

- Production software demonstrated in bullets: APIs, pipelines, deploy/CI, a titled internship — not Skills-only claims.
- Prior internship visible as a titled experience — the JD names it as required.
- Full-stack product engineering with trade-offs the candidate can narrate (`resume.md` §12): frontend + backend/API + datastore + deploy.
- Retrieval / eval / agentic signal in the top half when present (company identity): semantic search, embeddings, eval/quality gates, agent pipelines with numbers — not paper-abstract research.
- Shipped product used by someone other than the author (customers, operators, paying clients). Owner mentality evidenced as a diagnosed defect or end-to-end delivery, not a slogan.
- JD languages (Python and/or TypeScript) through use in bullets, not Skills alone. Java/Go are or-list, not a must if unproven.
- Quality-as-urgent: a named production defect or reliability path (lawyer users, high-stakes work).

## Anti-Patterns

- Inventing Java, Go, Kubernetes, Harvey Vault/Assistant usage, Copilot, Snowflake, Databricks.
- Leading with LoRA / research-paper / `model.fit()` framing as if this were an ML-research intern seat.
- Club-ops, GTM/quant sourcing, or deal-flow work with no engineering the role tests.
- Notebook ML with no pipeline, API, retrieval, eval, or deploy story.
- Thin single-bullet filler that dilutes a production + retrieval/eval spine.
- Claims the candidate cannot defend in an AI-assisted 60-minute coding round.
- Remote-only or refusing NYC/SF hybrid 3 days/week.
- Zero prior internships on the page.
