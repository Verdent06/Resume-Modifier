## Screen Criteria

**Pass signals (abstract — the writer discovers which entries carry them):**
- Python and SQL demonstrated through use in bullets, not only the Skills line (`resume.md` keyword-through-use).
- End-to-end data workflow: ingest messy or multi-source data → ETL/transform/normalize → validate or score → API, pipeline, or analytics/AI consumer → measured outcome (`resume.md` §14; `recruiting.md` §13).
- Data-engineering fluency as the spine: robust pipelines/architectures that make AI performant — analog to "pipelines that fuel generative AI," without claiming Deloitte production ownership.
- Applied LLM / vector / genAI / agentic evidence when it is a real system (orchestration, eval, embeddings, APIs such as Claude/OpenAI via actual use) — not a buzzword line.
- Forward-deployed / client-facing delivery kept visible in the lead window because of track divergence: stakeholder-scoped work, sole-engineer client contracts, consultant-shaped delivery — not hobby ML.
- Entrepreneurial or MVP signal (ship, iterate, paying or institutional users) as supporting evidence of "think like an entrepreneur, deliver like an engineer."
- Deployment/governance analog: eval gates, consensus/fail-closed checks, audit-ish validation — human checkpoints without inventing a governance product.
- Quantitative coursework (stats, calc, econ) visible in Education; class-year on page shows current enrollment (`Expected May 2028` is Spring 2028, matching graduate-by-Spring/Summer-2028). GPA 3.66 clears 3.0 / 3.2.

**Anti-patterns:**
- Generic SWE / full-stack product resume that never shows pipelines, SQL, or data activation — wrong scholar seat.
- Notebook ML or `model.fit()` with no pipeline, no client analog, no measured outcome.
- Skills-only Python/SQL/AWS/LLM with no bullet proof.
- Invented Tableau, Informatica, Hadoop, Spark, Power BI, R, Java, TensorFlow, Snowflake, Databricks, Copilot, or Fusion claims (JD names them as examples; stuffing them is a fabrication smell — `resume.md` §8).
- Club-ops or community-growth filler occupying prime slots.
- Pure audio-DSP / embedded C++ as the lead with no data/AI or client-delivery analog.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact.
- Treating this as GPS AI and Data Engineering (req 362479) or Forensic Analytics — different scholar postings.
- Claiming day-one ownership of a Big Four client's production platform.
