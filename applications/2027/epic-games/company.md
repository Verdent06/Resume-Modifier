# Epic Games

Epic Games builds Unreal Engine and ships Fortnite and other real-time entertainment titles; Unreal is the industry-standard engine for high-fidelity interactive 3D across games, film, automotive, and architecture. Engineering identity is **C++-heavy engine and tools work** — editor toolchain, content packaging/distribution/streaming, and game-scale systems — not generic web CRUD and not a frontend intern seat. HQ is Cary, NC (Raleigh metro); this intern req sits on Unreal Engine / Engineering Generalist. Best brand in gaming SWE (`companies.md` B-tier). **This intern is Tools Programmer Intern Greenhouse 6200355004 / req R27446 (Content Architecture, C++) — not the Build Operations Tools intern (gh_jid 6147167004, C# / GUI / CI telemetry) and not Frontend Programmer Intern (gh_jid 6173862004).**
