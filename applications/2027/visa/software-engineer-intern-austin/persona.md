## Role Summary

Twelve-week campus SWE intern on a Visa Technology and Operations team in **Austin, TX** (Workday REF088544W). Interns join a real engineering team on impactful projects that advance Visa's payments mission, with workshops, socials, and a final presentation to Visa leaders. JD surface is generic intern SWE: one or more of Java / C/C++ / C# / .NET / Python / JavaScript / HTML; automation/testing tools (Selenium, REST, Python, Groovy); software testing principles; full software lifecycle and secure coding. Example projects *could* include Kafka/Docker/Kubernetes self-serve, a knowledge-base chatbot, gas-station automated payments, low-latency automation, Visa Checkout usability, testing and visual monitoring tools, digital-currency routing, or a mobile-banking app factory — team-match flavor, not the screen filter. Company identity (`company.md` / `companies.md`) is **payments / fintech-backend / high-scale transaction systems** — a global payments network, not a trading desk, not a consumer-app startup, and not an ML-research seat. **This is the regular Software Engineer Intern Summer 2027 track, not the Sophomore Internship Program.**

## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has that the JD names (**Python**, **C++**, **HTML**; TypeScript covering the JavaScript area). Keyword-through-use in bullets, not Skills-only (`resume.md` §2). **Do not invent Java, C#, or .NET.**
- Shipped full-stack or backend software: REST/APIs or services, persistence, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Automated tests, Selenium/Playwright-class automation, debugging, or monitoring through use matches preferred testing tools and "testing tools / visual monitoring" example work.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an Easy–Med HackerRank OA and subsequent tech rounds (the funnel bottleneck).
- Modern practices through use: Git/version control, tests or CI, full software lifecycle, secure or production-disciplined shipping.
- Payments / fintech-backend / high-scale secure flavor on that spine: production APIs, financial or regulated-data workflows, reliability/latency discipline — memorable at Visa without replacing the SWE spine.
- Kafka / Kubernetes / chatbot / digital-currency as plus (example-project flavor), never as the lead story for a generic SWE intern req, and never invented.
- Class-year on the page: `Expected May 2028` satisfies graduating December 2027 – August 2028.

**Anti-patterns:**

- Skills-line Java/C#/.NET/Groovy/Kafka/Kubernetes with zero bullet evidence (fabrication smell at a polyglot floor-signal payments shop).
- Invented Snowflake, Databricks, Copilot, Fusion, Tableau, or Java employment — banned; not in this JD's honest inventory and not to be claimed.
- Invented chatbot/LLM-lead or notebook-ML as if this were an ML-research intern seat because one example project is a knowledge-base chatbot.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/API/cloud/payments SWE.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + payments-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Treating this req as the Sophomore Internship Program (wrong grad window / wrong track).
