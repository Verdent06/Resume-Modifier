## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages/frameworks the candidate actually has that the JD names (**Angular** / TypeScript covering the JS family). Keyword-through-use in bullets, not Skills-only (`resume.md` §2). **Do not invent Java, Spring Boot, or Node.js.**
- Shipped full-stack or backend software: REST/APIs or services, persistence, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Internal-tools / dashboard / workflow-automation analogs match the back-office paragraph.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an Easy coding screen if invited.
- Modern practices through use: Git/version control, tests or CI, Agile/stakeholder delivery.
- Enterprise-finance / bank-IT flavor on that spine: production APIs, financial or regulated-data workflows, reliability/audit-minded delivery — memorable here without replacing the SWE spine.
- Cloud-native / microservices / GenAI as plus (modernization flavor), never as the lead story for a generic SWE co-op, and never invented.
- Class-year and GPA on the page: `Expected May 2028` and GPA 3.66 satisfy rising-junior + 3.0 floor.

**Anti-patterns:**

- Skills-line Java / Spring Boot / Node.js with zero bullet evidence (fabrication smell at a shop that named those frameworks).
- Invented Snowflake, Databricks, Copilot, Fusion, Tableau, or Sentry — banned; not in this JD and not in inventory.
- Invented core-banking, card-network, or Java-microservice claims because the team paragraph named money movement / cards.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat (Jeanie's AI is flavor).
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/API/cloud/enterprise SWE.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + finance-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
