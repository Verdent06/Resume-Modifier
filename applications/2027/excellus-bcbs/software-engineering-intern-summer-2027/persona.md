# College Intern — Summer 2027 — Software Engineering at Excellus BCBS

## Role Summary

A paid 10-week Summer 2027 college internship (first Monday in June through second Friday in August; 2027 dates June 7 – August 13) on the Candesa Pharmacy Solutions development team at Excellus BlueCross BlueShield. The intern implements and tests application enhancements, completes conversion work, joins Agile ceremonies, and contributes through code reviews and technical discussion. Surface work is generic intern SWE. Company identity is a nonprofit Upstate NY Blue plan’s pharmacy-benefits engineering org — not a consumer web product, not a PBM-technician rotation, and not the non-SWE college-intern siblings posted the same day (Records, Internal Audit, Procurement, Sales).

## Track Decision

- **screen_track:** full-stack (general SWE)
- **differentiator:** healthcare-payer / pharmacy-benefits software (Candesa Pharmacy Solutions under Excellus BCBS — member-privacy constrained application delivery, not an invented claims or PBM internship)
- **track_divergence:** true

The literal requirements test Computing Sciences & IT (CS/SE/IT/Cyber or similar), continuous full-time enrollment, and good academic standing, with preferred (not required) Azure/AWS, C#, Angular, GIT, and Copilot-class AI tools. That is a general SWE screen (`recruiting.md` Part III §11; `resume.md` Part III §12), so the resume spine is full-stack: shipped applications, APIs, conversion-style data work, cloud, Git. The company-fit signal is software that has to be correct next to member data and a pharmacy-benefits product — application enhancement, defect RCA, conversion, Agile/code-review discipline — without inventing a Candesa, C#, or Copilot internship. Lead with the full-stack spine and keep Angular + cloud/Git + enhancement/defect evidence prominent and deep.

## Team & Bar

The reviewer is a C-tier regional-BCBS university recruiter (Workday `lthc.wd1` / ExcellusBCBSCareers; TA reach-out then hiring-manager interviews per the student careers page; no published intern OA; bottleneck: resume; ~20–30% directional, peer Wellmark UX SWE / BCBS MI / McKesson CMM). They route a generic intern resume onto a pharmacy-solutions application team whose day-to-day is enhancements, conversion, Agile, and code review — not a greenfield startup and not a helpdesk rotation. What wins: a shipped application or API with ownership and impact metrics; Angular and AWS/Git demonstrated in bullets, not Skills alone; enough defect-RCA / conversion / test evidence to be believable next to an existing codebase. Recruiter voice is practical — "can this person write, test, and ship application changes on a team?" — not "did they intern at a PBM." Prestige is a tiebreaker (`recruiting.md` §8). Enrollment + academic standing are knockout gates, not resume lines. Posted intern pay is $18–20/hr; housing is not provided.

## Screen Criteria

- Shows shipped application or data-system delivery (APIs, conversion/ETL, databases, production ownership, cloud) so the general-SWE screen is obvious.
- Demonstrates preferred-stack evidence through use where honest — Angular in a bullet, AWS/cloud in a bullet, Git/CI in a bullet — not a Skills-list dump.
- Keeps enhancement / defect-RCA / conversion / test evidence visible in the top half as the pharmacy-application differentiator, framed as application software — never as an invented Candesa, claims, HIPAA, or pharmacy-tech internship.
- Uses impact metrics (failure recovery, cost, hours saved, scale) rather than vanity counts.
- Anti-patterns: claiming C#, Azure, Github Copilot, Fusion, Snowflake, Databricks, Tableau, or pharmacy/PBM platforms the page cannot defend; a pure agentic/LLM product resume with no application delivery; notebook ML; club-ops filler; burying Angular/cloud/Git below the fold.
