Company identity (`company.md` / `companies.md`) is **ultra-low-latency electronic trading / derivatives-marketplace infrastructure** (Globex, risk systems, market architecture) — fintech-backend / market-infra, not a consumer-app shop, not a prop-trading desk, and not an ML-research seat. **This is not** Year-Long Technology Internship **34831** and **not** Software Engineering Fellowship **34824**.

## Screen Criteria

**Pass signals (abstract):**

- A JD language from the or-list demonstrated in **bullets**, not Skills alone. **Python satisfies Java and/or Python.** Listing Java with zero bullet evidence is worse than omitting it. Keyword-through-use (`resume.md` §2).
- Shipped full-stack or backend software: REST APIs, persistence/SQL, and deploy (Docker/cloud/CI) tied to an outcome (`resume.md` §12). Unit testing or CI through use matches the bonus list.
- Git and Linux/UNIX-adjacent tooling through use (Docker, CI, production deploy) — bonus stack proven in work, not a Skills dump.
- High-performance / real-time **systems** depth on the page: concurrency, lock-free or memory discipline, latency/throughput, production correctness — the exchange-adjacent signal that separates this firm from a generic SWE screen.
- Finance-adjacent or market-data / pipeline evidence as flavor on that spine — memorable at a derivatives marketplace without claiming Globex, matching-engine, or exchange internships.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in a coding pre-assessment and a subsequent virtual coding round.
- Class-year on the page: `Expected May 2028` (current student; still enrolled after Summer 2027). GPA ≥ 3.5 is a plus here (`resume.md` I.3); this JD does not print a GPA floor.

**Anti-patterns:**

- Java (or GCP, Kubernetes, Maven, IntelliJ) named in Skills with zero bullet evidence — fabrication smell at a shop that lists those as bonus/stack.
- Invented Globex, matching-engine, or derivatives-trading internships.
- Re-targeting to an ML-research / LoRA / agent-pipeline lead as if this were an AI-agents internship because past interns designed AI agents.
- All-CRUD / all-web-app page with no systems-performance or finance-adjacent signal — reads generic at a firm whose identity is ultra-low-latency trading infrastructure.
- Python named in Skills with zero bullet evidence.
- SQL named in Skills with zero bullet evidence.
- Club-ops, community-growth, or CAD/mechanical filler with no software the role tests.
- Soft, metric-free shipping claims where reliability, scale, and performance are the firm's selling point.
- Thin single-bullet entries that dilute a full-stack + systems/fintech spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Treating this req as Year-Long Technology Internship **34831** or Software Engineering Fellowship **34824**.
