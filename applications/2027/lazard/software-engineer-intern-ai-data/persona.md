## Screen Criteria

**Pass signals (abstract — the writer discovers which entries carry them):**
- Python demonstrated through use in bullets, not only the Skills line (`resume.md` keyword-through-use); object-oriented or staged pipeline design visible in engineered Python.
- Full-stack / SDLC analog: requirements or stakeholder scoping → design/build → test or eval → maintain/deploy (Git, CI/CD, containers, cloud).
- Relational and NoSQL through use (SQL/Postgres-class and Redis-class), not Skills-only.
- Data-intensive applications: ETL or pipelines at countable scale, served through an API or product, with impact metrics a recruiter can size in 30 seconds.
- Applied LLM / agentic / eval / embeddings signal in the top half when present (JD familiarity + interest lines): eval harnesses, quality gates, agent pipelines, embedding stores — not paper-abstract research.
- Shipped work used by someone other than the author (clients, operators, internal stakeholders).
- Class-year on page: `Expected May 2028` shows still enrolled for a Summer 2027 intern. GPA 3.66 is a genuine signal (`resume.md` GPA ≥ 3.5).

**Anti-patterns:**
- Notebook ML or `model.fit()` / LoRA / research-paper framing as the lead — this is applied AI software on a data-product intern, not an ML-research seat (`recruiting.md` §13 split).
- IBD-analyst resume: deal-flow, pitch-book, or markets storytelling with no engineering the role tests.
- Skills-only JD languages (Python listed, never used in bullets).
- Club-ops or community-growth filler occupying prime slots.
- Invented Java, JavaScript-as-required, MySQL, MongoDB, ElasticSearch, Airflow, Prefect, Kubernetes, MCP-as-used, Snowflake, Databricks, Copilot, Fusion, Tableau.
- Thin single-bullet filler that dilutes a production + pipeline spine.
- Pure audio-DSP / embedded systems as the lead with no data-product analog.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact.
