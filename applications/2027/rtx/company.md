# RTX (Raytheon)

RTX (formerly Raytheon Technologies) is one of the largest U.S. aerospace and defense primes, with Raytheon as its missile-and-defense segment. The Huntsville, AL site (Redstone Arsenal corridor) supports missile-defense and integrated air-and-missile-defense programs, where software teams build, integrate, and test command-and-control and sensor/effector software on Unix/Linux platforms. Intern software work here is developer-and-integrator work on mission-critical systems: writing Java/Python components, integrating applications from many sources, and holding a high testing/code-review/documentation bar rather than research or greenfield product invention.

## Quick Facts

- **Tier:** C-tier (traditional defense prime; slow pace, ongoing restructuring)
- **HQ / offices:** Arlington, VA (RTX corporate); this req is US-AL-Huntsville (382 / 420 Jan Davis Dr)
- **Valuation / signal:** Fortune 500 defense prime; stable brand, moderate SWE prestige signal
- **Product focus:** Missile defense, integrated air-and-missile-defense, sensors, and mission-critical C2 software
- **Intern comp (2027 SWE):** Not stated in JD (defense primes ~$30-40/hr range per reference/companies.md)
- **Work model:** Onsite, Summer 2027 internship, Huntsville AL
- **Clearance / eligibility:** Must be able to obtain and maintain a U.S. government security clearance; U.S. citizenship required. Enrolled in a Bachelor's+ CS/CompE/SWE program, at least sophomore/junior/senior/post-grad standing by summer 2027.

## Stack & Hiring Signal

- **Languages:** Java (required, Unix/Linux env), Python (scripting, preferred); JavaScript framework (AngularJS/VueJS) preferred
- **Domains:** Mission-critical defense software; application integration; test/coverage discipline; CI (Jenkins/Maven/GitLab)
- **What wins:** Demonstrated software development in a Unix/Linux environment, real integration of components from multiple sources, disciplined unit testing / code coverage / code reviews, and version control + CI fluency. A resume that shows shipped, integrated, well-tested software (not just notebooks) with Python + a JS framework and CI passes this screen; the resume is the gate since there is no OA.
