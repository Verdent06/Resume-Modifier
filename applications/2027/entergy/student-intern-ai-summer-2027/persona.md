## Screen Criteria (abstract)

Pass signals:
- Hands-on AI agents (multi-step orchestration, tool/model integration, structured output or eval) — not a thin chatbot wrapper or a notebook demo.
- Workflow / process automation with a before/after: pipelines that replace manual work, scored throughput, or recurring workers — the JD's HR/ESS automation line (onboarding, benefits, service requests as *analogs*, not invented HR-system internships).
- Agent testing / validation discipline: eval harnesses, tests, faithfulness/quality lifts, edge-case coverage — "test and validate agent functionality across different use cases and edge cases."
- Process documentation / stakeholder analog: documenting current-state or serving output to non-ML users (HR/ESS partner collaboration, solution-design docs, contract/API ownership).
- Python through use is the honest engineering overlap; the JD names no programming language. Claude (LLM vendor) through use is allowed via inventory swap sets. Do not treat Copilot Studio or Power tools as candidate skills.
- Metrics that size impact (hours saved, quality/faithfulness, throughput), landed as the closer (`resume.md` §4).
- Utility-adjacent operations or regulated-industry process work is a plus for the differentiator, but not a fabricated electric-utility or Copilot internship.

Anti-patterns:
- ML-research framing: publications, novel methods, LoRA/`model.fit()` as the identity with no agent, no automation, no delivery (`recruiting.md` §13 research vs applied split). This req is applied AI Agent Development in HR/ESS.
- Off-axis lead: pure C++ audio-DSP, club-ops, or a generic SWE identity with agents buried.
- Agentic/LLM claims only in Skills with no supporting system.
- **Inventing Copilot, Copilot Studio, GitHub Copilot, Power Automate, Power Apps, Power Platform, Microsoft 365, Snowflake, Databricks, Tableau, or Fusion CAD.** Shop flavor on the JD is not a license to claim those tools.
- Claiming HRIS/Workday-HCM internships or Entergy platform experience the page cannot defend.
- Metric-free architecture bullets the recruiter cannot size.
- No live GitHub on an intern engineering resume (`resume.md` §3).
