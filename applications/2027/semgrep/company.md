# Semgrep

Semgrep is a developer-first AppSec company: static analysis (SAST), software composition analysis (SCA), and secrets detection that lives in the write/review loop rather than a separate security queue. The open-source Semgrep engine plus the commercial AppSec Platform (Code, Supply Chain, Secrets) is the product — catch reachable issues, cut false positives, and ship fixes without breaking developer flow. Cloud Platform intern work is full-stack product and reliability on that platform (Python / PostgreSQL / TypeScript / React), not the Program Analysis intern seat (OCaml / Haskell / compilers).
