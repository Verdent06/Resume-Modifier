# Software Engineer Intern (Summer 2027) at Affirm

Recruiter lens shared by the writer and grader. Abstract bar signals only — no candidate entry names, no include/omit table.

## Role Summary

Twelve-to-sixteen-week paid SWE intern on Affirm Consumer Engineering. Interns spec a project with a mentor and manager, **ship it to production**, monitor the deployment, and present to the engineering org — not a throwaway intern sandbox. JD surface is **generic intern SWE**: Python, C/C++ or Java; frontend WebApps / JavaScript / AngularJS / React; OOP; deployment and testing frameworks; API development/documentation; AWS or other PaaS; communication. Company identity (`company.md`) is **consumer-fintech / BNPL / honest installment lending / fintech-backend** — checkout credit, loan servicing, merchant APIs — not a trading desk and not an ML-research seat.

## Track Decision

- **screen_track:** `full-stack`
- **differentiator:** consumer-fintech / BNPL / honest consumer lending / fintech-backend
- **track_divergence:** true

Requirements literally test general SWE (`resume.md` Part III §12; `recruiting.md` Part III §11): languages, frontend, APIs, OOP, deploy/test, AWS. That routes to `full-stack` (default for a generic SWE intern req). Do **not** route `ai-ml` because past intern examples mention data pipelines, and do **not** route `dev-ops` because CI/CD is a listed skill not the role's identity.

The company's dominant engineering identity is **consumer money-movement and lending-backend at checkout scale**. That identity is distinct from generic product-SWE, so divergence is true: the resume leads with the `full-stack` spine **and** keeps finance-adjacent / production-API / reliability shipping prominent in the lead window. Do not lead as notebook ML, agentic-research, or hard-real-time C++/audio-DSP as the first-pass identity — C++ is a JD or-list language, not the company story.

## Team & Bar

Affirm is **B-tier** (`companies.md` B-TIER — public consumer BNPL, $55/hr intern): Greenhouse resume → OA (HackerRank 3Q **[directional]** or CodeSignal GCF on some SWE roles **[directional]**) → recruiter → two practical coding finals → behavioral/manager. **Bottleneck: OA then tech.** Recruiter voice: a consumer-fintech campus screener looking for an eligible intern who already ships APIs/UIs they can walk through, who can talk Python or C++ without claiming Java they did not use, and who sounds like they would own a production slice rather than a class project.

No class-year or GPA gate on this JD. Graduation Expected May 2028 is fine. Dual sponsorship Booleans are knockouts (`recruiting.md` Part I §1). Comp: $55/hour / $9,500/month. Posted 2026-10-02 — first wave (`recruiting.md` Part II §8).

Winning *kinds* of evidence: JD languages the candidate actually has, demonstrated in bullets not Skills alone; a shippable product or production REST API with a persistence decision and a deploy path; frontend through use (React or Angular, not a Skills-only JavaScript claim); tests/CI or release discipline; finance-adjacent or data-integrity delivery as flavor. Intern-stage weighting still favors engineered projects plus live GitHub (`resume.md` Part II intern).

## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually ships that the JD names (**Python**, **C++**). Keyword-through-use in bullets, not Skills-only (`resume.md` §2). **Do not invent Java or AngularJS.** TypeScript covering JavaScript/React is honest; C++ must not be Skills-only if listed.
- Shipped full-stack or backend software: REST/APIs, a real frontend or client surface, a persistence decision, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12).
- Deployment and testing through use: CI, pytest, release/audit, or production defect RCA — the JD names deployment/testing frameworks because intern work ships.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in a HackerRank/CodeSignal OA.
- Consumer-fintech / BNPL / fintech-backend flavor on that spine: production APIs, financial or regulated-data workflows, reliability/latency or named production defects — memorable here without replacing the SWE spine.
- Class-year on the page: `Expected May 2028` with no JD window conflict.

**Anti-patterns:**

- Skills-line Java / AngularJS / Kafka with zero bullet evidence (fabrication smell at a polyglot floor-signal shop).
- Invented Shopify-style Go, or BNPL/ledger/underwriting claims the pool does not carry.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/API/cloud consumer-finance SWE (C++ still needs bullet proof if it is in Skills).
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + fintech-backend spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
