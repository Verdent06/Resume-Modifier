**Pass signals (abstract — the writer discovers which entries carry them):**

- Shipped full-stack or backend software used in a real workflow — coding through use, not a skills dump (`resume.md` §12). Maps to "build full-stack software that will be used daily in our production environment."
- Polyglot proof for languages the candidate actually has that the JD names (**Python**, **TypeScript** / JavaScript-family). Keyword-through-use in bullets. **Do not invent Ruby.**
- Git / version control through use (GitHub, CI). JD lists git as a proficiency floor.
- Quality analog: tests, debugging, or a named defect fix — "security, compliance, quality, and design as part of every change."
- Cloud/deploy tied to an outcome (AWS/Docker/CI) as production-path evidence, not an SRE exclusive.
- Stakeholder or PM-adjacent delivery (user stories → shipped software; code other people used).
- Consumer-finance / messy-data / payments-adjacent flavor on that spine without claiming Acima underwriting.
- Class-year and GPA on the page: `Expected May 2028` and `3.66` satisfy May 2027–May 2028 and 3.2.

**Anti-patterns:**

- Invented Acima lease-to-own, retailer-kiosk, or underwriting claims because the brand is on the JD — analog shipping, not product ownership.
- Treating this as **Upbound (Crossplane)** cloud-control-plane / Kubernetes intern, or applying the Plano **R-100761** "assist SDLC / no languages" lens as if git and Python/TS were unstated.
- ML-research / LoRA / notebook-ML lead because the tools line named AI agents.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests production web/API full-stack.
- Club-ops or community-growth filler occupying prime slots.

- Thin single-bullet entries that dilute a shipped-application spine.
