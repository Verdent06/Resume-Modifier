# Motorola Solutions

Motorola Solutions (NYSE: **MSI**) sells mission-critical communications and public-safety software: land-mobile radio (MCN/LMR), video security, and command-center platforms. **RadioCentral** is the cloud radio-fleet programming product for APX devices — remote firmware/codeplug updates over Wi-Fi or LTE, centralized fleet workflows, MFA and RBAC, hosted in a secured cloud environment (product page names Azure; that host is product intel, not a resume keyword). This intern req (**R68388**) sits on the **RadioCentral Cloud Services** team in Chicago: build features as microservices or web applications in a cloud architecture. It is not the Android Platform intern (**R68363**, Schaumburg/Plantation) and not a RadioCentral Data Engineer intern (PySpark/Databricks sibling — do not invent that stack).
