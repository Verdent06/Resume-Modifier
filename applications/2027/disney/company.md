# The Walt Disney Company

The Walt Disney Company (NYSE: DIS) is a Fortune-class public entertainment company. Parks & Experiences Professional Internships at Walt Disney World ($31/hr undergrad) are not Disney Streaming SWE and are not the Disney Central contact-center SWE intern ($43/hr). Three Spring 2027 FL reqs share this file — do not mix stacks or personas:

- **WDW CS/CE Interns (req 10158145)** — WSHES / Safety Assurance multidisciplinary routing (quality engineering, safety analytics, ride/show process-control, Engineering Services, Facility Asset Management). $31/hr. Close 2026-08-31.
- **Labor Systems Web Integration Intern (req 10158184)** — Park Ops / Experience Integration (DLR). Cast labor-management web apps (workload, scheduling, time, deployment). $31/hr. GitHub required on resume. Close 2026-08-31.
- **Software Engineering Intern, Spring 2027 (req 10158599)** — Disney Destinations, LLC / Walt Disney World Resort; Job Posting Segment Commercial Strategy; Primary Business Disney Central (WDW); Orlando (7100 Municipal Dr), fully on-site. Custom web-based applications for contact-center efficiencies. OOP: C#, Java, JavaScript (Node, TypeScript). Databases: Postgres, Informix, Microsoft SQL. Telephony/SaaS/SSO/incident-management integrations. Bash/Batch scheduled jobs. Jira/Zendesk/ServiceNow. Jenkins + GitHub Actions + Git/GitHub/GitLab. $43/hr. Posted 2026-08-28; close 2026-09-05. Education: currently pursuing Bachelor's in CS, IT, or related — **no Junior/Senior class-year gate** (unlike Parks PI). Return-to-school after internship. Own housing and transportation. Employer legal entity: Disney Destinations, LLC.

## Quick Facts

- **Tier:** B-tier (`reference/companies.md` — Parks Professional Internship; solid brand, resume-gated; not a FAANG SWE prestige seat)
- **HQ / offices:** Burbank, CA (corporate HQ). Parks PI reqs: **Lake Buena Vista, FL**. 10158599: **Orlando, FL** Disney Central (7100 Municipal Dr), fully on-site.
- **Valuation / signal:** Public (NYSE: DIS); Fortune-class Parks & Experiences brand. Parks PI seats are not Streaming SDE. 10158599 is Disney Central / Commercial Strategy contact-center tooling at $43/hr — closer to Streaming intern pay than Parks PI $31/hr, still not a Streaming SDE req.
- **Product focus (10158145):** Walt Disney World park operations software — safety-trend analytics, ride/show process-control, quality/engineering services, facility asset systems
- **Product focus (10158184):** Cast labor-management web apps — scheduling, time, deployment, reporting — plus sustainment of databases and dashboards
- **Product focus (10158599):** Custom web/service apps for contact-center efficiencies; Postgres/Informix/MSSQL; vendor telephony + SaaS (incident management, SSO); scheduled Bash/Batch jobs; Jenkins/GHA
- **Intern comp (2027):** Parks PI (10158145 / 10158184): $31/hr undergrad; WDW CS/CE also lists $36/hr graduate. **10158599: $43/hr** (Orlando).
- **Work model:** Paid full-time **January–June 2027**. Labor Systems and 10158599: Monday–Friday 40 hours EST, own housing/transport. WDW CS/CE: weekdays with occasional weekends/holidays; limited ACC housing. Disney Look appearance guidelines.
- **Clearance / eligibility:** Enrolled, 18+, unrestricted work authorization; return-to-school after (or current Disney program). WDW CS/CE: Junior/Senior/Graduate by arrival; GPA 3.0+ preferred. Labor Systems: Junior or Senior preferred; **GitHub required on the resume**. **10158599: currently pursuing Bachelor's CS/IT/related — no class-year Junior/Senior gate.** Parks PI posted 2026-08-24, close 2026-08-31. 10158599 posted 2026-08-28; **close 2026-09-05**.

## Stack & Hiring Signal

- **WDW CS/CE (10158145):** may-use C++, C#, Python, Node.js; OOP + Microsoft Office required. Preferred SQL, Git, Docker, CI/CD, cloud, Linux. Do not invent C#, Node.js, PowerApps, a Disney College Program, or ROS.
- **Labor Systems (10158184):** required front-end web plus JavaScript, Python, **and/or** SQL. Preferred Angular or React, AWS/cloud, data-science *concepts*. Honest hits: TypeScript/Angular, React, Python REST, SQL/Postgres, AWS EC2/S3. **Do not invent Java, Spring, Node, Snowflake, Databricks, Tableau, Copilot, Fusion, or Sentry.** Posting category "Data Science and Analytics Intern" is ATS taxonomy, not an ML-research screen.
- **Disney Central SWE (10158599):** required one-or-more of C# / Java / JavaScript; SQL (Postgres / Informix / MSSQL); Git + CI/CD (Jenkins, GitHub Actions). JD also names TypeScript, Node, telephony/SaaS/SSO, Bash/Batch, Jira/Zendesk/ServiceNow. Honest hits: TypeScript (JS-family), SQL/Postgres, Git/GitHub, GitHub Actions, FastAPI/Flask REST, React, AWS EC2/S3, Docker. **Do not invent C#, Java, Node, Informix, Microsoft SQL, Jenkins, Zendesk, ServiceNow, SSO products, Snowflake, Databricks, Tableau, Copilot, or Fusion.** Willingness-to-learn C#/Java is a form/interview answer, not a Skills-line claim.
