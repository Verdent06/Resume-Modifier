Paid onsite Lake Buena Vista **Labor Systems Web Integration Intern** (Spring 2027, Jan–June, six months, $31/hr) on Disney Experiences **Park Ops / Experience Integration**. JD surface work: sustain existing labor systems, applications, tools, databases, and reporting; in-flight capital/local projects spanning **database design, backend server management, front-end web, and dashboard/visualization design**. ## Screen Criteria

**Pass signals (abstract):**

- Front-end web through use: a real UI (React or Angular) inside bullets, not Skills-only (`resume.md` §2, §12). TypeScript covers the JD's JavaScript requirement honestly.
- Python and/or SQL through use in architectural decisions (REST/APIs, ETL, persistence) — the JD's language floor is an or-list; polyglot proof for languages the candidate actually has.
- Preferred Angular or React in bullets. AWS/cloud tied to a shipped outcome. Data-pipeline / analytics *concepts* as intern-scale ingest→store→serve, never invented warehouses or BI tools.
- Shipped full-stack software other people used: APIs, databases, dashboards, stakeholder handoff — maps to sustainment of labor systems, tools, databases, and reporting.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an Easy–Med coding screen if invited.
- GitHub (or portfolio) on the page — required materials.
- Class-year on the page: `Expected May 2028` satisfies junior-year preference.

**Anti-patterns:**

- Invented **Java, Spring, Node, Snowflake, Databricks, Tableau, Copilot, Fusion, or Sentry** — banned; not in this JD and not honest inventory.
- Skills-line JavaScript/Python/SQL/Angular/React with zero bullet evidence.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat (posting category is taxonomy).
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests web/API/database/dashboard SWE.
- Invented workforce-management / Kronos / UKG / labor-ops product experience because the team paragraph named scheduling.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack web-integration spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Missing GitHub on the resume (materials ineligible).
