# Software Engineering Intern at Cohere

## Role Summary

SWE Intern across multiple teams (Frontend, Backend, Full-stack, Infrastructure) at an enterprise foundation-model company. Interns ship production code with FTE-level autonomy: user-facing product experiences (browser or server), API platform features, robust data pipelines (crawlers, storage, filters), scalable services for ML development, internal CI/CD tooling, and technical documentation. Team matching considers interests and experience. JD surface is generic full-stack SWE spanning frontend, backend, APIs, data, and infra; company identity is enterprise NLP — models, embeddings, RAG, and API infrastructure that customers depend on in production.

## Track Decision

- **screen_track:** full-stack (generic SWE requirements — frontend, backend, API, data pipelines, deployable services)
- **differentiator:** ai-ml / ml-infra (foundation models, NLP API platform, datasets-for-ML, scaling inference/serving, ML development infrastructure)
- **track_divergence:** true

The screen spine follows `resume.md` Part III §12 — shippable product, APIs, databases, cloud deploy, CI/CD proof in bullets. The differentiator follows `resume.md` Part III §14 and `recruiting.md` Part III §13 — end-to-end ML workflow, model adaptation/serving signals, data pipelines feeding models, not notebook-only `model.fit()`. When divergence is true, lead with the full-stack spine **and** keep ML-infra / applied-ML carriers prominent and deep in the top half — do not pivot the entire page to research-only framing.

## Team & Bar

Cohere is B-tier in `companies.md` with <3% estimated acceptance and bottleneck at tech rounds (3–4 Med–Hard, no standard OA). Recruiter voice: interns who already ship to production, can own a feature end-to-end, and show curiosity about cutting-edge ML systems without reading as pure research. Remote-friendly global hiring with Toronto/NYC presence. Eligibility is a hard gate: enrolled post-secondary student available for 3–6 months full-time. AI-enabled applicant screening is disclosed — keyword stuffing and unverifiable claims are higher risk than at firms without semantic screening.

## Screen Criteria

- Full-stack or backend shipping with APIs, data stores, and deploy paths demonstrated in bullets — not Skills-only.
- Data-pipeline / crawler / ETL evidence with throughput or time-saved metrics — JD explicitly names pipelines and filters.
- ML-infra or applied-ML depth beyond API wrappers: fine-tuning, embeddings/vector search, eval harnesses, inference latency/cost, or orchestrated ML pipelines — company differentiator must register in the first screen pass.
- User-facing product or API platform impact (latency, reliability, cost, users) — Cohere sells production API access.
- CI/CD, Docker, cloud deploy, and internal-tooling signals where present — JD names CI/CD and dev utilities.
- Technical communication / documentation habit is a plus when tied to shipped systems.
- Class-year on page must show current enrollment (`Expected May 2028` satisfies Summer 2027 internship eligibility).

## Anti-Patterns

- Screening as ML research PhD track when the req is SWE intern — lead engineering delivery, not paper abstracts.
- Agentic buzzwords without pipeline architecture, eval, or production metrics.
- Frontend-only or club-ops framing with no backend/API/data depth.
- Crawler or pipeline claims with no scale or outcome numbers.
- Thin single-bullet filler entries that dilute a strong production + ML-infra spine.
- Languages or frameworks listed in Skills with zero bullet evidence.
