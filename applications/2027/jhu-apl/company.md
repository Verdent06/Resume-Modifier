# Johns Hopkins Applied Physics Laboratory (JHU APL)

The Johns Hopkins University Applied Physics Laboratory is a not-for-profit **Navy-sponsored university-affiliated research center (UARC)** in Laurel, Maryland — the nation's largest UARC (est. 1942; ~8,800 staff; ~$2.09B). It builds classified and unclassified systems for national security, space, and science: rapid prototyping plus long-horizon R&D for DoD and civilian sponsors. This intern req sits in the **Air and Missile Defense Sector (AMDS)** on **sensor systems / data analytics** — signal processing, multi-sensor fusion, tracking, and applied ML/stats on multi-dimensional sensor data — not a generic SWE intern and not a Tableau/BI dashboard seat.

## Quick Facts

- **Tier:** B-TIER (`reference/companies.md`) — higher technical prestige than C-tier primes (Raytheon / Lockheed intern SWE); peer to Northrop / Boeing intern brand, with a research-lab culture
- **HQ / offices:** Laurel, MD (461-acre campus, Baltimore–Washington metro). This intern: **onsite Laurel; telework not available**
- **Valuation / signal:** Nonprofit UARC (not a public prime). JHU affiliation. Critical Contributions to Critical Challenges. Staff ~8,800 (2025)
- **Product focus:** AMDS sensor systems — detection, tracking, characterization; active/passive, multi-band, multi-static fusion; multi-domain (air, sea, land, space) targeting from multi-spectral / multi-mode sensors
- **Intern comp (2027 Sensor Systems / Data Analytics intern):** **$22.60–$47.95/hr** (this JD). Levels.fyi SWE intern analog ~$34/hr + relocation **[directional]**
- **Work model:** Paid Summer **2027** internship only. Onsite Laurel. Multidisciplinary team of engineers, physicists, mathematicians, and computer scientists. Applications rolling (posting active as of 2026-09-04; listed ~4 days ago)
- **Clearance / eligibility:** **Interim Secret by start date; final Secret required.** U.S. citizenship is an eligibility requirement for the clearance. GPA **3.0 / 4.0** minimum. Pursuing BS/MS/PhD in EE, Aero, CompE, Systems, MechE, Engineering Physics, Physics, Applied Physics, Applied Math, Math, **or another related technical field** (CS qualifies). Background investigation + drug test before start (federal contractor; marijuana is disqualifying). iCIMS req **59958**

## Stack & Hiring Signal

- **Languages:** JD names **none**. Screen for applied analytics in languages the candidate actually has — **Python and SQL through use**. Do **not** invent Tableau, Power BI, Snowflake, Databricks, MATLAB, or radar/RF toolchains
- **Domains:** Signal and data processing for detection/tracking/characterization; multi-sensor fusion (active/passive, multi-band, multi-static); sensor-architecture tasking; applied AI/ML on sensor data; data science / statistical analysis on large multi-dimensional datasets; algorithm work in simulation / HPC
- **What wins:** Because the bottleneck is the resume (`recruiting.md` intern funnel; B-tier UARC), a one-page PDF that shows end-to-end data or applied-ML workflow (ingest messy/multi-source data → transform/score/fuse → measured outcome), Python/SQL through use, and stakeholder-scoped delivery. Sensor/fusion analog is multi-source integration — not invented radar. Preferred: prior internship or research in engineering/math/physics/related. Club-ops, notebook ML, generic full-stack/audio-DSP leads, and BI-tool stuffing fail this screen
