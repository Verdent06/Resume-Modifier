# Software Engineer Intern (Summer 2027) at DraftKings

## Role Summary

Ten-week Boston SWE intern on Backend or Web Development teams shipping production code on DraftKings' core sports-technology platform — live sportsbook / DFS / iGaming systems that real customers use. JD surface is generic intern SWE: currently enrolled CS/CE (or related), Git, OOP languages (TypeScript, C#, or Java), unit or automated end-to-end testing, classes/side-projects/hackathons, agile, production-ready code. Company identity is a publicly traded, regulated consumer iGaming company headquartered in Boston — fintech-adjacent product, not a trading desk, not an ML-research seat. The opening AI paragraph is company flavor, not an `ai-ml` track.

- **screen_track:** full-stack
- **differentiator:** consumer sports-tech / regulated iGaming / real-time sportsbook platform
- **track_divergence:** true

Spine is Backend or Web (APIs, React/TS, Flask/FastAPI); differentiator-aligned production/regulated/consumer-platform evidence stays prominent and deep beside that spine.

## Screen Criteria

**Pass signals (abstract):**

- TypeScript demonstrated in bullets, not Skills alone — JD names TypeScript / C# / Java; only languages the candidate actually has belong on the page. C# or Java in Skills with zero inventory is fabrication.
- Git / version control through use (CI, collaboration, or shipped repos), not a Skills-only token.
- Tests and production-ready shipping: unit tests, automated e2e, CI pytest/GitHub Actions, or equivalent — plus code that reached real users.
- Backend or Web spine: REST/APIs, React/TypeScript (or equivalent web), Flask/FastAPI (or equivalent backend), persistence and deploy (AWS/Docker) tied to an outcome (`resume.md` §12).
- Differentiator flavor on that spine: sports-tech, regulated-product, or real-user consumer-platform shipping — memorable at a Boston iGaming company without becoming a DSP or ML resume.
- CS fundamentals visible enough to survive an Easy–Med HackerRank OOP/class-design OA (`recruiting.md` §6 LLD).
- Class-year on the page: current enrollment (`Expected May 2028`) satisfies a JD that only requires being a bachelor's student.

**Anti-patterns:**

- Skills-line C#, Java, Snowflake, Databricks, Copilot, Fusion, or Tableau with no bullet evidence (fabrication smell).
- Opening AI paragraph treated as an `ai-ml` targeting brief — LoRA / agentic / notebook-ML as the lead story for a Backend-or-Web intern req.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests Backend or Web; systems depth may sit below the lead window.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + production-shipping spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
