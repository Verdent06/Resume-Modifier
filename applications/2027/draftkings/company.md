# DraftKings

DraftKings Inc. (Nasdaq: DKNG) is a digital sports entertainment and gaming company headquartered in Boston: daily fantasy sports, online sportsbook, and iGaming on a consumer sports-technology platform that has to stay live under sports-event load and state gaming regulation. Campus SWE interns land on Backend or Web Development teams shipping production code on that core platform — not an ML-training seat and not a trading desk. The product identity is regulated consumer iGaming and real-time sportsbook systems; the intern JD itself is generic full-stack SWE (TypeScript / C# / Java, Git, tests).

No GPA floor, no graduation-year window, no visa statement on the public posting. **Gaming license** issued by a state agency may be required as a condition of employment (JD); DraftKings guides candidates through it if relevant

## Stack & Hiring Signal

- **Languages:** Intern JD names TypeScript, C#, or Java (OOP). Screen tests whatever the candidate actually ships — **do not invent C# or Java**. TypeScript is the honest OOP language when that is the inventory
- **Domains:** Backend or Web on a live sports-technology platform; production code to real users; agile; testable/efficient software (unit tests, automated e2e); Git. Opening AI paragraph is company flavor, not an `ai-ml` track
- **What wins:** Shipped backend or web software (APIs, React/TS, Flask/FastAPI) with Git and tests through use; production ownership to real users; sports-tech / regulated-product flavor as differentiator on a full-stack spine (`resume.md` Part III §12; `recruiting.md` Part III §11).
