## Screen Criteria

**Pass signals (abstract):**

- Python through use in bullets (`resume.md` §2 keyword-through-use). Proficiency is named; a Skills-only Python line fails.
- SQL / database evidence through use (queries, persistence, freshness, integrity). Oracle is named with SQL — **do not invent Oracle**. PostgreSQL/SQL through use is the honest analog.
- Shipped full-stack or backend software: REST/APIs or services, persistence, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Testing, debugging, or code-review discipline matches "code, test, and debug."
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an Easy–Med coding/skills test if invited.
- Bank-IT / fintech-backend flavor on that spine: production APIs, financial or regulated-data workflows, reliability/controls-minded delivery — memorable here without replacing the SWE spine.
- AI or security-tool exposure as a **plus** (asset line), never as the lead story for a generic SWE intern, and never invented Sentry/Copilot/Fusion.
- Honest class year on the page. If Education shows a graduation date outside Dec 2026–June 2027, that is a screen-level eligibility miss — tag it; do not treat it as a cosmetic date.

**Anti-patterns:**

- Invented Oracle, FTP/SFTP production work, firewall configuration, Java, C#, Snowflake, Databricks, Tableau, Copilot, Fusion, or Sentry.
- Invented core-banking, payments-rail, or CIBC-platform claims because the company is a bank.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat (AI is an asset).
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests Python/SQL/SDLC/bank applications.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + finance-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
- Lying on the graduation window to clear a knockout.
