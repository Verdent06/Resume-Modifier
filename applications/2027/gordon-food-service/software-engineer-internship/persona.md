## Role Summary

Paid **Software Engineer Internship** at Gordon Food Service Home Office, Wyoming, Michigan (Workday **R-57377**, `gfs.wd5` / `usjobs-gen-gfs`, posted 2026-09-18). 12-week onsite intern, May–August 2027. Comp unlisted (hourly, paid weekly, flex hours, store discount, EAP). Housing at no cost for Home Office interns who do not reside in Kent County, MI. Tobacco-free; pre-employment drug test. **Not** the Software Engineer Intern (Low Code / Appian) sibling and **not** the MMSC Category Technology Intern.

Day-to-day is **generic intern SWE with a foodservice eCommerce flavor**: contribute to feature development, enhancements, and API integrations on the **Gordon Ordering** eCommerce platform using Java/Spring Boot and Angular; build/refine CI/CD, unit/integration tests, and database interactions on Google Cloud Platform (GKE, Cloud SQL PostgreSQL); evaluate AI-assisted engineering tools, test harnesses, and code-quality workflows as **developer productivity** (not modeling); sit in agile ceremonies with engineers, architects, UX, and product owners. Company identity (`company.md` / `companies.md`): North America's largest family-owned broadline foodservice distributor (~$24B sales) whose software org serves customers, employees, and partners across the US and Canada.

## Screen Criteria (abstract)

Pass signals:
- Shipped full-stack or backend production software: REST/APIs or services, a real stakeholder or user, persistence or ETL, deploy analog (`resume.md` §12). Keyword-through-use for TypeScript / Angular / SQL / PostgreSQL / Python / Flask or FastAPI / Docker / Git / GitHub Actions in bullets, not Skills alone (`resume.md` §2).
- Angular (or TypeScript frontend) through use — the JD's Gordon Ordering Angular line. Honest Angular in a production UI bullet beats claiming Java/Spring Boot.
- CI/CD + relational-database analog: GitHub Actions / Docker Compose / pytest, PostgreSQL or injection-safe SQL freshness — the JD's CI/CD, tests, and Cloud SQL PostgreSQL lines without inventing GKE/GCP.
- Tests or production debug with a witness metric (unit/integration testing suites; failure-rate drop; named defect with a before/after).
- Collaboration analog: stakeholder-scoped delivery or pairing — agile ceremonies, not a Scrum-cert line.
- Metrics that size impact (hours saved, failure-rate drop, throughput, precision), landed as the closer (`resume.md` §4).
- Class-year on the page: `Expected May 2028` — honest junior standing; GPA 3.66 ≥ 3.0.

Anti-patterns:
- Inventing Java, Spring Boot, GKE, GCP, Snowflake, Databricks, Copilot, Fusion, or Tableau.
- ML-research framing: LoRA-as-lead, publications, notebook `model.fit()` with no application, no tests, no delivery. This req is Gordon Ordering product SWE; AI tools are productivity.
- Off-axis lead: pure audio-DSP, club-ops, deal-sourcing GTM, or agent/RAG-as-the-job when the role tests eCommerce features, APIs, Angular, tests, and Postgres.
- Angular / SQL / CI/CD claims only in Skills with no supporting system.
- Claiming Gordon Ordering, foodservice, GFS platform, or Java internships the page cannot defend.
- Metric-free architecture bullets the recruiter cannot size.
- No live GitHub on an intern engineering resume (`resume.md` §3).
