## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has that the JD names (**SQL**). Keyword-through-use in bullets, not Skills-only (`resume.md` §2). **Do not invent C#, .NET, Azure, Blazor, or SQL Server** — intern JD accepts a similar-language code sample.
- Shipped full-stack or backend software: REST/APIs or services, SQL/persistence, and data pipelining / ETL tied to an outcome (`resume.md` §12). Flask/FastAPI, Docker, Git through use match basic SWE + pipeline exposure.
- CS fundamentals visible: DS&A coursework plus engineered work defensible in a similar-language code sample or Easy coding screen if invited.
- Modern practices through use: Git/version control, scrum/Agile or stakeholder delivery, independent remote-ready ownership.
- Payments / fintech-backend / payment-orchestration flavor on that spine: production APIs, financial or regulated-data workflows, pipeline/reconciliation-shaped delivery — memorable here without replacing the SWE spine.
- Microservices / Azure / AI insights as plus (company-stack flavor), never as the lead story for a generic SWE intern req, and never invented.
- Class-year on the page: `Expected May 2028` satisfies working toward a CS bachelor's with return-to-school after Summer 2027.

**Anti-patterns:**

- Skills-line C# / .NET / Azure / Blazor / SQL Server with zero bullet evidence (fabrication smell at a Microsoft-stack shop).
- Invented Snowflake, Databricks, Tableau, Copilot, Fusion, or Sentry — banned; not in this intern JD and not in inventory.
- Invented card-rail, ACH, or Azure-microservice claims because the company paragraph named payment orchestration.
- Agentic-AI / LoRA / notebook-ML lead as if this were an ML-research intern seat (AI insights are product flavor).
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests APIs, SQL, pipelines, and web/mobile design.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + payments-delivery spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
