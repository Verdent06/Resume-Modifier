# Transcard Payments

Transcard Payments LLC is a privately held Chattanooga fintech that builds **global payment orchestration** for banks, fintechs, and businesses: embedded disbursements, receivables, account-to-account, cross-border, AI insights, and supply chain financing. Flagship product is **SMART Suite** (APIs on Azure; also SMART Exchange) — multi-rail B2B/B2C workflows, system-of-record / ERP integration, reconciliation, and bank-grade security. Founded 2008 on a fuel-payments platform (U.S. Xpress), sold that product to U.S. Bank, then rebuilt a cross-industry platform from 2012. UK Payment Institution authorization in 2024; Canada expansion 2025. Production stack is C# / .NET / SQL Server / Blazor on Azure (Microsoft customer story + senior SWE reqs). The Summer 2027 intern SWE posting is still generic exposure (mobile/web, scrum, APIs, data pipelining) plus a possible code sample in a *similar* language — not a C#-only knockout.
