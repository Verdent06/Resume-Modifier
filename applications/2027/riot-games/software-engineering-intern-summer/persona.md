## Screen Criteria

**Pass signals (abstract):**

- **OOP language demonstrated in bullets** (C++ is the honest JD hit), not Skills alone (`resume.md` §2 keyword-through-use).
- Production shipping: APIs, services, or client systems deployed to real users, with a witness metric.
- Real-time, latency, concurrency, or player-adjacent reliability evidence in the top half — the live-game differentiator must register on a 7-second pass (`resume.md` I.3).
- Backend / API / service ownership alongside the real-time signal — JD spans player-facing features through shared platform SDKs.
- SDLC flavor through use (CI, tests, deploy) as a plus, not a substitute for shipped systems.
- Class-year on the page: `Expected May 2028`. GPA 3.66 clears the 2.5 floor.

**Anti-patterns:**

- **Gaming hobby framing** without engineering the role tests (club ops, "I play League," no systems).
- C++ / Java / C# named in Skills with zero bullet evidence — fails the OOP floor.
- Invented Unity, Unreal, Java, C#, or a ranked-ladder story the page cannot defend.
- Leading with unrelated quant/GTM or PE lead-gen as the first-pass identity at a games company.
- Notebook ML or agentic buzzwords without delivery.
- Thin single-bullet filler that dilutes a production + real-time spine.
- Soft, metric-free shipping claims where live-game teams size latency, reliability, and player impact (`resume.md` §4).
