- JS-family through use: TypeScript covering JavaScript; React and/or Angular covering the React/Vue.JS or-list. **Do not invent Java, C#, Vue, or Node.js-as-used.**
- Shipped full-stack or backend software: REST/APIs, persistence, and cloud/deploy (AWS/Docker/CI) tied to an outcome (`resume.md` §12). Testing, debugging, or code-review discipline matches "software development intern" on an in-house WM tech team.

- CS fundamentals visible: DS&A coursework plus engineered work defensible in a light technical/behavioral if invited.

- Named AI tools as a **plus** (working-knowledge or-list), never as the lead story, and never invented Copilot / Devin / Claude Code / Factory.AI / WatsonX production claims.
- Honest class year on the page. `Expected May 2028` clears December 2027 – May 2029.
