## Screen Criteria

**Pass signals (abstract):**

- Polyglot proof for languages the candidate actually has. JD names Java, Python, JavaScript, or TypeScript as a one-of floor — **do not invent Java**. Keyword-through-use for Python / TypeScript / SQL / React / REST / Git / Docker in bullets, not Skills-only (`resume.md` §2).
- Shipped full-stack or backend software: REST/APIs or services, a real frontend (React/TypeScript preferred) or client surface, a persistence decision (SQL/Postgres), and deploy/CI (Docker/GitHub Actions analog to GitLab CI) tied to an outcome (`resume.md` §12).
- CS fundamentals visible: DS&A coursework plus engineered work defensible in an easy practical screen if one is issued.
- Environmental-obligation / finance-audit flavor on that spine: processing, validating, or transforming environmental, financial, or regulated operational data — memorable here without replacing the SWE spine and without inventing STATERA, ARO/ERO modules, or SOX controls ownership.
- Applied data/pipeline or applied AI (document processing analog, automation) as plus — **not** ML-research, LoRA, or notebook-only modeling (`recruiting.md` §13 applied vs research split).
- Class-year on the page: `Expected May 2028` — honest junior standing; satisfies currently pursuing a degree for Summer 2027.

**Anti-patterns:**

- Skills-line Java / Spring Boot / RabbitMQ / Ansible / GitLab / Copilot with zero bullet evidence (fabrication smell at a Java/Spring shop).
- Invented Snowflake, Databricks, Tableau, Copilot, Fusion, Sentry, or STATERA/ARO/ERO product ownership.
- ML-research / LoRA / "research assistant" lead as if this were a GenAI-research intern seat. Data-and-AI plus is applied pipelines and document/data processing, not publications.
- Hard-real-time C++/audio-DSP as the first-pass identity when the role tests React/TS, REST, SQL, and environmental/financial data workflows.
- Club-ops, community-growth, or coursework-only framing with no shipped application.
- Thin single-bullet entries that dilute a full-stack + regulated-data spine.
- Vanity metrics (uptime, LOC, coverage %) standing in for impact (`resume.md` §4).
