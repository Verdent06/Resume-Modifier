## Screen Criteria

- Production software demonstrated in bullets: APIs, pipelines, deploy/CI, a titled internship — not Skills-only claims.
- Prior internship in backend, infrastructure, security, UI/full-stack, or ML/NLP/search visible as a titled experience — the JD names it.
- Full-stack product engineering with trade-offs the candidate can narrate (`resume.md` §12): frontend + backend/API + datastore + deploy.
- Search / retrieval / agentic signal in the top half when present (company identity): semantic search, embeddings, eval/quality gates, agent pipelines with numbers — not paper-abstract research.
- Shipped product used by someone other than the author (customers, operators, paying clients). Owner mentality evidenced as a diagnosed defect or end-to-end delivery, not a slogan.
- Class-year on page: `Expected May 2028` will fail a literal Fall-2026 / Spring-2027 scan.

## Anti-Patterns

- Inventing Go, Java, Kubernetes, Elasticsearch, Glean connectors, Copilot, Snowflake, Databricks.
- Leading with LoRA / research-paper / `model.fit()` framing as if this were an ML-research intern seat.
- Club-ops, GTM/quant sourcing, or deal-flow work with no engineering the role tests.
- Notebook ML with no pipeline, API, retrieval, or deploy story.
- Thin single-bullet filler that dilutes a production + search spine.
- Claims the candidate cannot defend in a 1-hour coding round or a 2-hour project interview.
- Pretending the printed graduation window matches May 2028.
