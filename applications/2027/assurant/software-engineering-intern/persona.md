## Screen Criteria (abstract)

Pass signals:
- Shipped applications: frontend framework + backend/API + persistence or deploy, narrated decision-by-decision (`resume.md` §12). Keyword-through-use for Angular, React, AWS — not Skills alone (`resume.md` §2).
- Business-problem-with-code: a manual process replaced, or a defect diagnosed, with a witness metric — the intern program’s “solve real-world challenges” / production-issue line.
- Delivery / automation analog: Docker, CI, or cloud deploy (EC2/S3) — the JD’s application development, code quality, and automation focus.
- Polyglot proof for languages/frameworks the candidate actually has. JD names .NET / React / Angular / Android / iOS / Oracle as a team-match list — **do not invent .NET, Azure, Datadog, Oracle, or mobile native**. Angular/React through use beats a Skills-only claim.
- Production-support analog: a user-facing failure, investigation, fix, witness metric.
- Cloud through use (AWS). Azure is “or AWS,” not a fabrication target.
- Metrics that size impact (error-rate, hours saved, latency, throughput), landed as the closer (`resume.md` §4).
- Class-year on the page: `Expected May 2028` — honest Junior / rising-junior standing for Summer 2027; one semester remaining after 8/7/2027.
- SWE identity, not Global Finance intern identity — a Finance sibling req is posted the same cycle.

Anti-patterns:
- Skills-line .NET / C# / Azure / Azure DevOps / Jira / Datadog / Dynatrace / Oracle / Android / iOS / Copilot / Rovo with zero bullet evidence (fabrication smell).
- Inventing those tools, or claiming Assurant / policy-admin / mobile-device-protection internships the page cannot defend.
- Leading as a Finance intern or actuarial intern when this is Software Engineering Intern R-115727.
- ML-research / LoRA / notebook `model.fit()` as the first-pass identity when the role tests application delivery (`recruiting.md` §13 applied vs research split).
- Off-axis lead: hard-real-time C++/audio-DSP or club-ops fronting an enterprise insurance application-delivery intern req.
- Metric-free architecture bullets the recruiter cannot size.
- No live GitHub on an intern engineering resume (`resume.md` §3).
