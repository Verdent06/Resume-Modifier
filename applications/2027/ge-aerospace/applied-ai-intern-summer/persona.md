## Screen Criteria

Pass signals:
- Python, SQL, and (if claimed) C++ demonstrated **through use in bullets**, not Skills-list only.
- Applied AI delivery: LLM/agent workflows, applied ML, or computer vision **inside a system** — PoC, API, pipeline, or production — not a notebook demo.
- Data engineering: ingestion, ETL, databases, or pipelines that other people actually consume.
- Cloud through use (AWS in a deploy/storage/inference decision). Azure certs are desired, not a floor.
- Engineer- or stakeholder-facing delivery: APIs, demos, architectures presented, tools adopted — analog to "engineers evaluate and adopt data and AI solutions."
- Metrics that size impact, landed as the closer (`resume.md` §4).
- One-page parseable PDF with a live GitHub (`resume.md` §3).

Anti-patterns:
- ML-research framing (publications, novel methods, LoRA/fine-tune as the **lead identity**) on an applied product-AI intern req.
- Claiming Snowflake, Databricks, GitHub Copilot, Fusion, Tableau, C#, or AWS/Azure certifications the page cannot defend.
- Notebook ML without delivery (no pipeline, no API, no stakeholder).
- Leading as audio-DSP / real-time C++ hobby systems, or as PE deal-sourcing / GTM scoring.
- Generic full-stack web resume with AI only in the Skills line.
- Skills-list keyword stuffing; metric-free architecture bullets the recruiter cannot size.
- Inventing aerospace internships, DecisionIQ/Innovator Method experience, or tools not evidenced.
