# Software Engineering Intern (2027 Start) – Winter at Databricks

## Role Summary

Winter 2027 SWE intern (January–April only; this apply: Bellevue, WA; posting also lists Mountain View and San Francisco). Paid; Bellevue $51.50–$60/hr. Interns join a team, own a project end-to-end (design, code, feedback), and ship features into the Databricks platform across full stack, backend, infrastructure, systems, tools, cloud, databases, and customer-facing products — with a dedicated mentor and the 2027 intern cohort. JD surface is generic SWE: CS/Engineering degree in the fall-2027 / spring-2028 window, implementation in a general-purpose language (Python, Java, or C++ as examples), DS&A and OOP, comfort with ambiguous collaborative work. Company identity is data/AI infrastructure — a lakehouse platform at global scale — not a consumer CRUD product and not an ML-training internship. One application per 30 days; location is chosen at apply.

## Screen Criteria

- JD languages demonstrated in bullets, not Skills alone — Python and/or C++ through use. Java is an example language on the JD, not a fabrication invitation if it is absent from the page.
- Algorithms, data structures, and OOP as a floor: DS&A coursework visible plus design decisions in bullets (classes, encapsulation, concurrency primitives, API/data-model choices) — not a skills-list restatement.
- Production or production-shaped shipping: APIs, data pipelines, or services with a deploy path (cloud, containers, CI) so "build features for the platform" is believable.
- Data-infra differentiator visible in the top half: ETL/aggregation, storage, backend services that move or serve data, or systems/performance/concurrency evidence — without naming Databricks products, Spark-as-employer-experience, Unity Catalog, Lakehouse-as-skill, or peer warehouse brands.
- Full-stack spine: at least one product defensible layer-by-layer (backend/API, data store, a client or pipeline consumer, deploy). Breadth across the stack plus depth in one layer (`resume.md` §12).
- End-to-end project ownership signal (design → implementation → feedback/quality) that maps to the JD's intern project model.
- Impact metrics a recruiter can size in 30 seconds (latency, throughput, cost, failure recovery, volume, hours saved) — maps to "scales quickly while maintaining quality and security."
- Class-year on page: `Expected May 2028` satisfies spring 2028; internship term is junior-year winter with return to school.

## Anti-Patterns

- Requiring or claiming Databricks product experience (Lakehouse, Unity Catalog, Spark-as-employer-product, Genie, Lakebase, Agent Bricks, Lakeflow) or peer tools (Snowflake, Tableau, Copilot, Fusion).
- Leading with LoRA / LangGraph / agentic-AI product framing as if this were an ML-training internship.
- Club-ops, GTM/quant sourcing, or deal-flow work with no engineering the role tests.
- Python or C++ named only in Skills; Java invented to match the JD example list.
- Notebook ML with no pipeline, API, or deploy story.
- Thin single-bullet filler that dilutes a production + systems spine.
- Claims the candidate cannot defend for 45 minutes in a project deep-dive or a concurrency follow-up.
