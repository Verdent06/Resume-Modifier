# Software Engineering Intern at Arcfield

## Role Summary

Arcfield is hiring a Software Engineering Intern in Middletown, RI to modify applications across Linux and Windows, support development/integration/test, write software and test documentation, and deliver in an Agile Scrum environment. The JD surface is classic general SWE: Java and C++ OOP, Python scripting, React/CSS web work, Git/Jira tooling, unit and integration testing. The company identity is defense systems integration — especially NUWC-adjacent unmanned-systems software, integration rigor, and mission-critical delivery discipline under government engineering standards.

## Team & Bar

The reader is a defense-contractor hiring manager or technical recruiter screening for a student who can work in Agile teams with mentors, troubleshoot real applications, and support integration and test with documentation discipline. The funnel is resume-forward (no standard OA gate for defense primes). The bar is fundamentals plus demonstrated polyglot development under Linux, object-oriented design in Java or C++, version-control fluency, and evidence of quality-focused delivery — integration testing, debugging, and on-time execution matter as much as feature building.

## Screen Criteria

- Java and/or C++ should appear in experience or project bullets where OOP is claimed; Python and React/CSS support the JD's polyglot web mandate.
- Linux development, Git, and Agile/SDLC signals should be visible through real use (build, deploy, test, CI), not Tools-line orphans.
- Strong signals: integration and unit-test ownership, polyglot application modification, documentation or test-plan discipline, team-based delivery with measurable quality outcomes, and defense-adjacent systems rigor (reliability, hardware-software boundary, structured test).
- Anti-patterns: notebook-only ML without delivery, club-growth narrative without engineering depth, AI-agent hype without systems discipline, and a page that reads as pure frontend or pure research with no integration/test surface.
- When track diverges, the first-read should still say "ships and tests application software in Java/C++/Python" while a secondary read registers defense-systems integration and unmanned-platform credibility.
