## Role Summary
This is a generalist backend/full-stack SWE internship embedded within one of Mastercard's London engineering teams — most likely Vocalink or a product platform team. Day-to-day work involves writing production code across the full software development lifecycle: requirements, design, implementation, testing, code review, and deployment. At Mastercard's scale, "high-quality code" means PCI-DSS-compliant, thoroughly tested, and auditable — they will care deeply about test coverage, security hygiene, and maintainable design patterns. Success at 3 months looks like independently shipping a feature end-to-end, demonstrating strong CS fundamentals (especially algorithms and data structures), and having a commit record that shows clean, reviewed, production-ready code.

## What They're Really Looking For
- **Strong Java fluency** — Mastercard's core systems run on Java microservices; Python or JavaScript are fine as additional languages but Java is what they actually hire interns into
- **Test discipline** — "exposure to automated tests" is a baseline requirement; candidates who mention unit + integration test coverage numbers will stand out versus those who just say they "wrote tests"
- **Security awareness** — Mastercard handles cardholder data and PCI-DSS is part of every design decision; mentioning OAuth, token security, or access control signals you understand the domain
- **CS fundamentals depth** — the explicit callout of algorithms, data structures, and debugging tools suggests they screen on these; an intern who can read a stack trace and explain a memory issue will pass screens that generic "I love coding" candidates won't
- **Penultimate-year student** — they explicitly want someone graduating 2027+; this is a pipeline play for full-time hiring, so intellectual curiosity and growth trajectory matter more than depth
- **Source control fluency** — not just "I use git" but branching workflows, PRs, code review culture; CI/CD awareness is a bonus

## Required Skills
- Exposure to algorithms, data structures, and core computer science concepts
- Proficiency in one or more programming languages: Java, JavaScript, C#, Python
- Exposure to automated tests to verify code correctness and expected behavior
- Knowledge of source control management (e.g., git), deployment, and task management tools
- Strong analytical and problem-solving skills
- Familiarity with debugging tools: stack traces, memory profiling, code tracing
