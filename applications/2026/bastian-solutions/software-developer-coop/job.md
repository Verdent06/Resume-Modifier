## Role Summary
The Pallet Automation group at Bastian Solutions develops and maintains Exacta and viadat—proprietary warehouse management and pallet automation software. As a Software Developer Co-op you will implement features and modifications from specifications and requirements, run software validation so modules meet functional specs and design docs, and participate in the bug lifecycle: triage, log analysis, root-cause investigation, and fixes alongside senior developers. You will design and execute test plans, communicate bugs to the team, and create or maintain test environments so the team can cover all aspects of each project. Success looks like owning small-to-medium features end-to-end, closing bugs with clear root-cause documentation, and learning C#, SQL Server/Oracle, and Visual Studio in a real product codebase. Optional travel to customer sites during implementation (expenses paid).

## What They're Really Looking For
- **Spec- and requirement-driven work** — Comfort implementing from written specs and design documents, not greenfield R&D.
- **Validation and quality mindset** — Willingness to manually deploy and test; strong attention to detail in validation and bug identification.
- **Log-driven debugging** — Ability to use logs to locate issues and work with seniors to fix bugs (root cause, not band-aids).
- **Test discipline** — Designing and running test plans, maintaining test environments, and closing the loop on open issues with the team.
- **Eagerness to learn** — JD explicitly calls out "eager to learn" Visual Studio, C#, C++, SQL Server/Oracle; they expect to train, not hire experts.
- **Stability and fit** — Three rotations in Grand Rapids signal they want someone who will commit and grow into the stack.

## Required Skills

- Eager to learn in Visual Studio, C#, C++, SQL Server and/or Oracle
- Strong quality control and computer skills including ability to learn how to manually deploy and test software
- Strong troubleshooting skills
- Ability and willingness to learn
- Must be eligible to work in the USA long term without sponsorship
