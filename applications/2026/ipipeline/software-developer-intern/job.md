## Role Summary

The Software Developer Intern supports building high-quality software solutions on a collaborative, agile team. Day-to-day work spans the full development lifecycle: concept, design, coding, and testing. The intern will follow coding standards set by technical management, apply agile methodology, analyze and resolve technical and application problems, and work with other software engineers to meet team goals. Evening and/or weekend deployment support may be required. Success at three months looks like shipping tested, standards-compliant code and contributing reliably to team deliverables.

## What They're Really Looking For

- Someone who can slot into an agile team without constant hand-holding: understands SDLC and can apply process.
- Demonstrated ability to write and test code that meets defined standards—not just "I built a project," but evidence of working within constraints.
- Comfort with enterprise-style stack (C#, Java, HTML5) and willingness to learn their specific tools.
- Problem-solver who can debug and resolve technical and application issues.
- Reliable collaborator with good communication; team goals matter more than solo heroics.
- Optional but valued: database experience and version control (Git) familiarity to reduce ramp-up.

## Required Skills
- Currently pursuing a degree in Computer Science, Software Engineering, or a related field
- Knowledge of basic coding languages including C#, Java, and HTML5
- Understanding of agile development methodologies
- Willingness to learn new software and technologies
- Strong problem-solving skills
- Good interpersonal and communication skills
- Ability to work in a team environment

## Preferred Skills
- Experience with database management and security a plus
- Familiarity with version control, such as Git
