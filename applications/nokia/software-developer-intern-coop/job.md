## Role Summary
Interns develop software solutions — features, automation, and custom tools — while maintaining high code quality through reviews, testing, troubleshooting, and debugging. Day-to-day work includes collaborating with engineering teams to fix bugs and improve functionality/performance, gathering and interpreting requirements for new features, and working across the stack: UI/UX in React; scripting and app development in Python, Java, JavaScript, or Go; and deployment/automation with Terraform and Ansible. By three months, success looks like shipping features or automation, participating in code reviews and CI, and gaining exposure to test automation (e.g. Radish) and cloud (GCP/Azure) for scalable deployments. The role sits in Nokia’s Dallas ecosystem (O-RAN, 5G, network automation) and uses Git, Jira, Confluence, and Jenkins in an Agile context.

## What They're Really Looking For
- **Polyglot scripting/app:** Comfort in at least one of Python, Java, JavaScript, Bash, or Go — and willingness to touch multiple over the internship.
- **Tooling fluency:** Git, Jira, Confluence, Jenkins as daily drivers; not just “used once” but part of a real workflow.
- **Containers and cloud:** Docker, Kubernetes, Helm in practice; virtualization and cloud (GCP/Azure) for deployments, not just theory.
- **Quality and process:** Code reviews, testing, troubleshooting, debugging as non-negotiables; CI and Agile as how work gets done.
- **Optional but valued:** React for UI work; Terraform/Ansible for automation; IP networking basics; Linux; OS concepts (processes, threads, memory, synchronization) and strong debugging.

## Required Skills
- Programming experience in one or more of Python, Java, JavaScript, BASH, GoLang
- Familiarity with common development tools such as Git, Jira, Confluence, and Jenkins
- Exposure to Virtualization and Cloud technologies, along with knowledge of Containerization tools like Docker, Kubernetes, and Helm

## Preferred Skills
- React (UI/UX development)
- Terraform, Ansible (deployment/automation)
- Strong knowledge of basic IP networking concepts
- Familiarity with Linux distros
- Familiarity with Continuous Integration and Agile development processes
- Understanding of OS and system software concepts (processes, threads, memory management, synchronization) and excellent debugging skills
