Software development for the battery plant Unreal Engine 5 project at BMW Group’s Spartanburg-area operations: gameplay-style mechanics for simulation/training, VR/AR development, 3D data pipeline development, and department dashboard and database development/support. Day-to-day work includes implementing solutions in UE5 for game mechanics, 3D data pipelines, database connections, and networking; participating in cross-functional project teams; creating and maintaining user and support documentation; and providing technical support for UE5 and other software. Success at 3 months means delivering on assigned features in the UE5 project, supporting dashboards/databases, and applying Agile and coding standards.
