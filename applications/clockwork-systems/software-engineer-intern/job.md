## Role Summary
Full-stack intern building backend services and frontend applications that power distributed systems at scale. You will design and deploy scalable backends, build responsive UIs, integrate frontend with backend, and collaborate on API design, database modeling, and system architecture. Day-to-day includes debugging, optimization for performance and reliability, code reviews, and contributing to engineering best practices. Success at 3 months looks like shipping real features across the stack in a small, senior team focused on AI infrastructure and software-driven fabrics.

## What They're Really Looking For
- **Full-stack ownership** — Comfort coding across backend and frontend; not just "I used React" but end-to-end feature delivery.
- **Performance and reliability mindset** — Company does low-latency, high-performance systems; metrics and optimization matter.
- **API and system design** — Ability to participate in API design and database modeling, not just consume specs.
- **Collaborative rigor** — Code reviews and best practices are explicit; they want someone who fits a small-team, high-communication culture.
- **CS fundamentals** — Data structures, algorithms, and software design principles are required; coursework or project proof.
- **Ship speed** — "Fast-paced" and "hands-on" signal they want someone who can deliver quickly with guidance.

## Required Skills
- Currently pursuing Bachelor's, Master's, or PhD in Computer Science, EE, or related field
- Strong programming skills in Python, Java, C++, Go, or JavaScript/TypeScript
- Experience with frontend frameworks (React, Angular, Vue) and backend frameworks (Django, Node.js, Spring)
- Solid understanding of databases, REST APIs, and software design principles
- Knowledge of data structures, algorithms, and full-stack development concepts
- Strong problem-solving, debugging, and communication skills

## Preferred Skills
- Experience with cloud platforms (AWS, GCP, Azure)
- Familiarity with containers and orchestration (Docker, Kubernetes)
- Exposure to low-latency or high-performance systems
- Previous full-stack project experience (personal, academic, or professional)
