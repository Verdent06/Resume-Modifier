## Role Summary
The SVG (team) Software Intern contributes to SVG team projects: building data mining and analysis tools, machine learning applications, and C++ or open source software. You develop core software engineering skills—defining requirements, project planning, coding, debugging, testing, and documenting—while training on Cadence’s core EDA products and working with a designated mentor. Success means delivering a concrete project and presenting results at the end of the summer.

- Capacity to own a small project end-to-end: requirements, implementation, testing, docs.
- Clear communication and the ability to present work to the team.
