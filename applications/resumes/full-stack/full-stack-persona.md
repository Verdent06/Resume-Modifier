# Persona — General SWE / Full-Stack Track (base resume)

**Role summary:** Summer/co-op general software engineering internship — shipping a working product end-to-end (frontend, backend, API, data, deploy), not a domain specialization.

**screen_track:** `full-stack` (General SWE)  
**differentiator:** Breadth across the stack (frontend + backend + persistence + cloud) with real ownership on at least one shipped, revenue-generating product — not tutorial-grade single-layer work.

## Team & bar

Recruiter / HM at a generalist SWE intern program (big-tech generalist tracks, startups hiring for product engineering, mid-size non-tech-tech companies). Bar is: can this student ship a working product end-to-end and defend every layer's trade-off (why this DB, why this caching strategy, why REST over WebSocket) — not just call an API from a tutorial.

## Screen criteria (abstract)

- Frontend framework proven in real product work (not just listed) — React/Angular/Next.js
- Backend service or API shown in production, not just localhost
- A database or persistence layer used inside a real system decision
- Cloud/deployment fluency (AWS/GCP, Docker, CI/CD) tied to real delivery
- JavaScript/TypeScript signal visible early, not buried below a Python-only lead
- Trade-off fluency — the bullet defends a decision, not just names a tool
- GitHub as proof of work for the flagship product/project

## Anti-patterns

- Backend/data-only resume with zero frontend or client-surface evidence
- Frontend-only resume with zero API/backend/data-store evidence
- Skills dumping React/GraphQL/Spring Boot with zero bullet proof
- Python-pipeline-heavy lead that buries JS/TS until deep in the page
- Hard real-time C++ DSP as the lead story (wrong track; fine as a depth differentiator lower on the page)
- Vague cloud claims ("familiar with AWS") with no tied delivery

## ATS keywords (through use, not stuffing)

Python, TypeScript, Angular, RxJS, Flask, REST API, asyncpg, SQL, AWS (EC2), Docker, Redis, Celery, Git

## Entry lane preference (lens only — writer decides from context.md)

Reward: shipped product with real users/revenue, frontend depth (Angular/RxJS/TypeScript), backend/API/cloud ownership, persistence-layer evidence.  
Deprioritize: pure GTM/data-aggregation scoring with no API/frontend signal; hard real-time C++ audio DSP as the lead (fine lower on the page as a systems-depth differentiator, not as the opening story).
