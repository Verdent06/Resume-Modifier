## Role Summary
The intern designs and implements a Dynamic Application Security Testing (DAST) test bench for Neo4j’s internal APIs and MCP (Model Context Protocol) solutions. Day-to-day work includes researching and evaluating open source DAST tools, building a reusable environment for security engineers to run repeatable API tests, running structured experiments against selected APIs (including Aura APIs), comparing findings across tools for signal quality, and documenting setup, results, and recommendations. Success at 3 months is a working, documented environment; a short list of recommended tools with rationale; and clear comparison of findings and limitations. The intern works with the Application Security team and collaborates with platform and engineering teams.

## What They're Really Looking For
- **Security + tooling mindset** — Someone who enjoys building and testing in a security context: DAST, API testing, and reusable test environments, not just feature development.
- **Python + REST APIs** — Solid coding in Python and good understanding of how REST APIs are designed and consumed; the role is API-centric (Aura APIs, MCP services).
- **Open source and experimentation** — Experience setting up and using open source tools; comfort running structured experiments and comparing results.
- **MCP awareness** — Understanding of the role MCP servers play in modern software development (agentic/AI tooling); Neo4j is investing in agentic AI and graph-backed context.
- **Documentation and clarity** — Curiosity, structured thinking, and the ability to document technical findings clearly so others can reuse and extend the setup.
- **Application security interest** — Strong interest in application security and desire to work on real security challenges in a production environment.
